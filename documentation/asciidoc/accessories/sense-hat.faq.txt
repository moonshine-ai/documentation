# About

Q: What is the Sense HAT and what can it actually do?
A: It's an add-on board letting your Pi sense pressure, humidity, temperature, orientation, and movement.

Q: I've heard the Sense HAT was used in space. Is that actually true?
A: Yes, it was developed for use on the International Space Station via the Astro Pi programme.

Q: Does the Sense HAT work with my Raspberry Pi? I'm not sure if it's compatible.
A: It works with any Raspberry Pi that has a 40-pin GPIO header.

Q: What language do I need to use to program the Sense HAT?
A: There's an officially supported Python library, but C++ is also supported.

# Features

Q: What sensors does the Sense HAT actually have built in?
A: It has gyroscope, accelerometer, magnetometer, temperature, pressure, humidity, and colour sensors.

Q: How many buttons does the joystick have on the Sense HAT?
A: The Sense HAT has a five-button joystick.

Q: I want the schematics for the Sense HAT. Where do I find those?
A: Download schematics and mechanical drawings from the Raspberry Pi Product Information Portal.

# LED matrix

Q: What kind of LED matrix is on the Sense HAT? Like what's the resolution?
A: It's an 8×8 RGB LED matrix using the RGB565 framebuffer format.

Q: How do I actually write to the LED matrix, like what's the technical way to do it?
A: Write to it as a standard file or use mmap on the appropriate framebuffer device node.

# Joystick

Q: How does the joystick show up on the system? Can I use it like a normal input device?
A: It shows up as an input event device mapped to the arrow keys and Enter.

Q: What libraries can I use to read input from the Sense HAT joystick?
A: SDL, pygame, and python-evdev are all suitable libraries for joystick input.

# Install

Q: How do I install the Sense HAT software on my Raspberry Pi?
A: Run sudo apt install sense-hat, then reboot to enable I2C and update the kernel.

Q: Do I need to do anything special before plugging in the Sense HAT?
A: You need an up-to-date kernel, I2C enabled, and a few dependencies installed first.

Q: Why do I have to reboot after installing the sense-hat package?
A: Rebooting enables I2C and loads the new kernel if it changed during installation.

Q: I just want to get started quickly. What's the fastest way to install everything?
A: Run sudo apt update, then sudo apt install sense-hat, then sudo reboot.

# Calibrate

Q: How do I calibrate the Sense HAT's sensors? I'm getting weird readings.
A: Install octave, run RTIMULibCal, and follow the magnetometer calibration steps.

Q: What do I actually have to physically do during the magnetometer calibration?
A: Waggle the Pi around covering all six axes until the min and max values stop changing.

Q: Where does the calibration file get saved when I'm done?
A: Copy the resulting RTIMULib.ini file to /etc/ after calibration is complete.

Q: I finished calibrating and now there's a local config file I don't need. What should I do with it?
A: Remove it with rm ~/.config/sense_hat/RTIMULib.ini after copying to /etc.

Q: Is there more than one way to calibrate the magnetometer?
A: Yes, you can do min/max calibration or additionally do an ellipsoid fit calibration.

# Getting started

Q: Where can I find example code to play around with after installing the Sense HAT?
A: Example code is found under /usr/src/sense-hat/examples after installation.

Q: Where's the full documentation for the Python Sense HAT library?
A: Complete documentation is at sense-hat.readthedocs.io.

# Use the Sense HAT with C++

Q: Can I use C++ instead of Python with the Sense HAT?
A: Yes, RTIMULib is a C++ and Python library supporting the Sense HAT sensors.

Q: I'm using the C++ examples but the readings don't seem very accurate. What am I missing?
A: Copy RTIMULib.ini to your current working directory for more accurate sensor data.

Q: How do I compile the C++ examples for the Sense HAT?
A: Run make in the appropriate example directory to compile C/C++ examples.

# Troubleshooting

Q: I'm trying to read the EEPROM on my Sense HAT. How do I do that?
A: Enable I2C0 and I2C1 in config.txt, reboot, then run the eepflash.sh script with -r flag.

Q: Will writing to the EEPROM break my Sense HAT or Pi?
A: It won't damage hardware, but errors may prevent automatic HAT detection on boot.

Q: I have a Raspberry Pi 3 Model B and the EEPROM steps aren't working. Is that a known issue?
A: Yes, Pi 2 Model B Rev 1.0 and Pi 3 Model B may not work due to firmware controlling I2C0.

Q: How do I disable write protection before flashing the Sense HAT EEPROM?
A: Run i2cset -y -f 1 0x46 0xf3 1 to disable write protection before flashing.
