# About

Q: What's actually in the Raspberry Pi SSD Kit? What do you get?
A: You get an M.2 HAT+, an SSD, stacking header, spacers, and screws.

Q: Does the SSD Kit work with the Active Cooler, or do I have to choose one or the other?
A: The kit includes hardware to fit it alongside the Active Cooler on Pi 5.

Q: I'm looking at the SSD Kit but I don't know what an M.2 HAT+ is. What's it for?
A: The M.2 HAT+ is a separate Raspberry Pi accessory bundled with the SSD.

Q: What sizes does the Raspberry Pi SSD come in for this kit?
A: Not specified in this section.

# Install

Q: Okay I've got the SSD Kit, how do I actually put it together?
A: Follow the installation instructions for the Raspberry Pi M.2 HAT+.

Q: Is there a separate install guide for the SSD Kit or do I just follow the HAT+ instructions?
A: You follow the M.2 HAT+ installation instructions to install the SSD Kit.

# Whole Document

Q: I've got a Raspberry Pi 5 and I want to add an SSD. Is this kit what I need?
A: Yes, the SSD Kit is designed to work with Raspberry Pi 5.

Q: Can I use the SSD Kit and the Active Cooler at the same time on my Pi 5?
A: Yes, the kit includes a stacking header and spacers to enable that.
