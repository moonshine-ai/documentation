# Getting started

Q: What boards can I use with the AI Camera?
A: Use Raspberry Pi 4 Model B, Pi 5, Zero 2 W, or Pi 3 Model B+.

Q: I just got my AI Camera, what's the first thing I should do software-wise?
A: Update your Raspberry Pi software with sudo apt update and full-upgrade.

Q: Do I need to do anything special to connect the AI Camera physically?
A: Follow the Install a Raspberry Pi Camera instructions for your board.

# Install the IMX500 firmware

Q: What does installing imx500-all actually do? Like what gets put on my Pi?
A: It installs firmware files, neural network models, post-processing stages, and Sony packaging tools.

Q: My camera's taking forever to start up after I installed everything. Is that normal?
A: Yes, firmware loading can take several minutes if not previously cached.

Q: Where does it put all those neural network model files?
A: Neural network model firmware files go into slash usr slash share slash imx500-models.

Q: Do I have to reboot after installing the firmware or can I just keep going?
A: Yes, you need to restart your Raspberry Pi after installing the prerequisites.

# Object detection

Q: How do I get bounding boxes showing up on my camera feed?
A: Run rpicam-hello with the imx500_mobilenet_ssd.json post-processing file flag.

Q: What's actually doing the object detection, my Pi or the camera itself?
A: All object detection runs directly on the AI Camera, not your Raspberry Pi.

Q: I want to record video with the object detection boxes visible. Can I do that?
A: Yes, use rpicam-vid instead of rpicam-hello with the same post-processing file.

Q: The detection output looks really jumpy and noisy. Is there a way to smooth that out?
A: Temporal filtering and hysteresis are applied by default; remove temporal_filter config to disable.

Q: How do I limit how many objects it tries to detect at once?
A: Set the max_detections parameter in the imx500_object_detection stage configuration.

Q: It's detecting things it shouldn't. Can I make it more strict about what counts as an object?
A: Yes, raise the threshold value to require higher confidence before detecting an object.

# Pose estimation

Q: What does PoseNet actually track on a person's body?
A: It labels key points associated with joints and limbs on the body.

Q: Does pose estimation all happen on the camera like object detection does?
A: No, PoseNet's output tensor needs additional post-processing on your host Raspberry Pi.

Q: What command do I run to see pose estimation working on my camera feed?
A: Run rpicam-hello with the imx500_posenet.json post-processing file at 1920x1080.

Q: Can I limit how many people it tries to track at once?
A: Yes, set max_detections in the imx500_posenet stage to limit tracked bodies.

# Picamera2

Q: Does Picamera2 support the AI Camera too, or is it just rpicam-apps?
A: Yes, Picamera2 supports image classification, object detection, segmentation, and pose estimation.

Q: I want to use Picamera2 with the AI Camera. Do I need to install anything extra?
A: Install python3-opencv and python3-munkres for the OpenCV-dependent examples.

Q: How do I run YOLOv8 object detection with Picamera2?
A: Run imx500_object_detection_demo.py with the imx500_network_ssd_mobilenetv2 model flag.

Q: Where do I find the Picamera2 AI Camera examples?
A: Download the picamera2 GitHub repository; examples are in the root directory.

# Whole Document

Q: I've never used a Raspberry Pi camera before. Is this gonna be super complicated to set up?
A: Setup involves attaching hardware, updating software, installing firmware, and rebooting.

Q: What two neural network models come pre-packaged for the AI Camera?
A: MobileNet SSD for object detection and PoseNet for pose estimation come pre-packaged.

Q: What software frameworks work with the Raspberry Pi AI Camera?
A: The AI Camera works with libcamera, rpicam-apps, and Picamera2.

Q: Where are the post-processing JSON config files stored on my Pi?
A: They're located in slash usr slash share slash rpi-camera-assets.
