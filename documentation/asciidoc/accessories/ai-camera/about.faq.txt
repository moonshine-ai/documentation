# About

Q: What sensor does the Raspberry Pi AI Camera use?
A: It uses the Sony IMX500 imaging sensor for AI capabilities.

Q: I've heard the AI Camera can run neural networks. Does it need a separate chip for that or is it built in?
A: The AI capability is built into the Sony IMX500 imaging sensor itself.

Q: What kind of models can I actually run on this camera, like do I have to use ones made by Raspberry Pi?
A: You can run either pre-packaged or your own custom neural network models.

Q: I want to use this camera with my Python code. Is it compatible with Picamera2?
A: Yes, the AI Camera works with both rpicam-apps and Picamera2.

Q: What's the point of the AI Camera over a regular camera module?
A: It provides low-latency, high-performance AI capabilities to any camera application.

Q: I don't really know what inference data is. What does this camera actually produce that I need to deal with?
A: Neural networks on the IMX500 generate inference data you'll need to interpret.

Q: Does this thing work with the regular Raspberry Pi camera software or do I need something special?
A: It integrates with Raspberry Pi's existing camera software stack with minimal effort.

Q: I want to deploy my own neural network. Is that actually doable without a lot of hassle?
A: Yes, tight integration with the camera software stack allows deployment with minimal effort.
