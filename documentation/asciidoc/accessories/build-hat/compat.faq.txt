# Device Compatibility

Q: What LEGO kits are supported by the Build HAT library?
A: It supports SPIKE Portfolio, Mindstorms Robot Inventor, and PoweredUp connector devices.

Q: Does the Build HAT work with Mindstorms Robot Inventor stuff?
A: Yes, Mindstorms Robot Inventor devices are supported by the Build HAT library.

Q: I've got a SPIKE Prime set. Will the motors and sensors work with the Build HAT?
A: Yes, SPIKE Prime motors and sensors are fully supported in firmware and Python.

Q: What's the difference between product codes 45680 and 45681 for the SPIKE Prime Expansion Set?
A: Product 45681 includes the Maker Plate; the original 45680 does not include it.

Q: I'm looking at the SPIKE Prime Expansion Set and I want the Maker Plate. Which one do I buy?
A: You need product code 45681, which is the version that includes the Maker Plate.

Q: Does the colour and distance sensor work fully with the Build HAT or are there limitations?
A: The colour and distance sensor only has partial firmware support and uncertain Python support.

Q: Are the WeDo 2.0 motion and tilt sensors supported in the Build HAT firmware?
A: No, the WeDo 2.0 motion and tilt sensors don't show firmware support listed.

Q: I've got a PoweredUp LED lights module. Can I use it with the Build HAT in Python?
A: Python support for PoweredUp LED lights is not listed as supported.

Q: What's the difference between active and passive devices in this list?
A: Not specified in this section.

Q: I want to use a Force Sensor with my Build HAT. Is that going to work?
A: Yes, the Force Sensor is fully supported in both firmware and Python.

Q: Which motors from the SPIKE Prime set are compatible with the Build HAT?
A: The Large Angular Motor and Medium Angular Motor from SPIKE Prime are fully supported.

Q: I've got a train motor, the black one model 88011. Will that work with the Build HAT?
A: Yes, the system train motor 88011 is supported in both firmware and Python.

Q: Is the 3x3 LED matrix thing from SPIKE Essentials supported?
A: Yes, the 3x3 LED matrix is fully supported in firmware and Python.

Q: Does the Build HAT support the Technic XL motor?
A: Yes, the Technic XL motor is fully supported in both firmware and Python.

Q: I've got a medium linear motor from the Boost set. Can I use that with Build HAT?
A: Yes, the medium linear motor from Boost is supported in firmware and Python.
