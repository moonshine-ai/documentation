# Further Resources

Q: Where can I find the full Python library docs for the Build HAT?
A: Full Python Library documentation is available on the ReadTheDocs website.

Q: I want to use the Build HAT with .NET instead of Python. Is there any info on that?
A: The .NET IoT GitHub repository has more information on the .NET library.

Q: Are there any fun beginner projects I can follow along with using the Build HAT?
A: The Raspberry Pi Foundation has five LEGO projects including a robot car and plotter.

Q: I'm trying to understand how the Build HAT communicates. Is there any documentation on the protocol it uses?
A: Yes, you can download the Raspberry Pi Build HAT Serial Protocol documentation online.

Q: Can I build a game controller using LEGO and the Build HAT? Like is there a guide for that?
A: Yes, the Raspberry Pi Foundation has a LEGO Game Controller project you can follow.
