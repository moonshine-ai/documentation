# Use Motors from .NET

Q: What's the difference between active and passive motors in .NET?
A: Active motors give position and speed data; passive motors only control speed.

Q: What values can I pass into SetPowerLimit and SetBias?
A: Both only accept values between zero point zero and one point zero.

Q: What does the bias setting actually do on a motor?
A: It compensates for DC motors needing minimum drive before they'll turn at all.

Q: What are the default values when a motor gets created?
A: Power limit defaults to zero point seven and bias defaults to zero point three.

# Passive Motors

Q: What's the speed range I can set on a passive motor?
A: Passive motor speed goes from negative one hundred to positive one hundred.

Q: I started my train motor but want to slow it down without stopping it. Can I do that?
A: Yes, once started you can adjust speed and the motor adjusts accordingly.

Q: Can a passive motor tell me how fast it's actually going?
A: No, the Speed property is target only; passive motors can't measure real speed.

Q: What functions are there to control a passive motor besides setting the speed?
A: You can use Start, Stop, and SetSpeed to control passive motors.

# Active Motors

Q: What extra info can I read from an active motor that I can't get from a passive one?
A: Active motors provide Speed, AbsolutePosition, Position, and TargetSpeed properties.

Q: Do active motors keep updating their sensor readings even when stopped?
A: Yes, active motor properties are read continuously even when the motor is stopped.

Q: I want my active motor to go back to its starting position. How do I do that?
A: Use MoveToPosition passing zero and set TargetSpeed before calling it.

Q: Can I make my code wait until the motor finishes moving before doing the next thing?
A: Yes, each move function lets you block the thread until the operation completes.

Q: What's float mode on an active motor and when would I use it?
A: Float removes all constraints, useful when using the motor as a tachometer.

Q: Is there like a tolerance when moving to a specific position? It doesn't have to be exact?
A: Yes, absolute and relative position moves have a tolerance of a few degrees.

# Whole Document

Q: I'm using .NET and I've got a LEGO train motor. Is that a passive or active motor?
A: Train motors are typical passive motors in the Powered Up system.

Q: Do I need to remember to stop my motors in code or do they stop on their own?
A: You must explicitly stop motors; the docs remind you to start and stop as needed.
