# Work with Sensors

Q: I've got a colour sensor and a force sensor — which ports do I plug them into on the Build HAT?
A: Connect the colour sensor to port B and the force sensor to port C.

Q: Do I need an external power supply just to use sensors, or can I get away with a normal USB charger?
A: No external supply needed for sensors — a standard USB power supply works fine.

Q: I pressed the force sensor but nothing showed up in Thonny. What's supposed to happen?
A: The colour sensor LED turns on and the closest colour name prints in the REPL.

Q: What's the best thing to hold in front of the colour sensor to test it?
A: LEGO elements are described as ideal objects to use for testing.

Q: So the colour sensor just stays off until I press the force sensor? Is that right?
A: Yes, pressing the force sensor turns the colour sensor on, releasing turns it off.

Q: I'm confused — what does the `pause()` at the end of the script actually do?
A: Not specified in this section.

Q: What library do I need to import to use the force and colour sensors in Python?
A: You need to import ForceSensor and ColorSensor from the buildhat library.

Q: How does the code know when I press or let go of the force sensor?
A: You assign functions to `when_pressed` and `when_released` on the ForceSensor object.

# Whole Document

Q: I'm just using sensors, no motors — do I really need that big external power brick?
A: No, without motors you can just use a standard USB power supply for your Pi.

Q: I want to read sensor data from Python on my Build HAT. Where do I even start?
A: Connect your sensors to the HAT ports and use the buildhat Python library to read them.
