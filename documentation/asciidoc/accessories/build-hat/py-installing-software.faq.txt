# Install the Build HAT Python Library

Q: How do I install the Build HAT Python library on my Raspberry Pi?
A: Open a terminal and run sudo apt install python3-build-hat to install it.

Q: I'm running an older version of Raspberry Pi OS and the apt command isn't working for the Build HAT library. What do I do?
A: On older systems, use sudo pip3 install buildhat to install the library instead.

Q: Do I need to use pip or apt to install the Build HAT library? I'm confused about which one to use.
A: Use apt on Bookworm or newer; use pip3 on older Raspberry Pi OS versions.

Q: I want to learn more about the Build HAT Python library. Where can I find more info?
A: Full documentation for the Build HAT Python library is available at buildhat.readthedocs.io.

Q: Wait, what version of Raspberry Pi OS do I need to use apt for the Build HAT library?
A: Bookworm and later versions support installing the library using apt.

Q: I tried running the apt install command but it's saying the package isn't found. What's going on?
A: Raspberry Pi OS versions before Bookworm don't support apt for this library; use pip3 instead.
