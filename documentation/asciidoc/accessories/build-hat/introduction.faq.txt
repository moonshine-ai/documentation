# About

Q: What even is the Build HAT? I've never heard of it before.
A: It's an add-on board letting you control LEGO Technic motors and sensors.

Q: Does the Build HAT work with my Raspberry Pi Zero?
A: Yes, it works with all 40-pin GPIO Raspberry Pi boards including Zero-series.

Q: I've got a Raspberry Pi 5, will the Build HAT fit on it?
A: It fits any Raspberry Pi with a 40-pin GPIO header, so yes.

Q: How many motors can I plug into the Build HAT at once?
A: The Build HAT provides four connectors for LEGO Technic motors and sensors.

Q: Can I control the Build HAT with Python or do I need something else?
A: There's an easy-to-use Python library available to control your LEGO Technic devices.

Q: I've got the latest Raspberry Pi OS and the Build HAT isn't working. What's going on?
A: Build HAT isn't supported on Trixie yet; stay on or install Bookworm instead.

Q: Do I need a separate power supply for the Build HAT or does it use the Pi's power?
A: An external 8V PSU is available separately to power both Build HAT and Raspberry Pi.

Q: What kind of sensors can I actually connect to the Build HAT?
A: Available sensors include a distance sensor, colour sensor, and a versatile force sensor.

Q: I've got a Raspberry Pi 400. Can I still use the Build HAT with it?
A: Yes, with a ribbon cable or extension device it works with Keyboard-series devices.

Q: Wait, can the Build HAT power my Raspberry Pi 400 through the GPIO?
A: No, the Build HAT cannot power Keyboard-series devices via GPIO headers.

Q: What's inside the Build HAT that actually talks to the LEGO stuff?
A: An on-board RP2040 microcontroller manages low-level control of LEGO Technic devices.

Q: Are there any LEGO sets that work well with the Build HAT?
A: The SPIKE Prime Set 45678 and Expansion Set 45681 include supported elements.

Q: Do the LEGO motors tell you what position they're in, or is it just on and off?
A: Angular motors include integrated encoders that can be queried to find their position.

Q: I want to use a camera module alongside my LEGO stuff. Is that possible?
A: Yes, LEGO Technic devices can be controlled alongside standard Raspberry Pi accessories like cameras.
