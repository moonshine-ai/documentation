# Connect a Motor

Q: My LPF2 connector won't slide in easily — what should I do?
A: Rotate the connector 180 degrees and try inserting it again.

Q: Does it matter which way up I plug the motor connector into the Build HAT?
A: Yes, LPF2 connectors must be inserted the correct way up.

# Work with Motors

Q: I just ran my first Build HAT program and it paused for ages — is that normal?
A: Yes, firmware copies to the board first time, causing a few seconds pause.

Q: How do I know the firmware's loaded onto the Build HAT? Is there like a light or something?
A: The red LED turns off and the green LED lights up when firmware loads.

Q: Will it always take that long to start up every time I run a program?
A: No, only the first run after booting pauses; subsequent runs won't need it.

Q: How do I make my motor spin faster in Python?
A: Pass a higher speed value, like speed equals 50, to run_for_seconds.

Q: I want the motor to spin backwards. How do I do that?
A: Use a negative speed value, like speed equals negative 50, to reverse direction.

Q: Can I read the position of the motor shaft while it's turning by hand?
A: Yes, use get_aposition in a loop to see the shaft position change live.

Q: What does get_aposition actually do — like what does it return?
A: It returns the current angular position of the motor shaft.

# Whole Document

Q: Which port do I plug the motor into for these example programs?
A: The examples use port A on the Build HAT for the motor connection.

Q: I don't know what IDE to use for writing the Build HAT Python code. Any suggestions?
A: The documentation uses Thonny IDE for writing and running Build HAT programs.

Q: How long does the motor run by default when I call run_for_seconds?
A: In the example, run_for_seconds runs the motor for five seconds.
