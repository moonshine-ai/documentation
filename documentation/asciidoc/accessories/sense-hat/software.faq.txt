# Install

Q: How do I get my Pi ready to use the Sense HAT?
A: Update, install sense-hat package, then reboot your Raspberry Pi.

Q: Do I need to enable I2C myself before installing the Sense HAT stuff?
A: No, installing the sense-hat package will automatically enable I2C for you.

Q: I just installed the Sense HAT package. Do I need to restart my Pi?
A: Yes, reboot to enable I2C and load any updated kernel.

Q: What's the install command for the Sense HAT software?
A: Run sudo apt install sense-hat to install the package.

# Calibrate

Q: How do I calibrate the Sense HAT?
A: Install octave, copy RTEllipsoidFit, then run RTIMULibCal to calibrate.

Q: I started the magnetometer calibration. What am I actually supposed to do with the Pi?
A: Waggle the IMU so all six axes go through their extremes.

Q: How do I know when I'm done with the magnetometer calibration?
A: Stop when the min and max numbers on screen stop changing.

Q: After I finish calibrating, where do I save that INI file?
A: Copy RTIMULib.ini to /etc/ and remove the local copy from ~/.config/sense_hat/.

Q: What's the difference between the min/max and ellipsoid calibration options?
A: Do min/max first, then ellipsoid fit adds extra accuracy on top.

Q: After calibrating, I ran ls and saw a new file. What's it called?
A: The calibration creates a new file called RTIMULib.ini.

# Getting started

Q: Where do I find example code after installing the Sense HAT?
A: Example code is found under /usr/src/sense-hat/examples after installation.

Q: What's the official Python library for the Sense HAT?
A: The officially supported library is called sense-hat.

Q: Where can I find the full docs for the Sense HAT Python library?
A: Full documentation is at sense-hat.readthedocs.io.

Q: I want to use C++ with the Sense HAT. What library should I use?
A: Use RTIMULib, a C++ and Python library for IMUs on embedded Linux.

Q: How do I close that RTIMULibDrive11 example when I'm done?
A: Press Ctrl C to close the RTIMULibDrive11 example.

Q: The C++ examples seem to need a settings file. Where should I put it?
A: Copy RTIMULib.ini to your current working directory for more accurate data.

# Troubleshooting

Q: I want to read and write EEPROM data on my Sense HAT. Where do I start?
A: Enable I2C0 and I2C1 in config.txt, then reboot before proceeding.

Q: Will writing to the EEPROM break my Pi or Sense HAT?
A: It won't damage hardware, but errors may prevent automatic HAT detection.

Q: How do I actually read the EEPROM data from the Sense HAT?
A: Run sudo ./eepflash.sh -f=sense_read.eep -t=24c32 -r to read it.

Q: I'm on a Pi 2 or Pi 3 Model B. Will the EEPROM steps work for me?
A: These steps may not work on those boards due to firmware controlling I2C0.

Q: Do I need to do anything before writing to the EEPROM, like turning off write protection?
A: Yes, run i2cset to disable write protection before writing EEPROM data.

Q: I wrote to the EEPROM. Should I do anything after I'm done?
A: Re-enable write protection using i2cset after writing is complete.

# Whole Document

Q: I just got a Sense HAT. What's the whole setup process from unboxing to coding?
A: Update Pi, install sense-hat, reboot, calibrate sensors, then explore examples.

Q: Does the Sense HAT need I2C to work?
A: Yes, I2C must be enabled for the Sense HAT to work correctly.

Q: Can I use the Sense HAT with both Python and C++?
A: Yes, sense-hat supports Python and RTIMULib supports C++ and Python.
