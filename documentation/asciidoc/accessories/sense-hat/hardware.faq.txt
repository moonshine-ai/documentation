# Features

Q: What sensors does the Sense HAT actually have on it?
A: It has gyroscope, accelerometer, magnetometer, temperature, pressure, humidity, and colour sensors.

Q: Does the Sense HAT have any buttons or is it just sensors?
A: It has a five-button joystick in addition to all the sensors.

Q: I want the technical drawings for my Sense HAT. Where do I find those?
A: Download schematics and mechanical drawings from the Raspberry Pi Product Information Portal.

Q: What's the difference between the Sense HAT and Sense HAT V2?
A: Not specified in this section.

# LED matrix

Q: What kind of display is the LED grid on the Sense HAT?
A: It's an RGB565 framebuffer with the device ID RPi-Sense FB.

Q: How do I actually write to the LED matrix, like what's the method?
A: Write to it like a standard file or use mmap on the appropriate device node.

Q: Is there example code showing how to use the LED display?
A: Yes, the included snake example demonstrates how to access the framebuffer.

Q: How many LEDs does the Sense HAT have?
A: It has an eight by eight RGB LED matrix, totalling sixty-four LEDs.

# Joystick

Q: How does the joystick show up to my Raspberry Pi, like what does the system see it as?
A: It shows up as an input event device named Raspberry Pi Sense HAT Joystick.

Q: What keys does the joystick map to?
A: The joystick maps to the arrow keys and the Enter key.

Q: I want to use pygame with the Sense HAT joystick. Will that work?
A: Yes, pygame is listed as a suitable library for handling the joystick input.

Q: What libraries can I use to read the joystick input?
A: SDL, pygame, and python-evdev are all suitable libraries for joystick input.

Q: I don't want to use a library, I just want to read the joystick directly. Can I do that?
A: Yes, you can access it directly through the evdev interface.

Q: Is there sample code for getting the joystick working?
A: Yes, the included snake example shows how to access the joystick directly.
