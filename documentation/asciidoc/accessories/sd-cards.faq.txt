# About

Q: Does it matter what SD card I use, or is any card fine for a Raspberry Pi?
A: SD card quality critically affects overall Raspberry Pi user experience and performance.

Q: What's so special about the official Raspberry Pi SD cards compared to random ones I'd buy?
A: They support DDR50, SDR104 bus speeds, and command queueing for optimal performance.

Q: What's command queueing? Do I actually need it?
A: It allows pipelining of random read operations, ensuring optimal SD card performance.

Q: Can I get a Pi SD card that already has the OS on it?
A: Yes, Raspberry Pi SD cards are available pre-programmed with the latest Raspberry Pi OS.

Q: What sizes do the official Raspberry Pi SD cards come in?
A: They come in 32 GB, 64 GB, and 128 GB sizes.

# Specifications

Q: What speed class rating does the official Raspberry Pi SD card have?
A: Raspberry Pi SD cards are rated C10, U3, V30, and A2.

Q: I've got a Pi 5 — how fast is the official SD card on it?
A: On Pi 5 using SDR104, read is 5,000 IOPS and write is 2,000 IOPS.

Q: What about on a Pi 4, how fast does the card run?
A: On Pi 4 using DDR50, read is 3,200 IOPS and write is 1,200 IOPS.

Q: What form factor are these SD cards? Like, are they the full-size ones or the tiny ones?
A: They use the microSDHC and microSDXC form factor, so the small ones.

Q: What SD specification do the official Raspberry Pi cards use?
A: Raspberry Pi SD cards use the SD6.1 SD specification.

# Whole Document

Q: I'm buying my first Raspberry Pi — should I just get the official SD card?
A: Official cards offer optimised speeds and command queueing for best Raspberry Pi performance.

Q: My Pi feels sluggish. Could the SD card actually be causing that?
A: Yes, slow bus speeds and lack of command queueing reduce performance even on powerful models.

Q: What's the biggest official Raspberry Pi SD card I can get?
A: The largest available official Raspberry Pi SD card is 128 GB.
