# Legacy Support

Q: I've got an old Raspberry Pi and I'm trying to connect a touchscreen. Do I need extra cables or something?
A: Yes, use the included jumper cables to connect GPIO SCL/SDA pins to the display board.

Q: How do I tell if my Raspberry Pi is old enough to need these legacy instructions?
A: Only the original model has a 26-pin GPIO header; newer ones have 40 pins.

Q: I plugged in a DSI display on my original Raspberry Pi and nothing's showing up. What's going on?
A: DSI autodetection is disabled by default; add ignore_lcd=0 to config.txt to enable it.

Q: Where exactly do I add that ignore LCD line on my old Pi?
A: Add ignore_lcd=0 to the /boot/firmware/config.txt file on your Raspberry Pi.

Q: Does it matter which USB port I use to power the display on my original Pi?
A: Use the display board's PWR IN micro-USB connector, not the Raspberry Pi's micro-USB port.

Q: Why can't I just power everything through the Raspberry Pi's USB port? Seems easier.
A: The display uses around 400mA, which exceeds the Raspberry Pi's input polyfuse maximum rating.

Q: I've got a Model B original Pi and the touchscreen isn't working. Could it be a wiring thing?
A: Original Model A and B lack I2C on DSI, so jumper cables connecting GPIO to display are required.

Q: Wait, do Models A and B have the same DSI problem, or is it just one of them?
A: Both the Raspberry Pi 1 Model A and Model B have this same DSI connector limitation.
