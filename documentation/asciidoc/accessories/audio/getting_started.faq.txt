# Getting started

Q: What's this chatter box thing supposed to do exactly?
A: It plays random recorded clips when pressed, records new ones when held.

Q: How long do I hold the button to start recording a new clip?
A: Hold for ten seconds until a burp sound plays, then it records five seconds.

Q: What happens if I hold the button for more than 20 seconds?
A: It plays a burp sound and erases all your previous recordings.

# Hardware and wiring

Q: What kind of speaker do I need for this project?
A: Any small passive speaker works; they suggest five watts at four ohms.

Q: Do I need to buy a special button for this, or is there one already on the board?
A: The Codec Zero has an on-board button pre-wired to GPIO 27.

Q: Which GPIO pin does the button connect to on the Codec Zero?
A: The button uses GPIO pin 27, and Ground for the switch.

Q: I want to add an LED to my button. What pins do I use for that?
A: Use plus three point three volts and Ground for the LED if needed.

# Set up your Raspberry Pi

Q: Which version of Raspberry Pi OS should I use for this project?
A: This example uses Raspberry Pi OS Lite.

Q: Do I need to update my Pi before starting this project?
A: Yes, update your operating system before proceeding with the project.

# Program your Raspberry Pi

Q: How do I get the script to run automatically every time the Pi boots up?
A: Add an at-reboot crontab entry pointing to your chatter box Python script.

Q: What editor does the guide recommend for editing the crontab?
A: They recommend using nano for editing your crontab file.

Q: I don't have a desktop on my Pi Lite. How do I open a shell to write the script?
A: You can connect via SSH to open a shell on your Raspberry Pi.

Q: How do I make the Python script actually executable after I've saved it?
A: Run sudo chmod plus x chatter underscore box dot py.

Q: Where does the burp sound come from? Do I record it myself?
A: The script automatically downloads a burp sound file from rpf dot io.

# Use the toy chatter box

Q: Okay I've set it up. What's the correct way to record my first clip?
A: Press the button, release after the burp, then it records for five seconds.

Q: How do I delete all my recordings if I want to start fresh?
A: Hold the button past the first burp and release after at least 20 seconds.

Q: How do I know it actually deleted everything? Is there a confirmation?
A: A second burp sound plays confirming the recordings have been deleted.

Q: If I've recorded a bunch of clips, does it play them in order or randomly?
A: It plays a randomly chosen clip from your sounds folder each time.
