# Hardware Information

Q: What size screws does the PCB use?
A: All PCB screws are M2.5 size.

Q: I'm building a case for my Pi audio board. What standoffs do I need?
A: Use 5 mm male/female standoffs for the case attachment.

Q: What standoffs go between the Raspberry Pi and the audio boards?
A: Use 9 mm female/female standoffs between Raspberry Pi and audio boards.

Q: What power supply should I use for the DigiAMP Plus?
A: Use a 12V to 24V, 3A supply like the XPPower VEC65US19.

Q: What's the barrel connector size for powering the DigiAMP Plus?
A: The barrel connector is 2.5 mm inner diameter, 5.5 mm outer diameter, 11 mm.

Q: What thickness wire can I use with the Codec Zero speaker terminal?
A: It accepts wires between 14 to 26 AWG, maximum 1.6 mm diameter.

Q: What rotary encoders are compatible with these audio boards?
A: Tested encoders include Alpha RE160F-40E3-20A-24P, ALPS EC12E2430804, and Bourns ECW0JB24-AC0006L.

# GPIO Usage

Q: Which GPIO pins get taken up by the audio boards?
A: Power, ground, GPIO 2/3 for I2C, and GPIO 18 through 21 for I2S.

Q: I want to add a volume knob. Which GPIO pins does the rotary encoder use?
A: The rotary encoder uses GPIO 23/24, with the push switch on GPIO 27.

Q: Does the IR sensor use a GPIO pin?
A: Yes, the IR sensor uses GPIO 25.

Q: Can I share GPIO pins between the audio board and other sensors?
A: Some pins like I2C can be shared, but I2S and EEPROM pins are exclusive use.

Q: What's GPIO 22 used for on the DigiAMP Plus?
A: GPIO 22 handles mute and unmute support for the DigiAMP Plus.

# DAC PRO, DAC+, DigiAMP+, Codec Zero

Q: Can I still connect other stuff to GPIO when I've got the audio board on?
A: Yes, the boards re-expose Raspberry Pi signals for adding sensors and peripherals easily.

# Saving AlsaMixer Settings

Q: I got my audio settings just right. How do I save them so they don't reset?
A: Run sudo alsactl store from the command line to save your settings.

Q: I want to reload my audio settings on startup. How do I save them to a file?
A: Run sudo alsactl store -f /home/username/usecase.state to save settings.

Q: How do I restore my saved AlsaMixer settings from a file?
A: Run sudo alsactl restore -f /home/username/usecase.state to restore saved settings.

# MPD-Based Audio with Volume Control

Q: My MPD music player can't control the volume on my DAC board. How do I fix that?
A: Add a mixer_control line to the audio output section in /etc/mpd.conf.

Q: What should the mixer control name be set to for the DAC Pro or DigiAMP Plus?
A: Set mixer_control to "Digital" for Texas Instruments-based boards like DAC PRO and DigiAMP Plus.

Q: Which config file do I edit to get MPD working with my audio board's volume?
A: Edit the /etc/mpd.conf file to add the correct mixer_control line.

# Whole Document

Q: I've got a DAC Plus and want to add extra sensors. Is that possible?
A: Yes, the DAC Plus re-exposes Raspberry Pi signals so you can add sensors easily.

Q: What connectors does the DigiAMP Plus use for speakers?
A: The DigiAMP Plus uses CamdenBoss two-part connectors, specifically CTBP9350/2AO on the PCB.

Q: Do these audio boards work with the official 7-inch Raspberry Pi display?
A: Yes, use 5 mm male/female standoffs for the official 7-inch Raspberry Pi display.
