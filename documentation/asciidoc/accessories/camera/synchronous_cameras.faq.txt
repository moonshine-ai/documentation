# Synchronous Captures

Q: What's the difference between wired sync and software sync for cameras?
A: Software sync works over long distances without wires, with sub-millisecond accuracy.

Q: Can I sync a GS Camera and an HQ Camera together?
A: No, you can't synchronise a GS Camera and an HQ Camera together.

Q: I've got two HQ cameras close together. Do I need any extra hardware to sync them?
A: Yes, solder wires connecting the XVS and GND test points on each camera.

Q: Do I need to connect anything extra when syncing GS cameras?
A: Yes, you must also connect the XHS test point and bridge the MAS pad on sink cameras.

Q: I heard I need an external pull-up resistor for XVS. Is that still true?
A: No, external pull-up for XVS is no longer recommended; use the always-on property instead.

# Driver Configuration

Q: How do I set up the HQ camera as a source in the config file?
A: Add `dtoverlay=imx477,always-on,sync-source` to `/boot/firmware/config.txt`.

Q: What do I change in config.txt before adding the camera overlay lines?
A: Change `camera_auto_detect=1` to `camera_auto_detect=0` in the file.

Q: I've got both cameras on the same Pi. Do I need two overlay lines?
A: Yes, you need two separate dtoverlay lines, only one ending with `,cam0`.

Q: Can I switch which camera is the source and which is the sink without editing config files?
A: Yes, if they're on separate Pis, set the trigger_mode module parameter at runtime instead.

Q: How do I set the sink role at runtime instead of in config.txt?
A: Run `echo 2 | sudo tee /sys/module/imx477/parameters/trigger_mode` before starting the camera.

Q: Does the GS camera sink role get set in software like the HQ camera?
A: No, the GS Camera sink role is enabled by the MAS pin, not software configuration.

# Libcamera Configuration

Q: My cameras keep timing out before they all start. How do I fix that?
A: Edit a copy of the libcamera config file and set `camera_timeout_value_ms` to 60000.

Q: What's the timeout value I should set so cameras have enough time to start?
A: Set the timeout to 60000, which equals 60 seconds.

# Starting the Cameras

Q: Should I start the source or the sink camera first?
A: Start the sink first to ensure no frames are missed.

Q: How do I make sure both recordings are exactly the same length?
A: Use the `--frames` option to capture the same number of frames on both cameras.

Q: I'm using GS cameras and the recordings are different lengths. What's going on?
A: The GS source records one extra frame, so specify one fewer frame for the sink.

# Whole Document

Q: What even is XVS and why does it matter for syncing cameras?
A: XVS is the Vertical Sync pin that generates a pulse when a frame capture starts.

Q: I want to sync my cameras. Which method should I use, wired or software?
A: Software sync is recommended unless cameras are physically close, then wired sync works.

Q: Does synchronous capture work with Global Shutter cameras or just HQ cameras?
A: Both work, but for GS cameras an external trigger source is recommended instead.
