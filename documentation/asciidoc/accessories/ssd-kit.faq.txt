# About

Q: What's actually included in the Raspberry Pi SSD Kit?
A: It bundles an M.2 HAT+ with a Raspberry Pi SSD together.

Q: I've got a Pi 5 with an Active Cooler already on it. Can I still fit the SSD Kit?
A: Yes, it includes a stacking header, spacers, and screws for that.

Q: What's the stacking header size that comes with the kit?
A: The kit includes a 16 mm stacking header for installation.

Q: Is the SSD Kit just the drive, or does it come with the HAT too?
A: It bundles both the M.2 HAT+ and a Raspberry Pi SSD together.
