# Serial connections

Q: How do I wire up the Debug Probe to my Pico's UART pins?
A: Connect GND to pin 3, UART0_TX to pin 1, and UART0_RX to pin 2.

Q: Which GPIO pins are used for UART0 on the Pico by default?
A: UART0_TX is GP0 and UART0_RX is GP1 by default.

Q: I connected the Debug Probe but I don't know where the serial port shows up on my computer. Where do I look?
A: On Raspberry Pi it's `/dev/ttyACM0`; on macOS it appears as `/dev/cu.usbmodemXXXX`.

Q: I've never used minicom before. How do I install it?
A: Run `sudo apt install minicom` to install it on your system.

Q: What's the command to actually open the serial connection with minicom?
A: Run `minicom -b 115200 -o -D /dev/ttyACM0` to open the serial port.

Q: I'm stuck in minicom and can't figure out how to quit. Help!
A: Press CTRL-A followed by X to exit minicom.

Q: I want to test if serial is working. What's a good simple program to try?
A: Build and upload the "Hello World" example from the pico-examples tree.

Q: After I upload the Hello World example and open minicom, what should I see?
A: You should see "Hello, world!" printed to the console.

Q: I'm on Windows and my COM port number keeps changing every time I plug in. Is that normal?
A: The unique serial number makes COM port numbering sticky per device on Windows.

Q: What baud rate do I need to use when connecting to the Pico's serial output?
A: Use 115200 baud when opening the connection with minicom.

A: It relays UART traffic from your Pico and exposes it as a CDC UART on your computer.
