# About the Debug Probe

Q: What exactly is the Raspberry Pi Debug Probe, like what does it do?
A: It's a USB device providing both a UART serial port and SWD interface.

Q: Does the Debug Probe work on Windows and Mac, or just Linux?
A: It works on Windows, macOS, and Linux platforms without issue.

Q: I've heard of CMSIS-DAP but I don't really know what it means. Does the Debug Probe support it?
A: Yes, the Debug Probe is fully compatible with the CMSIS-DAP standard.

Q: Does it work with OpenOCD?
A: Yes, it works with OpenOCD and other tools supporting CMSIS-DAP.

Q: Can I update the firmware on the Debug Probe if I need to?
A: Yes, it has open source, easily upgradeable firmware.

# The Debug Probe

Q: What voltage does the Debug Probe run at?
A: The probe operates at 3.3V nominal I/O voltage.

Q: What cables come in the box with the Debug Probe?
A: You get a USB power cable and three different debug cables.

Q: I've got the Debug Probe and I'm trying to figure out which wire is which. What do the colours mean?
A: Orange is TX/SC output, black is GND, and yellow is RX/SD input.

Q: I want to connect the Debug Probe to a breadboard. Which cable should I use?
A: Use the JST-SH to 0.1-inch male header cable, intended for breadboards.

Q: My target board is powered separately. Is there anything I should watch out for before connecting the Debug Probe?
A: Connect GND first before any signal lines to avoid damaging the probe.

Q: The LEDs on my Debug Probe are off. Does that mean it's not working?
A: If DAP LEDs are off, OpenOCD has disconnected; red LED should still indicate power.

Q: How many LEDs does the Debug Probe have and what do they do?
A: It has five LEDs — one red power LED and four activity indicator LEDs.

Q: The two DAP LEDs just turned on. What does that mean?
A: OpenOCD switches both DAP LEDs on when the target is connected.
