# Install tools

Q: What do I actually need installed to use the Debug Probe?
A: You need OpenOCD and the GNU Project Debugger, GDB, installed.

Q: I'm on a Mac, what's the easiest way to get set up for debugging with the Pico?
A: Install the VS Code extension, which bundles OpenOCD, toolchains, GDB, and definitions.

Q: Does Raspberry Pi have an official VS Code extension for Pico development?
A: Yes, it bundles OpenOCD, Arm toolchains, GDB, and Pico register definitions.

Q: I don't want to use VS Code. Can I install these tools some other way?
A: Yes, you can manually install tools by following Appendix C in the guide.

Q: I'm on Windows and want to install everything manually. Is that a good idea?
A: No, manual installation of tools on Windows is not recommended.

Q: Where do I find instructions for setting up the Debug Probe stuff?
A: Chapter 3 of the Getting Started with Raspberry Pi Pico guide covers this.

Q: Does the VS Code extension work on regular Linux or just Raspberry Pi OS?
A: It's recommended for Raspberry Pi OS, most Linux variants, macOS, and Windows.

Q: What's OpenOCD? Do I need it just to use the Debug Probe?
A: Yes, OpenOCD is required along with GDB to use the Debug Probe.
