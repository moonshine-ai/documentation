# SDK Setup

Q: I'm on a Raspberry Pi and want to start coding for the Pico. What's the quickest way to get set up?
A: Run the setup script from the command line on your Raspberry Pi.

Q: Do I need to update my Pi before running that setup script?
A: Yes, make sure your Raspberry Pi OS is up to date first.

# Raspberry Pi Pico C/C++ SDK

Q: What IDEs can I use with the Pico C++ SDK? Like does it work with VS Code?
A: Yes, it works with Visual Studio Code, Eclipse, and CLion.

Q: I'm building for an Adafruit Feather RP2040, not a plain Pico. How do I tell CMake that?
A: Pass `-DPICO_BOARD=adafruit_feather_rp2040` to CMake when building.

Q: I want to build for Pico W. Is there anything extra I need to pass to CMake?
A: Pass `-DPICO_BOARD=pico_w` and optionally your WiFi credentials to CMake.

Q: Where can I find the actual SDK source code?
A: It's open source and available on the pico-sdk GitHub repository.

Q: I want example projects to look at. Where do I find those?
A: Check the pico-examples repository on GitHub for example projects.

# Your First Binaries

Q: The on-board LED on my Pico, which GPIO pin is it connected to?
A: It's connected to GP25 on the Pico, or WL_GPIO0 on Pico W.

Q: How do I get the blink program onto my Pico without writing any code?
A: Download the Blink UF2, hold BOOTSEL, plug in, then drag and drop it.

Q: My Pico isn't showing up on my computer. What should it appear as when I plug it in?
A: It mounts as a Mass Storage Device called RPI-RP2.

Q: I want to try the Hello World example. What do I need to see the output?
A: Install minicom and connect at 115200 baud to `/dev/ttyACM0`.

Q: What baud rate do I use with minicom for the Hello World example?
A: Use 115200 baud rate with minicom.

# Quick-start your own project

Q: What version of CMake do I need to build Pico projects?
A: You need at least CMake version 3.13.

Q: How do I get the Pico SDK onto my machine to start a project?
A: Clone it locally with `git clone https://github.com/raspberrypi/pico-sdk.git`.

Q: I built my project and now I've got a dot elf and a dot uf2 file. What's the difference?
A: The ELF loads via a debugger; the UF2 installs via drag and drop.

Q: My project uses USB for output instead of UART. Is there an example for that?
A: Yes, check the hello-usb example for default USB stdout output.

Q: I want to know what boards are already defined in the SDK. Where do I look?
A: Check the boards include directory on GitHub; there's a header per board.
