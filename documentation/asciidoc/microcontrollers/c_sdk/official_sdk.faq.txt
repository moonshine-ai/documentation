# Raspberry Pi Pico C/C++ SDK

Q: Can I use Visual Studio Code with the Pico C SDK or do I need something else?
A: Yes, the C SDK works with Visual Studio Code, Eclipse, and CLion.

Q: Where do I even start with the C SDK for Pico? Like what do I download first?
A: Download the C SDK and examples, then check the getting started documentation.

Q: I want to code in C for my Pico W and connect it to WiFi. Is there a guide for that?
A: Yes, there's a guide called "Connecting to the Internet with Raspberry Pi Pico W."

Q: Is the Pico SDK source code available somewhere, like on GitHub?
A: Yes, the SDK source code is open source on the pico-sdk GitHub repository.

Q: I'm not building for a regular Pico, I've got an Adafruit Feather RP2040. How do I set that up?
A: Pass `-DPICO_BOARD=adafruit_feather_rp2040` to CMake when building your application.

Q: How do I build stuff for the Pico W instead of the regular Pico?
A: Pass `-DPICO_BOARD=pico_w` to CMake when building your application.

Q: I need to connect my Pico W to my WiFi network during the build. How do I pass in my password?
A: Pass `-DWIFI_SSID="Your Network"` and `-DWIFI_PASSWORD="Your Password"` to CMake.

Q: Where can I find example projects for the Pico C SDK?
A: Example projects are available in the pico-examples repository on GitHub.

Q: Can I just use the command line with the C SDK or do I need an IDE?
A: You can use the C SDK from the command line or from popular IDEs.

Q: Where do I find a list of supported boards for the Pico SDK?
A: Check the `boards/` directory in the Raspberry Pi Pico SDK on GitHub.
