# SDK Setup

Q: How do I get started with the C++ SDK for Pico? Is there a guide somewhere?
A: There's a full getting started document available from Raspberry Pi's official docs.

Q: I'm developing on a Raspberry Pi itself. Is there a quick way to set up the toolchain?
A: Run the setup script from the command line to quickly set up the toolchain.

Q: Where do I find that setup script for Pico development on a Raspberry Pi?
A: It's available on GitHub under the raspberrypi pico-setup repository as pico_setup.sh.

Q: Do I need to update my Raspberry Pi before running the setup script?
A: Yes, make sure your Raspberry Pi OS is up to date before running it.

Q: I haven't updated my Pi in a while. Does that matter before I run the Pico setup script?
A: Yes, you should update your OS before running the Pico setup script.
