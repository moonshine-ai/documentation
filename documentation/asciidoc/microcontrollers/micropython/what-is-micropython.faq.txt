# What is MicroPython?

Q: What actually is MicroPython, like in plain terms?
A: It's a full Python 3 implementation that runs directly on embedded hardware.

Q: Does MicroPython work on the Raspberry Pi Pico?
A: Yes, the Pico has its own MicroPython port with low-level hardware access modules.

Q: I've heard of the REPL but I don't know what it is. What's it do?
A: It's an interactive prompt letting you execute commands immediately via USB Serial.

Q: Can I access the Pico's hardware directly from MicroPython, like the pins and stuff?
A: Yes, the Pico port includes modules for accessing low-level chip-specific hardware.

Q: Does MicroPython have a filesystem built in?
A: Yes, MicroPython includes a built-in filesystem.

Q: Is MicroPython the full version of Python or is it stripped down?
A: It's a full implementation of the Python 3 programming language.

Q: Where do I go if I've got questions about MicroPython that aren't about the Pico specifically?
A: Check the MicroPython Wiki or the MicroPython Forums for broader community support.
