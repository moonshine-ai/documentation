# Which hardware am I running on?

Q: How do I figure out if my MicroPython code is running on a Pico or a Pico W?
A: Check indirectly via network functionality or inspect the sys.implementation details.

Q: There's no direct way to tell what board I'm on in MicroPython, right? So what do I do instead?
A: Check for WLAN in the network module or inspect sys.implementation._machine string.

Q: I want to know if my firmware was built for the Pico W. How do I check that?
A: Import sys and check if "Pico W" appears in sys.implementation._machine string.

Q: What's that network trick for detecting if I've got a Pico W?
A: Import network and check if hasattr returns true for the WLAN attribute.

Q: I'm writing a MicroPython script and need it to behave differently on Pico W. How do I detect which board I'm on?
A: Use network module to check for WLAN, or inspect sys.implementation._machine for "Pico W".

Q: If I do import sys and check sys.implementation, what does it actually show me?
A: It shows the name, version, machine type, and whether it's compiled for Pico W.

Q: Does MicroPython have a built-in way to just directly tell you what hardware it's running on?
A: No, there's no direct method; you must check indirectly through network or sys module.
