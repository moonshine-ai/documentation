# Drag-and-Drop MicroPython

Q: How do I actually get MicroPython onto my Pico? Like what's the process?
A: Download the UF2 file, then drag and drop it onto your Pico.

Q: I've got a Pico W, not a regular Pico. Do I need a different file to install MicroPython?
A: Yes, there's a separate UF2 file specifically for the Pico W.

Q: My Pico isn't showing up when I plug it in. What button do I need to hold?
A: Hold the BOOTSEL button while connecting the USB cable to your computer.

Q: When do I let go of the BOOTSEL button? Just whenever or is there a specific time?
A: Release it once your Pico appears as a Mass Storage Device called RPI-RP2.

Q: After I drag the file over, does anything happen automatically or do I have to do something else?
A: Your Pico reboots automatically and you're then running MicroPython.

Q: I've got a Pico 2 W. Is there a MicroPython file for that specific board?
A: Yes, there's a dedicated UF2 download for the Pico 2 W board.

Q: Once MicroPython is installed, how do I actually start using it?
A: Access the REPL via USB Serial after your Pico reboots.

Q: I don't have a regular Pico or Pico W, I've got some other RP2040 board. Can I still get MicroPython?
A: Other RP2040 and RP2350 board distributions are on the MicroPython download page.

Q: I want to use Wi-Fi on my Pico W with MicroPython. Where do I find out how to do that?
A: Check the guide called Connecting to the Internet with Raspberry Pi Pico W-series.

Q: What's the easiest way to learn how to program my Pico in MicroPython if I'm just starting out?
A: The Raspberry Pi Pico-series Python SDK book has step-by-step instructions for beginners.

Q: Can I use Thonny to program my Pico in MicroPython?
A: Yes, the Pico Python SDK book covers programming with the Thonny IDE.
