# Where can I find documentation?

Q: Where do I go to learn about using MicroPython on a Raspberry Pi Pico?
A: Check the Raspberry Pi Pico Python SDK document at pip.raspberrypi.com.

Q: I've got a Pico W and I want to connect it to the internet using MicroPython. Is there a guide for that?
A: Yes, "Connecting to the Internet with Raspberry Pi Pico W" covers MicroPython and C++.

Q: What's the RP2 Quick Reference and do I need it?
A: It's the official MicroPython documentation specifically for the RP2XXX microcontroller port.

Q: I'm trying to use the rp2 module in my MicroPython code but I don't know what it does. Where do I look?
A: The RP2 Library page at docs.micropython.org covers the rp2 module officially.

Q: I just got a Pico and want to start coding in Python. Where's the best place to start reading?
A: Start with the Raspberry Pi Pico Python SDK for a MicroPython environment overview.

Q: Are there official Raspberry Pi docs for MicroPython or is it all third-party stuff?
A: Raspberry Pi publishes official SDK and internet connectivity guides for MicroPython.
