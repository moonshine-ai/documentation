# What is MicroPython?

Q: What even is MicroPython? Is it just a cut-down version of Python?
A: It's a full Python 3 implementation that runs directly on embedded hardware.

Q: I've heard about the REPL thing — what does that actually do on the Pico?
A: It gives you an interactive prompt to execute commands immediately via USB Serial.

Q: Does MicroPython let you access the hardware stuff on the Pico, like the pins and chips?
A: Yes, the Pico port includes modules for accessing low-level chip-specific hardware.

# Drag-and-Drop MicroPython

Q: I want to get MicroPython on my Pico — what's the easiest way to do that?
A: Download the UF2 file and drag and drop it onto your Pico.

Q: I've got a Pico W, not a regular Pico. Do I need a different file?
A: Yes, download the Pico W-specific UF2 file from the MicroPython website.

Q: How do I actually put the UF2 file on my Pico? Like what are the steps?
A: Hold BOOTSEL while plugging in USB, release it, then drag the UF2 onto RPI-RP2.

Q: When I hold the BOOTSEL button and plug in my Pico, what should I see on my computer?
A: Your Pico should appear as a Mass Storage Device called RPI-RP2.

Q: After I drop the UF2 file onto my Pico, what happens next?
A: Your Pico reboots and you're now running MicroPython, access REPL via USB Serial.

Q: I've got a Pico 2 W — there's a UF2 for that specifically, right?
A: Yes, there's a separate UF2 file available specifically for the Pico 2 W.

Q: I've got some other RP2040 board that's not an official Pico. Can I still use MicroPython?
A: Yes, other RP2040 and RP2350 board distributions are on the MicroPython download page.

# Where can I find documentation?

Q: Where's the best place to learn how to use MicroPython on my Pico?
A: The Raspberry Pi Pico Python SDK book covers MicroPython for Raspberry Pi microcontrollers.

Q: I want to get my Pico W connected to the internet. Is there a guide for that?
A: Yes, "Connecting to the Internet with Raspberry Pi Pico W" covers that in C++ and MicroPython.

# Which hardware am I running on?

Q: How do I figure out in my code whether I'm running on a Pico or a Pico W?
A: Check indirectly by seeing if network functionality is included in your MicroPython firmware.

Q: Is there a direct way in MicroPython to check if I'm on a Pico W?
A: No, there's no direct method; you check indirectly via network or sys module.

Q: What's that sys module trick to tell which board my MicroPython was compiled for?
A: Import sys and check sys.implementation._machine for the "Pico W" string.

Q: I ran the sys thing and got a long output. How do I know if it's a Pico W firmware?
A: If "Pico W" appears in sys.implementation._machine, it was compiled for Pico W.
