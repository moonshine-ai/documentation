# RP2040

Q: What's the RP2040 and what's it used for?
A: It's a dual-core microcontroller for low-cost, low-power embedded control applications.

Q: What boards actually use the RP2040 chip?
A: Pico, Pico W, Pico H, Pico WH, and other third-party RP2040-based boards.

Q: How big is the RP2040 chip physically?
A: It's packaged in a seven by seven millimeter QFN-56 form factor.

# RP2040 naming

Q: Why is it called RP2040? What do those numbers even mean?
A: RP means Raspberry Pi silicon, two cores, Cortex-M0+, 264 kB RAM, no built-in flash.

Q: So the "2" in RP2040 means it has two cores?
A: Yes, the two refers to the number of processor cores on the chip.

Q: I heard RP2040 has no storage built in. Is that true, and what does the name tell me about that?
A: Yes, the last zero means no on-board flash memory is included.

Q: What does the "4" in RP2040 stand for?
A: It represents 264 kB of on-chip SRAM, expressed as a logarithmic factor.

# RP2040 features

Q: How fast does the RP2040 run?
A: The dual-core Cortex-M0+ processor runs at up to 133 MHz.

Q: How much RAM does the RP2040 have?
A: It has 264 kB of on-chip SRAM split across six independent banks.

Q: There's no flash built in — so where does my program actually live?
A: Programs run from external flash memory over a fast QSPI interface with caching.

Q: What's PIO on the RP2040? I keep seeing it mentioned.
A: It's a programmable subsystem with two blocks and eight state machines for custom peripherals.

Q: Does the RP2040 support USB?
A: Yes, it has a built-in USB 1.1 controller with both host and device support.

Q: How many PWM channels does the RP2040 have?
A: It has sixteen PWM channels built in.

Q: What serial communication options are on the RP2040?
A: It has two UARTs, two SPI controllers, and two I2C controllers built in.

Q: Can the RP2040 read temperature or voltage sensors?
A: Yes, it has a four-channel ADC with 12-bit conversion and an on-board temperature sensor.

# Internal temperature sensor

Q: Can I use the RP2040's built-in temperature sensor for accurate readings?
A: Not without calibration; it's low-resolution and unlikely to be accurate uncalibrated.

Q: Why is the temperature sensor on the RP2040 so inaccurate?
A: Accuracy depends on knowing the ADC reference voltage, which RP2040 doesn't provide internally.

Q: Does the RP2040 temperature sensor go up or down in voltage as it gets hotter?
A: The sensor voltage falls as temperature rises.

Q: How do I get an accurate voltage reference for the RP2040 temperature sensor?
A: Measure it externally or provide an external precision voltage reference.

# Sleep mode power

Q: How much power does the RP2040 use when it's in deep sleep?
A: It typically draws around 180 microamps even in deep sleep.

Q: I need my project to use as little power as possible. What's the best approach for the RP2040?
A: Completely power off the system or the RP2040 part rather than relying on sleep mode.

Q: Does temperature affect how much current the RP2040 draws in sleep?
A: Yes, sleep current varies nonlinearly with temperature.

# RP2040-based boards

Q: Can I use the Raspberry Pi Pico design files to make my own board?
A: Yes, Raspberry Pi grants permission to use, copy, modify, and distribute them freely.

Q: Where can I talk to people about third-party RP2040 boards?
A: The Raspberry Pi forums have a section for discussing third-party RP2040-based boards.

Q: Are there any reference designs available if I want to build my own RP2040 board?
A: Yes, there's a Minimal Viable Board and a VGA Carrier Board design available.

Q: I want to make an RP2040 project with a screen. Is there a reference design for that?
A: Yes, the VGA Carrier Board design is a reference for multimedia use with Pico.
