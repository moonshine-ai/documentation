# Manually start and stop Connect

Q: How do I turn on Connect from the command line?
A: Run `rpi-connect on` to start Connect or Connect Lite.

Q: I want to shut down Connect without rebooting. How do I do that?
A: Run `rpi-connect off` to stop Connect from the command line.

Q: What's the command to start Connect Lite specifically?
A: Connect Lite uses the same `rpi-connect on` command as regular Connect.

Q: I accidentally left Connect running and want to turn it off. What do I type?
A: Type `rpi-connect off` in the terminal to stop Connect running.

Q: Wait, is it the same command to start both Connect and Connect Lite?
A: Yes, `rpi-connect on` starts both Connect and Connect Lite.
