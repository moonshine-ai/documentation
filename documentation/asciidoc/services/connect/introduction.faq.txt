# Introduction

Q: What even is Raspberry Pi Connect? Like what does it actually do?
A: It lets you securely access your Raspberry Pi from anywhere worldwide.

Q: Do I need to install Connect or does it come already on my Pi?
A: Connect comes pre-installed on Raspberry Pi OS Desktop and Full versions.

Q: I'm running Raspberry Pi OS Lite. Do I get Connect on that too?
A: Yes, but only the Lite variant, which supports remote shell access only.

Q: Wait, so the Lite version of Connect can't do screen sharing?
A: Correct, the Lite Connect variant only supports remote shell access.

Q: How do I actually use Connect once it's set up? Where do I go?
A: Visit connect.raspberrypi.com to access your Pi's desktop or shell.

Q: Is Connect secure? I don't want random people accessing my Pi.
A: Yes, Connect uses a secure encrypted connection between your Pi and browser.

Q: My Pi and browser can't connect directly. Does that mean it just won't work?
A: No, Connect falls back to a relay server when a direct connection fails.

Q: I've got an older Pi running an older OS. Will Connect work on it?
A: Connect requires Raspberry Pi OS Bookworm or later to work.

Q: What's the first thing I need to do to get Connect working?
A: You need to link your device with a Connect account first.

Q: I heard Connect uses a relay server sometimes. Does Raspberry Pi store my data then?
A: Only metadata needed to operate Connect is retained in relay situations.
