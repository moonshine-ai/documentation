# Compute Module 4S datasheet

Q: What even is the CM4S? How is it different from the regular CM4?
A: CM4S has CM4 internals but uses the older DDR2-SODIMM form factor.

Q: Does the CM4S use the same connector as the older Compute Modules?
A: Yes, CM4S uses the DDR2-SODIMM form factor like CM1, CM3, and CM3+.

# Compute Module 3+ datasheet

Q: Is the CM3+ still being supported or is it discontinued?
A: CM3+ is a supported product with end-of-life no earlier than January 2028.

# Compute Module 1 and Compute Module 3 datasheet

Q: Are CM1 and CM3 still being made or are they getting discontinued soon?
A: CM1 and CM3 are supported with end-of-life no earlier than January 2026.

Q: I'm moving from a CM1 to a CM4 for my project. Is there any migration guide?
A: Yes, a white paper exists specifically to help developers migrate from CM1 or CM3 to CM4.

Q: I need the schematics for my original Compute Module 1. Where do I find those?
A: CM1 schematics are available as a linked document at pip.raspberrypi.com.

# Compute Module IO Board schematics

Q: What's the difference between the CMIO Version 1 and Version 3?
A: Version 1 only supports CM1, while Version 3 supports CM1, CM3, CM3+, and CM4S.

Q: I've got a CM3+ and I'm looking for a compatible IO board. Will the standard CMIO work?
A: Yes, CMIO Version 3 is compatible with CM3+.

Q: Someone mentioned CMIO3 in a forum post. What does that mean exactly?
A: CMIO3 is shorthand for Compute Module IO Board Version 3.

# Compute Module Camera/Display Adapter Board schematics

Q: I want to connect a camera to my Compute Module. Is there an adapter board for that?
A: Yes, the Compute Module Camera/Display Adapter Board provides camera and display interfaces.

Q: Where do I find the design documents for the camera and display adapter board?
A: Design documents for CMCDA Version 1.1 are available at pip.raspberrypi.com.
