# Localise your Raspberry Pi

Q: How do I change the language on my Raspberry Pi?
A: Use the raspi-config tool to configure your UI language settings.

Q: My keyboard's typing the wrong characters. How do I fix the layout?
A: You can change the keyboard layout using the raspi-config tool.

Q: I'm in a different time zone and the clock's wrong. How do I fix that?
A: Use raspi-config to configure the correct time zone for your Raspberry Pi.

Q: Is there like one tool that handles all the language and region stuff, or do I have to go digging around?
A: Yes, raspi-config handles language, keyboard layout, and time zone all in one place.

Q: I just set up my Pi and everything's in the wrong language. What do I do?
A: Open raspi-config and use it to set your preferred UI language.

Q: What's raspi-config? Is that what I use to change regional settings?
A: Yes, raspi-config is the tool for changing language, keyboard, and time zone.
