# Change a user's password

Q: How do I change my password on the Raspberry Pi?
A: Use raspi-config or run the passwd command in the terminal.

Q: I want to change my password but I don't know where to start. Is there like a menu option for that?
A: Run raspi-config, then select option 2 and follow the instructions.

Q: What's the quickest command to change my password without going through menus?
A: Just run passwd in the terminal to change your current user's password.

# Add a user

Q: How do I add a new user account to my Pi?
A: Run sudo adduser followed by the username you want to create.

Q: I added a new user but they can't run sudo commands. How do I fix that?
A: Run usermod to add them to groups including sudo, adm, and others listed.

Q: Where does the new user's home folder end up when I create an account?
A: It's created at /home/ followed by the new username you chose.

Q: How do I check if the permissions actually worked after I added the new user?
A: Run sudo su followed by the username; success means permissions are configured correctly.

Q: My new user's keyboard is typing the wrong characters. What's going on?
A: Sign in as that user and run sudo raspi-config nonint update_labwc_keyboard to fix it.

# Delete a user

Q: I want to completely remove a user and all their files. What do I run?
A: Run sudo deluser with the remove-home option to delete user and their directory.

Q: Can I delete a user but keep their home folder just in case?
A: Yes, run deluser without the remove-home option to preserve their home directory.

# Change the default user

Q: How do I make a different user log in automatically when the Pi boots up?
A: Run raspi-config, select option 1 Boot/Auto login, then reboot your Pi.

Q: I changed the auto login user but nothing happened. Did I do something wrong?
A: You need to reboot your Pi after changing the setting in raspi-config.
