# Set up a headless Raspberry Pi

Q: What even is a headless Raspberry Pi? Like what does that mean?
A: It's a Pi running without a monitor, keyboard, or mouse attached.

Q: I don't have a monitor for my Pi. How do I still control it?
A: Connect it to a network and access it remotely over SSH.

Q: I've got my Pi on the network but I want a proper desktop. Can I do that without a monitor?
A: Yes, connect via SSH first, then enable VNC using raspi-config.

Q: My Pi's taking forever to connect to WiFi on first boot. Is that normal?
A: Yes, it can take up to five minutes to boot and connect first time.

# Connect to a wired network

Q: Can I just plug my headless Pi into ethernet and it'll connect automatically?
A: Yes, plug it in via Ethernet and it connects to the network automatically.

Q: My Pi model doesn't have an ethernet port. Can I still use a wired connection?
A: Yes, you can use an Ethernet adapter if your Pi lacks a built-in port.

# Connect to a wireless network

Q: How do I get my headless Pi onto WiFi if I can't plug in a keyboard?
A: Enter your SSID and password in the Wi-Fi tab in Raspberry Pi Imager.

Q: I heard you used to be able to use a wpa_supplicant file for WiFi setup. Does that still work?
A: No, that functionality isn't available from Raspberry Pi OS Bookworm onwards.

Q: Will my Pi work on a 5 GHz WiFi network?
A: Not always — some boards and adapters don't support 5 GHz, check your documentation.

# Remote access

Q: How do I turn on SSH before I even boot the Pi for the first time?
A: Enable SSH in the Remote Access tab in Raspberry Pi Imager before imaging.

Q: I don't want to use Imager. Is there another way to enable SSH on a fresh install?
A: Create a file named `ssh` at the root of the bootfs partition on the SD card.

Q: I just want a graphical desktop on my headless Pi. What do I do after SSH-ing in?
A: Use raspi-config after connecting via SSH to enable VNC for a graphical desktop.

# Configure a user manually

Q: What's this userconf.txt file I need to create? What goes in it?
A: One line containing your username, a colon, then an encrypted password.

Q: What characters am I allowed to use in my Pi username?
A: Lowercase letters, digits, and hyphens only, starting with a letter, max 31 characters.

Q: How do I make that encrypted password for the userconf.txt file?
A: Run `openssl passwd -6` on another computer and enter your desired password.

Q: I'm setting up userconf.txt but I don't know how to encrypt my password. Do I need special software?
A: Use OpenSSL on another computer — run `openssl passwd -6` in a terminal.
