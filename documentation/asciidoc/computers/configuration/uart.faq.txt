# Configure UARTs

Q: What's the difference between PL011 and mini UART on the Raspberry Pi?
A: PL011 is broadly 16550-compatible; mini UART has a reduced feature set.

Q: I connected my Pi's UART to a 5V system and now it's acting weird. What happened?
A: All Raspberry Pi UARTs are 3.3V only; connecting to 5V causes damage.

Q: Can I use my Pi's serial pins with a 5V device at all?
A: Yes, use an adapter or a low-cost USB to 3.3V serial adapter.

# Raspberry Pi Zero, 1, 2 and 3

Q: How many UARTs does a Raspberry Pi 3 have?
A: It has two UARTs: UART0 which is PL011, and UART1 which is mini UART.

# Raspberry Pi 4 and 400

Q: Does the Pi 4 have more serial ports than the Pi 3?
A: Yes, Pi 4 has six UARTs total, though four extra PL011s are disabled by default.

Q: I've got a Pi 400 and need more than two serial ports. Is that possible?
A: Yes, four additional PL011 UARTs exist but are disabled by default.

# Raspberry Pi 5

Q: Does the Pi 5 have a mini UART like older Pi models?
A: No, Raspberry Pi 5 does not have a mini UART.

Q: How many UARTs does the Pi 5 have?
A: Raspberry Pi 5 has five UARTs, all PL011 type.

# CM1, CM3, CM3+ and CM4

Q: I'm using a Compute Module and can't find any serial ports. Are they disabled?
A: Yes, on all Compute Module models UARTs are disabled by default.

Q: How do I enable a UART on a Compute Module and pick which GPIO pins to use?
A: Use a Device Tree overlay in config.txt, specifying GPIO pins like txd1_pin and rxd1_pin.

# Primary UART

Q: Which GPIO pins does the primary UART use on a regular Pi?
A: The primary UART uses GPIO 14 for transmit and GPIO 15 for receive.

Q: Where does the primary UART show up on a Pi 5?
A: On Raspberry Pi 5, the primary UART appears on the Debug header.

Q: What's GPIO 14 called on the actual pin header?
A: GPIO 14 is pin 8, and GPIO 15 is pin 10 on the GPIO header.

# Secondary UART

Q: What's the secondary UART used for by default?
A: By default it's connected to the Bluetooth side of the wireless LAN and Bluetooth controller.

Q: Is the secondary UART available on the GPIO pins?
A: No, the secondary UART is not normally present on the GPIO connector.

# Primary and Secondary UART

Q: On a Pi 3, which UART is the primary one and which handles Bluetooth?
A: On Pi 3, UART1 is primary and UART0 handles Bluetooth.

Q: What Linux device file do I use to talk to the primary UART?
A: Use /dev/serial0, which is a symbolic link to the primary UART.

Q: What's /dev/ttyAMA0 exactly?
A: It's the first PL011, which is UART0.

Q: I'm on Bookworm and /dev/serial1 doesn't exist. Is that normal?
A: Yes, due to Bookworm changes serial1 doesn't exist by default.

Q: How do I bring back /dev/serial1 on Bookworm?
A: Add dtparam=krnbt=off to config.txt to re-enable serial1.

Q: What's /dev/ttyAMA10 for?
A: It's the Raspberry Pi 5 Debug UART device.

# Mini-UART and CPU Core Frequency

Q: My mini UART baud rate keeps changing on its own. What's going on?
A: Mini UART clock is linked to VPU core clock, so baud rate changes when core clock changes.

Q: How do I get the mini UART working properly without it going haywire?
A: Fix the VPU core clock frequency using enable_uart or core_freq in config.txt.

Q: If I set enable_uart equals 1, what clock speed does the core get locked to?
A: The core clock gets fixed to 250MHz, unless force_turbo=1 is set.

Q: Is the mini UART on by default?
A: No, mini UART is disabled by default if it's the primary or when Bluetooth is disabled.

# Disabling the Linux Serial Console

Q: I want to use the serial pins for my own project but they seem to be running a Linux console. How do I stop that?
A: Use raspi-config, go to Interface Options, then Serial Port, and disable the login shell.

Q: Do I need to reboot after turning off the serial console in raspi-config?
A: Yes, exit raspi-config and reboot for the changes to take effect.

# Enabling early console for Linux

Q: My Pi is crashing really early on boot and I can't see any error messages. Is there a way to get logs sooner?
A: Enable earlycon support by adding the appropriate option to cmdline.txt.

Q: What baud rate does earlycon use by default?
A: The baudrate defaults to 115200bps.

Q: I picked the wrong earlycon option and now my Pi won't boot. Is that a known thing?
A: Yes, selecting the wrong early console option can prevent the Pi from booting.

Q: Where does earlycon output show up on a Pi 5?
A: On Pi 5, earlycon output only appears on the 3-pin debug connector.

# UARTs and Device Tree

Q: I want to free up the main UART from Bluetooth on my Pi. What overlay do I use?
A: Use the disable-bt overlay, which makes UART0 the primary and disables Bluetooth.

Q: What does the miniuart-bt overlay actually do?
A: It switches Bluetooth to use mini UART and makes PL011 UART0 the primary UART.

Q: If I use miniuart-bt, do I need to do anything else?
A: Yes, also set VPU core clock to a fixed frequency using force_turbo=1 or core_freq=250.

Q: How do I enable the extra UARTs on a Pi 4?
A: Add uart2, uart3, uart4, or uart5 overlays in config.txt to enable them.

Q: If the overlay file is called disable-bt-overlay.dts, what do I actually write in config.txt?
A: Write dtoverlay=disable-bt, dropping the -overlay.dts part of the filename.

Q: After adding disable-bt, do I need to do anything else?
A: Yes, disable the modem service with sudo systemctl disable hciuart.

# PL011 and mini-UART

Q: Why does my mini UART keep dropping characters at higher speeds?
A: Mini UART has smaller FIFOs and no flow control, making it prone to losing characters.

Q: What features is the mini UART missing compared to PL011?
A: Mini UART lacks break detection, framing error detection, parity bit, and receive timeout interrupt.

Q: Does the Pi's PL011 support DCD or DTR signals?
A: No, neither mini UART nor the BCM2835 PL011 implementation supports DCD, DSR, DTR, or RI.
