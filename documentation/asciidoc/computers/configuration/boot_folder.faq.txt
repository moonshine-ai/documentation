# `boot` folder contents

Q: Where does Raspberry Pi OS keep its boot files?
A: Boot files are on the SD card's first FAT-formatted partition.

Q: I upgraded to Bookworm and now my boot partition path seems different. What happened?
A: Since Bookworm, the boot partition moved from `/boot/` to `/boot/firmware/`.

Q: What file system does the boot partition use?
A: The boot partition is formatted with the FAT file system.

# `bootcode.bin`

Q: What does bootcode.bin actually do?
A: It does basic setup then loads one of the `start*.elf` files.

Q: I've got a Pi 4 and I heard bootcode.bin isn't used on it. Is that true?
A: Yes, Pi 4 and 5 replaced it with boot code stored in onboard EEPROM.

# `start*.elf`

Q: What's the difference between start.elf and start_x.elf?
A: `start_x.elf` includes additional codecs; `start.elf` is just the basic firmware.

Q: What's start_cd.elf and when would I use it?
A: It's a cut-down firmware that removes codec, 3D, and debug support, used when `gpu_mem=16` is set.

Q: Does the Pi 5 use those elf firmware files?
A: No, Pi 5 firmware is self-contained within the bootloader EEPROM instead.

Q: I've got a Pi 4. Do I use the same elf files as a Pi 3?
A: No, Pi 4-series uses its own files like `start4.elf` and `start4x.elf`.

Q: What's start_db.elf for?
A: It's the firmware version used specifically for debugging purposes.

# `fixup*.dat`

Q: What are those fixup.dat files in my boot folder?
A: They're linker files that come in matched pairs with the `start*.elf` files.

# `cmdline.txt`

Q: What's cmdline.txt used for?
A: It holds the kernel command line that gets passed into the kernel at boot.

# `config.txt`

Q: What's config.txt for on a Raspberry Pi?
A: It contains many configuration parameters for setting up your Raspberry Pi.

Q: Does the Pi 5 need anything special in config.txt?
A: Yes, Pi 5 requires that config.txt exists and is not empty.

# `issue.txt`

Q: What's in the issue.txt file in the boot partition?
A: It contains the date and git commit ID of the distribution.

# `initramfs*`

Q: What does the initramfs file do?
A: It loads a temporary root file system into memory before the real one mounts.

Q: How do I turn on initramfs support on Bookworm?
A: Configure it in `config.txt` using the `auto_initramfs` keyword.

Q: Does Raspberry Pi OS come with an initramfs file included?
A: Yes, since Bookworm, Raspberry Pi OS includes an `initramfs` file by default.

# `ssh` or `ssh.txt`

Q: How do I enable SSH on my Pi without even booting into the desktop?
A: Just put a file called `ssh` or `ssh.txt` in the boot partition; contents don't matter.

Q: Does the ssh file in the boot folder need anything written in it?
A: No, even a completely empty file is enough to enable SSH at boot.

Q: Is SSH on by default on Raspberry Pi OS?
A: No, SSH is disabled by default unless the `ssh` file is present at boot.

# Device Tree blob files (`*.dtb`)

Q: What are those .dtb files in my boot folder?
A: They contain hardware definitions for various Raspberry Pi models.

Q: How does the Pi know which hardware config to load at startup?
A: The device tree blob files set up the kernel based on the detected Pi model.

# Kernel files (`*.img`)

Q: Which kernel file does a Pi 4 use?
A: Pi 4 uses `kernel7l.img` for 32-bit or `kernel8.img` for 64-bit.

Q: I've got a Pi 5. Which kernel image does it use?
A: Pi 5 uses `kernel_2712.img`, which is the Pi 5-optimized 64-bit kernel.

Q: What kernel file does a Pi Zero use?
A: A Pi Zero uses `kernel.img` with the BCM2835 processor.

Q: I ran lscpu and it says armv7l. Does that mean I'm running 32-bit?
A: Yes, `armv7l` means a 32-bit kernel; `aarch64` means 64-bit.

Q: Can a Pi 2 run a 64-bit kernel?
A: Only later Pi 2 revisions with BCM2837 can; earlier BCM2836 versions cannot.

# `overlays` folder

Q: What's the overlays folder in my boot partition for?
A: It holds Device Tree overlays for configuring hardware like third-party sound boards.

Q: How do I actually use one of those overlays for extra hardware?
A: Add the relevant entry to `config.txt` to select the overlay you need.

# Whole Document

Q: I just got a new Pi and I'm confused — what's actually happening when it boots up?
A: The SoC loads boot files from the FAT partition to start processors before Linux boots.

Q: Where do I go if I want to change boot settings on my Raspberry Pi?
A: Edit `config.txt` in the boot partition; see the config.txt documentation for details.

Q: I've got a Pi 4 versus a Pi 3 — are the boot files the same on both?
A: Pi 4 uses its own `start4*.elf` files and no `bootcode.bin`, unlike Pi 3.
