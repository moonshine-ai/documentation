# Legacy Boot Options

Q: What does setting `start_x=1` actually do in config.txt?
A: It's a shortcut that sets start_file to start_x.elf and fixup_file to fixup_x.dat.

Q: I've got a Pi 4 and set `start_x=1` — will it use different files than other models?
A: Yes, on Pi 4 it uses start4x.elf and fixup4x.dat if those files are present.

Q: What's the default baud rate for the UART on a Raspberry Pi?
A: The default initial UART baud rate is 115200.

Q: My display detection is wrong on first boot but works fine after a reboot without cutting power. What's that about?
A: Try adding a `bootcode_delay` to let the monitor finish starting up before EDID is read.

Q: What's the default UART clock frequency on the Pi?
A: The default initial UART clock frequency is 48 MHz, or 48000000.

Q: I'm doing bare-metal stuff and want to load the kernel at address zero. How do I do that?
A: Set `kernel_old=1` and the kernel will load to memory address 0x0.

Q: Where does a 64-bit kernel get loaded by default?
A: By default, 64-bit kernels are loaded to memory address 0x200000.

Q: I'm using `arm_control` to enable 64-bit — is that still the right way to do it?
A: No, `arm_control` is deprecated; use `arm_64bit` instead to enable 64-bit kernels.

Q: My SD card takes a while to be ready before Linux boots. Is there a way to add a delay?
A: Yes, use `boot_delay` to force a wait in seconds before the kernel loads.

Q: How do I calculate the total boot delay in milliseconds?
A: Total delay in milliseconds equals 1000 times boot_delay plus boot_delay_ms.

# Legacy Overclocking Options

Q: Can I stop my Pi 2 or 3 from ever going into turbo mode?
A: Yes, set `disable_auto_turbo` flag to prevent the GPU from entering turbo mode.

Q: What does `never_over_voltage` actually do — is it reversible?
A: It permanently sets a one-time programmable memory bit preventing overvoltage; it's not reversible.

# Legacy Conditional Filters

Q: I've got a Pi 4 with two HDMI ports and want different resolutions on each. How do I set that up in config.txt?
A: Use the `[HDMI:0]` and `[HDMI:1]` filters to apply different settings to each port.

Q: Is there another way to set HDMI settings per-port without using those filter sections?
A: Yes, use the `variable:index` syntax like `hdmi_group:0=2` and `hdmi_group:1=2`.

# Legacy Memory Options

Q: How much GPU memory does a Pi get by default?
A: Default is 64 MB for Pis with less than 1 GB RAM, and 76 MB for 1 GB or more.

Q: Will giving my Pi more GPU memory make 3D stuff run faster?
A: No, more GPU memory doesn't improve performance and can actually harm it.

Q: I've got Pi 4 — can I use less GPU memory than on older models?
A: Yes, Pi 4's 3D component has its own MMU, so a smaller gpu_mem value is fine.

Q: I've got a bunch of different Pis sharing the same SD card. Do I have to edit config.txt each time I swap?
A: No, use `gpu_mem_256`, `gpu_mem_512`, or `gpu_mem_1024` to set RAM-specific values automatically.

Q: Does the camera use GPU memory? Should I increase gpu_mem for camera stuff?
A: No, the camera stack uses Linux CMA memory, so increasing GPU memory won't help.

Q: What's the minimum value I can set gpu_mem to?
A: The minimum is 16 MB, but that disables certain GPU features.

Q: Does gpu_mem do anything on a Raspberry Pi 5?
A: No, Raspberry Pi 5 doesn't allocate GPU memory on behalf of the OS, so it has no effect.

# Legacy Video Options

Q: My HDMI display isn't being detected even though it's plugged in. How do I force HDMI output?
A: Set `hdmi_force_hotplug=1` to make the Pi always use HDMI output mode.

Q: I want the Pi to ignore the HDMI even though a monitor is plugged in. Can I do that?
A: Yes, set `hdmi_ignore_hotplug=1` to disable HDMI output even with a monitor connected.

Q: My TV is cutting off the edges of the screen. How do I fix the overscan settings?
A: Adjust `overscan_left`, `overscan_right`, `overscan_top`, or `overscan_bottom` pixel values in config.txt.

Q: There's a black border on the left side of my screen. Do I increase or decrease overscan_left?
A: Decrease overscan_left to reduce the black border between the left edge and text.

Q: How do I completely turn off overscan?
A: Set `disable_overscan=1` to disable the firmware's default overscan values.

Q: I want audio over HDMI — is there a setting I need to change?
A: Yes, set `hdmi_drive=2` for normal HDMI mode which sends audio if supported and enabled.

Q: My display seems to ignore the hdmi_mode and hdmi_group settings I set. What can I do?
A: Try setting `hdmi_force_mode=1` to remove all other modes except your specified ones.

Q: How do I find out what HDMI modes my monitor actually supports?
A: Boot in VGA mode then run tvservice commands to list CEA and DMT supported modes.

Q: I want to rotate my HDMI display 90 degrees. What setting does that?
A: Set `display_hdmi_rotate=1` to rotate the HDMI display 90 degrees clockwise.

Q: Can I flip my display horizontally instead of rotating it?
A: Yes, set `display_hdmi_rotate=0x10000` for a horizontal flip.

Q: My TV keeps turning on and switching channels when I reboot my Pi. How do I stop that?
A: Set `hdmi_ignore_cec_init=1` to stop the active source message being sent during bootup.

Q: What's the default CEC name my Pi shows up as on my TV?
A: The default CEC name is "Raspberry Pi."

Q: I want to use DTS or AC3 audio passthrough but my display says it's not supported. Is there a workaround?
A: Set `hdmi_force_edid_audio=1` to pretend all audio formats are supported by the display.

Q: I want audio to always come out of the headphone jack instead of HDMI. Is there a setting for that?
A: Set `hdmi_ignore_edid_audio=1` and ALSA will default to the analogue headphone jack.

Q: My Pi is running headless and I want to save memory by not using a framebuffer. How?
A: Set `max_framebuffers=0` to prevent any framebuffers from being allocated.

Q: I've got a Pi 4 with two HDMI displays but only one seems to work. What do I need to change?
A: Set `max_framebuffers=2`; on pre-Pi 4 devices the default is 1 and needs increasing.

Q: What framebuffer color depth does the Pi use by default?
A: The default framebuffer depth is 16 bits per pixel.

Q: I set framebuffer depth to 32-bit and now the display looks wrong. What do I do?
A: Try setting `framebuffer_ignore_alpha=1` alongside your 32-bit framebuffer depth setting.

Q: My composite video output is in black and white but I want it sharper — is there a trade-off setting?
A: Yes, set `sdtv_disable_colourburst=1` for monochrome output that may appear sharper.

Q: I want to set a totally custom resolution that isn't in any of the mode tables. How do I do that?
A: Use `hdmi_cvt` to define a custom CVT mode, then set hdmi_group=2 and hdmi_mode=87.

Q: My Pi Touch Display keeps showing on-screen even though I'd rather use HDMI as the main output. How do I change that?
A: Set `display_default_lcd=0` so the LCD isn't the default display and HDMI takes over.

Q: What framerate does the Pi Touch Display default to?
A: The Raspberry Pi Touch Display defaults to 60Hz framerate.

# Raspberry Pi 4 HDMI Pipeline

Q: I'm trying to run 1366x768 on my Pi 4 and it's not working. Is that a known issue?
A: Yes, Pi 4 can't output 1366x768 at 60Hz; try manually setting 1360x768 at 60Hz instead.

Q: How do I manually set 1360x768 on my Pi 4 since it's not in the mode list?
A: Add hdmi_group=2, hdmi_mode=87, and hdmi_cvt=1360 768 60 to config.txt.

# Legacy Miscellaneous Options

Q: My Pi is showing low-voltage warnings and I want to let it use turbo mode anyway. How?
A: Set `avoid_warnings=2` to allow turbo mode even when low voltage is present.
