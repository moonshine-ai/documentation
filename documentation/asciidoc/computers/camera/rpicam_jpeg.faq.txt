# `rpicam-jpeg`

Q: How do I take a photo with my Raspberry Pi camera and save it?
A: Run `rpicam-jpeg --output test.jpg` to capture and save a JPEG image.

Q: I ran the command and my screen just went weird — what's it doing?
A: It shows a preview window for five seconds, then captures a full resolution JPEG.

Q: The preview window stays up way too long. Can I make it shorter?
A: Use the `--timeout` option to change how long the preview window displays.

Q: How do I take a lower resolution photo instead of the full size one?
A: Use `--width` and `--height` options to change the saved image resolution.

Q: What format does rpicam-jpeg save photos in?
A: It saves photos as full resolution JPEG images.

Q: I want the preview to only show for like two seconds and save a small photo. How do I do that?
A: Run `rpicam-jpeg --output test.jpg --timeout 2000 --width 640 --height 480`.

Q: What's the default preview time before it takes the picture?
A: The preview window displays for five seconds before capturing the image.

Q: Can I change the size of the photo it saves?
A: Yes, use the `--width` and `--height` options to set the saved image resolution.
