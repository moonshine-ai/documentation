# Detection options

Q: How do I tell rpicam-detect what kind of object to look for?
A: Use the object option with a name from the model's label file.

Q: Where does rpicam-detect get its list of object names from?
A: Object names come from the model's label file.

Q: I don't want it taking a photo every single frame. How do I add a delay between captures?
A: Use the gap option to set minimum frames between captures.

Q: Wait, do these detection options work with any rpicam command or just the one?
A: Detection options only apply to rpicam-detect, not other rpicam commands.

Q: How do I actually pass these options on the command line? Like what's the format?
A: Prefix the option name with two dashes, then a space, then the value.

Q: I've got an option with a long name. Is there a quicker way to type it?
A: Some options have shorthand aliases, like dash-h instead of dash-dash-help.

Q: My file path has a space in it. Will that break the command?
A: Surround values containing spaces in quotes to avoid issues.
