# `rpicam-detect`

Q: Is rpicam-detect included in Raspberry Pi OS by default?
A: No, but you can build it if you install TensorFlow Lite first.

Q: I want to use rpicam-detect but I don't see it on my Pi. Why isn't it there?
A: Raspberry Pi OS doesn't include it; you need to build it yourself.

Q: What do I need to install before I can build rpicam-detect?
A: You need TensorFlow Lite installed before building rpicam-detect.

Q: There's a flag I need to pass when building this thing — what is it?
A: Pass `-Denable_tflite=enabled` when you run meson to enable TensorFlow Lite.

Q: What kind of objects can rpicam-detect actually recognize?
A: It recognizes about 80 object classes, including people, cars, and cats.

Q: What neural network does rpicam-detect use under the hood?
A: It uses Google MobileNet v1 SSD trained on the Coco dataset.

Q: So what happens when rpicam-detect actually spots something? Does it take a photo or what?
A: It captures a full-resolution JPEG then returns to monitoring preview mode.

Q: I want to secretly watch my cats while I'm away. Can I do that with this?
A: Yes, use rpicam-detect with the `--object cat` flag to capture cat photos.

Q: What does the `-t 0` part mean in the cat monitoring example?
A: Not specified in this section.

Q: What's the lores width and height set to in the cat example command?
A: The low-resolution preview is set to 400 wide and 300 tall.

Q: Does rpicam-detect just take one photo or does it keep monitoring after?
A: After capturing a JPEG it returns to monitoring preview mode continuously.
