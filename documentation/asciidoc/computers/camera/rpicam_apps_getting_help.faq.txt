# Getting help

Q: My camera keeps crashing and I don't know who to ask. Where should I go for help?
A: Post on the Raspberry Pi Camera forum or file a GitHub issue.

Q: I'm about to post on the forum but I'm not sure what info I need to include. What should I have ready?
A: Include OS version, libcamera version, camera model, Pi model, and console output.

Q: How do I find out what version of libcamera I've got installed?
A: Run `rpicam-hello --version` to check your libcamera and rpicam-apps versions.

Q: I bought a third-party camera module and it's not working. Will the Raspberry Pi team help me?
A: No, they don't support third-party camera module vendor software.

Q: I think I found a bug in the camera software, not just a setup problem. Is there somewhere I can report that?
A: Yes, create an issue in the rpicam-apps GitHub repository with full details.

Q: What command do I run to check my operating system version before posting for help?
A: Run `uname -a` to get your operating system version information.

Q: I want to post on the forum but I don't know my Pi's memory size. Does that actually matter?
A: Yes, you should report your Raspberry Pi model including its memory size.
