# Use `libcamera` from Python with Picamera2

Q: What's Picamera2 and why would I use it instead of regular Picamera?
A: Picamera2 is an easy-to-use Python API replacing the legacy Picamera library.

Q: Where can I find the docs for Picamera2?
A: Documentation is available on GitHub and in the official Picamera2 manual.

Q: I've got Pi OS Lite — does it come with Picamera2 already or do I need to install it?
A: Lite images include Picamera2 but without the GUI dependencies pre-installed.

Q: Can I still see a camera preview on Pi OS Lite even without the GUI stuff?
A: Yes, preview images can still be displayed using DRM/KMS on Lite.

Q: How do I install Picamera2 on my Pi?
A: Run `sudo apt install -y python3-picamera2` to install it with GUI dependencies.

Q: I don't need any of the GUI stuff, just the basic camera library. How do I install it without all that extra baggage?
A: Run `sudo apt install -y python3-picamera2 --no-install-recommends` to skip GUI dependencies.

Q: I installed Picamera2 with pip a while back. Do I need to do anything before reinstalling it properly?
A: Uninstall the old version first by running `pip3 uninstall picamera2`.

Q: Does the full version of Raspberry Pi OS come with Picamera2 already on it?
A: Yes, recent Raspberry Pi OS images include Picamera2 with all GUI dependencies.
