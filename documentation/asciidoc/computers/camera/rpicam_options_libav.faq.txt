# `libav-format`

Q: How do I set the output format when recording video with libav?
A: Use the `--libav-format` option with mkv, mp4, avi, h264, or mpegts.

Q: I didn't set a format option. What format will my video be saved in?
A: The file extension you give the output option determines the format.

Q: What formats can I use with libav, like can I do MP4?
A: Libav supports mkv, mp4, avi, h264 streaming, and mpegts streaming.

# `libav-audio`

Q: I want to record audio along with my video. How do I turn that on?
A: Pass `--libav-audio` and also specify an audio codec with `--audio-codec`.

Q: Does the libav-audio option need a value after it or just the flag?
A: It does not accept a value; just pass the option by itself.

# `audio-codec`

Q: What audio codec does libav use by default?
A: The default audio codec is AAC.

Q: How do I see what audio codecs are available on my Pi?
A: Run `ffmpeg -codecs` to list all available codecs on your system.

# `audio-bitrate`

Q: I want to record audio at a lower bitrate to save space. How do I set that?
A: Use `--audio-bitrate` followed by the bitrate value in bits per second.

Q: What's an example of recording video with a specific audio bitrate?
A: Run `rpicam-vid --codec libav -o test.mp4 --audio_codec mp2 --audio-bitrate 16384`.

# `audio-samplerate`

Q: What's the default sample rate when recording audio with libav?
A: The default is zero, which means it just uses the input's sample rate.

Q: Can I set a custom audio sample rate or does it just pick one automatically?
A: You can set a custom rate in Hz using `--audio-samplerate` with a numeric value.

# `audio-device`

Q: What even is ALSA? Do I need to know about it to pick an audio input?
A: ALSA is the audio system; use `--audio-device` to select your recording input.

Q: How do I find out what audio input devices are available on my Pi?
A: Run `pactl list | grep -A2 'Source #' | grep 'Name: '` to list them.

# `av-sync`

Q: My audio and video are out of sync in my recordings. Is there a way to fix that?
A: Use `--av-sync` to shift the audio timestamp by a value in microseconds.

Q: Can the av-sync option only shift audio forward or can it go backwards too?
A: It accepts both positive and negative values to shift audio either direction.

# Whole Document

Q: How do I even enable the libav backend? I don't see it doing anything.
A: Pass `--codec libav` to your rpicam command to enable the libav backend.

Q: I want to put a flag before the option name. How do I do that exactly?
A: Prefix every option name with two dashes, like `--libav-format` or `--audio-codec`.

Q: Are there shorthand versions of these options so I don't have to type everything out?
A: Some options have short aliases like `-h`; they save typing but reduce readability.
