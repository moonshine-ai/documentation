# `rpicam-raw`

Q: How do I record a raw video clip for two seconds using rpicam-raw?
A: Run `rpicam-raw -t 2000 -o test.raw` to record two seconds raw.

Q: I ran rpicam-raw but I can't tell what format the output is in. Where does it say?
A: The app prints pixel format and image dimensions to the terminal window.

Q: Does rpicam-raw show a preview while it's recording?
A: No, rpicam-raw does not show a preview window at all.

Q: I want each raw frame saved as its own file instead of one huge file. How do I do that?
A: Use the segment option with one and percent zero five d in the filename.

Q: My raw recording is dropping frames. What should I do to stop that?
A: Lower the framerate option below ten to avoid dropping frames during recording.

Q: Can rpicam-raw save files as DNG? I want to edit them properly.
A: No, use rpicam-still instead for DNG file format output.

Q: What's the fastest rpicam-raw can write frames from the HQ camera without losing any?
A: It can write 18 MB 12-megapixel HQ camera frames at 10fps.

Q: I'm recording at full 12-megapixel resolution and frames are getting dropped. What framerate should I use?
A: Set framerate to eight or below when recording at full HQ resolution.

Q: What's the default behavior when rpicam-raw saves output, like does it split it up at all?
A: By default, rpicam-raw outputs all raw frames into one single file.

Q: Where can I find out more about what the raw formats actually look like?
A: Check the mode documentation for more information on raw formats.
