# Differences between `rpicam` and `raspicam`

Q: I used to use image stabilisation in raspicam but I can't find it in rpicam-apps. Did they remove it?
A: Yes, rpicam-apps removed image stabilisation; post-processing replaced many such features.

Q: How do I turn off Auto White Balance in the new rpicam-apps? It used to be simpler.
A: Set a pair of colour gains using the awbgains option, like one point zero comma one point zero.

Q: I've got a NoIR camera and the white balance looks wrong. How do I fix it?
A: Pass the tuning-file option a NoIR-specific file like imx219_noir.json instead.

Q: Wait, what happened to the ISO option? I can't find it anywhere.
A: The ISO option was removed; calculate the gain value corresponding to your desired ISO instead.

Q: I used to do burst capture with raspicam-still. Can I still do that?
A: Use rpicam-vid in MJPEG mode with segment one to save each frame separately instead.

Q: What features got dropped going from raspicam to rpicam-apps?
A: Removed features include opacity, image effects, colour effects, annotation, DRC, stereo, stabilisation, and demo modes.

Q: I want to rotate my camera ninety degrees but it's not working. Is that supported?
A: No, rpicam-apps dropped support for ninety degree and two hundred seventy degree rotations.

Q: How do I disable defective pixel correction on my HQ camera?
A: Run sudo echo zero redirected to slash sys slash module slash imx477 slash parameters slash dpc_enable.

Q: I'm confused — in the old raspicam, metering and exposure were kind of the same thing. Is that still the case?
A: No, rpicam-apps separates metering and exposure into distinct options now.

Q: Does rpicam-apps let you set a flicker reduction period like the old camera software did?
A: No, rpicam-apps does not support setting a flicker period at all.

Q: What controls digital gain in rpicam-apps since there's no dedicated option for it?
A: The gain option sets digital gain implicitly rather than through explicit separate control.

Q: I'm switching from raspicam and some of my short command flags aren't working anymore. Why?
A: Multi-character short options were dropped; use the long form options instead, single-character ones remain.
