# `rpicam-apps`

Q: I've seen both `libcamera-still` and `rpicam-still` mentioned. Are they the same thing?
A: Yes, symbolic links let old `libcamera-*` names still work for now.

Q: What's the difference between `rpicam-still` and `rpicam-jpeg`? They sound the same to me.
A: `rpicam-jpeg` runs a preview then captures stills; `rpicam-still` emulates `raspistill`.

Q: I just got a fresh Pi. Do I need to install anything to use the camera apps?
A: No, fresh Raspberry Pi OS installs include the five basic `rpicam-apps` already.

Q: What's `rpicam-hello` actually do? Is it just a test thing?
A: It starts a camera preview stream and displays it on screen, like a hello world.

Q: I want to capture raw unprocessed frames from the sensor. Is there an app for that?
A: Yes, `rpicam-raw` captures raw Bayer frames directly from the camera sensor.

Q: Can I build my own camera app based on this stuff, or is it locked down?
A: Yes, `rpicam-apps` source is freely available under a BSD-2-Clause licence.

Q: What about `rpicam-detect`? I don't see it on my Pi.
A: It's not built by default; you need TensorFlow Lite installed to build it.

# `libcamera`

Q: What even is `libcamera`? Do I need to know about it to use the camera?
A: It's an open-source library supporting cameras directly from Linux on Arm processors.

Q: Does `libcamera` handle displaying my photos or encoding video itself?
A: No, use `rpicam-apps` for encoding and displaying; `libcamera` doesn't do that itself.

Q: I've got a third-party IMX519 sensor. Will it work with this?
A: Yes, the IMX519 is listed as a supported third-party sensor in `libcamera`.

Q: My camera has an IMX290 sensor in it. Is that going to be supported?
A: Yes, the IMX290 is listed among supported third-party sensors.

Q: What kind of auto-adjustment stuff does `libcamera` handle automatically?
A: It handles auto exposure, gain control, auto white balance, and auto lens-shading correction.

Q: I want to add support for a sensor that's not on the list. How do I do that?
A: Contribute the new sensor support directly to the upstream `libcamera` project.

Q: Does the Raspberry Pi use the exact same `libcamera` as everyone else, or is it different?
A: Raspberry Pi OS uses a fork of `libcamera` to control updates separately.

# Whole Document

Q: I'm on an older Raspberry Pi OS before Bookworm. Should I use `rpicam` or `libcamera` commands?
A: Versions before Bookworm still use the `libcamera-*` naming for camera applications.

Q: What's the actual difference between `libcamera` and `rpicam-apps`? I keep confusing them.
A: `libcamera` is the underlying library; `rpicam-apps` are the example CLI applications built on top.
