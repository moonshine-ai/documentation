# Image options

Q: How do I pass these options on the command line, like what's the format?
A: Prefix the option name with two dashes, then pass the value after it.

Q: My option value has a space in it and it's not working. What do I do?
A: Surround any value containing a space in quotes when passing it.

# `quality`

Q: What's the default JPEG quality when I take a still photo?
A: The default JPEG quality is ninety-three out of one hundred.

Q: Can I crank up the JPEG quality to the maximum? What do I set it to?
A: Yes, set quality to one hundred for maximum JPEG quality.

# `exif`

Q: I want to add my name as the artist in the photo's EXIF data. How do I do that?
A: Use the exif option, like `--exif IDO0.Artist=Someone` with rpicam-still.

Q: Can I add EXIF tags that aren't related to camera settings?
A: Yes, add non-camera tags after recording using the external tool ExifTool.

Q: I'm seeing warnings in the terminal about EXIF tags being formatted wrong. Should I worry?
A: It's a known libexif library limitation; many tags are incorrectly formatted as ASCII.

# `timelapse`

Q: I want to take a photo every five seconds for a minute. How do I set that up?
A: Use timelapse with an interval in milliseconds combined with the timeout option.

Q: How do I make each timelapse photo save as a separate file instead of overwriting the last one?
A: Use string formatting in the filename, like `test%d.jpg`, to get separate files.

# `framestart`

Q: The frame counter in my filenames starts at zero. Can I make it start at a different number?
A: Yes, use framestart to set a custom integer starting value for the frame counter.

# `datetime`

Q: I want my photos to automatically be named with the date and time. Is there an option for that?
A: Yes, use the datetime option; it names files in MMDDhhmmss.jpg format automatically.

Q: What format does the datetime option use for the filename? Like what order is it?
A: It uses month, day, hour, minute, second in the format MMDDhhmmss.jpg.

# `timestamp`

Q: Can I name my photos with a Unix timestamp instead of a regular date?
A: Yes, the timestamp option uses the current Unix system time as the filename.

# `restart`

Q: What does the restart marker thing do for JPEG files? Why would I use it?
A: Restart markers limit corruption impact and enable multi-threaded JPEG encoding and decoding.

# `immediate`

Q: I don't want any delay before my photo is taken. Is there a way to capture right away?
A: Yes, use the immediate option to capture the image as soon as the app runs.

# `keypress`

Q: I want to press Enter to take a photo instead of having it happen automatically. Can I do that?
A: Yes, the keypress option captures when you press Enter or when timeout expires.

Q: How do I quit without actually taking a photo when I'm using keypress mode?
A: Press the x key and then Enter to exit without capturing an image.

# `signal`

Q: Can I trigger a photo from another script using a signal instead of a keypress?
A: Yes, send SIGUSR1 to trigger a capture, or SIGUSR2 to exit without capturing.

# `thumb`

Q: How do I turn off the thumbnail that gets embedded in my JPEG photos?
A: Pass `none` to the thumb option to omit the thumbnail entirely.

Q: What's the default thumbnail size and quality when I take a still?
A: The default thumbnail is three hundred twenty by two hundred forty pixels at quality seventy.

# `encoding`

Q: I want to save my photos as PNG instead of JPEG. How do I change that?
A: Use the encoding option with the value `png` to switch to PNG output.

Q: Does the file extension I put in the filename actually control what format gets saved?
A: No, the encoding option always determines the format, overriding the file extension.

Q: What image formats can I save to with rpicam-still?
A: You can save as JPEG, PNG, BMP, uncompressed RGB, or uncompressed YUV420.

# `raw`

Q: Can I save a raw file at the same time as my normal JPEG? Like for editing later?
A: Yes, the raw option saves a DNG file alongside your regular output image.

Q: What editing tools can I use to process the raw DNG files from my Pi camera?
A: You can process the DNG files with tools like dcraw or RawTherapee.

Q: What info gets stored in the EXIF data of those raw DNG files?
A: Exposure time, analogue gain, white balance gains, and the ISP colour matrix are stored.

Q: Does the raw file have any processing applied to it from the camera?
A: No, raw file data comes straight from the sensor with no ISP processing applied.

# `latest`

Q: I'm doing timelapse and I always want a symlink pointing to the newest photo. How do I do that?
A: Use the latest option and pass your desired symbolic link name as the value.

# `autofocus-on-capture`

Q: Can I make the camera refocus right before it takes each photo?
A: Yes, autofocus-on-capture runs an autofocus cycle just before capturing an image.

Q: Does the autofocus-on-capture thing work with all Pi camera modules?
A: No, it's only supported by some modules like the Raspberry Pi Camera Module 3.

Q: I've got continuous autofocus mode on. Will autofocus-on-capture do anything extra?
A: No, continuous autofocus mode ignores autofocus-on-capture and focuses throughout preview instead.

# Whole Document

Q: I've never used these camera options before. How do I even know what shorthand aliases are available?
A: Each option lists its alias, like `-q` for quality or `-e` for encoding.

Q: I want to just take a photo quick from the command line. What's the simplest way to control the quality?
A: Use `-q` followed by a number between one and one hundred for JPEG quality.
