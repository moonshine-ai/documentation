# Install `libcamera` and `rpicam-apps`

Q: What's the difference between `rpicam-apps` and `rpicam-apps-lite`?
A: Lite omits desktop environment support, only making DRM preview available.

Q: Do I need to manually install rpicam-apps or does it come with Raspberry Pi OS?
A: Both rpicam-apps versions come pre-installed on their respective Raspberry Pi OS versions.

Q: I'm using Raspberry Pi OS Lite — do I get the full camera apps or the stripped-down version?
A: Lite OS comes with rpicam-apps-lite, which lacks desktop environment support.

Q: Can I still see a preview on the Lite version, or is that completely cut out?
A: Yes, the DRM preview is still available in rpicam-apps-lite.

Q: Do I need to install any extra libraries manually to get rpicam-apps working?
A: No, your package manager installs the required library dependencies automatically.

Q: I want to rebuild rpicam-apps but I don't want to build libcamera from scratch. Is that possible?
A: Yes, you can rebuild rpicam-apps without building libcamera or libepoxy from scratch.

Q: What even is an ABI version? Do I need to worry about it when installing?
A: No need to worry — your package manager handles ABI-versioned library installation automatically.

Q: I've got the desktop version of Raspberry Pi OS. Do I already have the camera apps installed?
A: Yes, rpicam-apps comes pre-installed on the full Raspberry Pi OS desktop version.
