# Install dependencies

Q: I keep getting permission denied errors when using my webcam. What's going on?
A: Add your username to the video group using the usermod command.

Q: How do I install the software I need to use a USB webcam?
A: Run sudo apt install fswebcam to install the required package.

Q: I added my user to the video group but I'm not sure it worked. How do I check?
A: Use the groups command to verify your user was added correctly.

# Take a photo

Q: What's the simplest command to just snap a photo with my webcam?
A: Run fswebcam image.jpg to capture and save a photo.

Q: The photos my webcam takes look really low quality. Can I make them bigger?
A: Use the -r flag with a resolution like 1280x720 for higher quality.

Q: There's this ugly timestamp bar across the bottom of my photos. How do I get rid of it?
A: Add the --no-banner flag to your fswebcam command to remove it.

Q: By default what resolution does fswebcam shoot at, is it decent?
A: No, it uses a low resolution by default, so specify higher resolution manually.

# Remove the banner

Q: Wait so every photo has a banner on it automatically? How do I turn that off?
A: Use the --no-banner flag when running fswebcam to disable the timestamp banner.

# Automate image capture

Q: I want each photo to automatically get saved with the date and time in the filename. How do I do that?
A: Write a Bash script using the date command to generate timestamped filenames automatically.

Q: Does fswebcam automatically name files with timestamps like the camera software does?
A: No, fswebcam has no built-in timestamp naming, so you need a Bash script instead.

Q: I wrote a bash script for my webcam but it won't run. What am I missing?
A: Make it executable first by running chmod +x on your script file.

# Capture a time lapse

Q: I want my Pi to automatically take a photo every minute for a time lapse. How do I set that up?
A: Use cron to schedule your webcam script to run at regular intervals.

Q: How do I actually edit the cron schedule on my Pi?
A: Run crontab -e to open the cron table for editing.

Q: What does the cron line actually look like if I want a photo every single minute?
A: Use five asterisks followed by the full path to your webcam script.

# Whole Document

Q: Can I use a regular USB webcam with my Raspberry Pi or do I need the special camera module?
A: Yes, a USB webcam works fine for recording pictures and videos on Raspberry Pi.

Q: What software do I need to take photos from a USB webcam on my Pi?
A: Install fswebcam using apt to capture photos from a USB webcam.

Q: I want to set up a time lapse with my webcam on a Pi. Is that doable without fancy software?
A: Yes, combine fswebcam with a Bash script and cron scheduling to achieve this.
