# Prerequisites

Q: How do I get TensorFlow Lite installed on my Raspberry Pi?
A: Run `sudo apt install libtensorflow-lite-dev` on Raspberry Pi OS Trixie onwards.

Q: I installed TensorFlow Lite but things still aren't working. Did I miss a step?
A: Yes, you must recompile rpicam-apps with TensorFlow Lite support after installing.

Q: Does TensorFlow Lite work on older versions of Raspberry Pi OS?
A: Raspberry Pi only builds and distributes TFLite packages from Raspberry Pi OS Trixie onwards.

# `object_classify_tf` stage

Q: What model does the object classification stage actually use under the hood?
A: It uses a Google MobileNet v1 model to classify objects in camera images.

Q: I want the object labels to show up on my camera preview. How do I turn that on?
A: Set `display_labels` to 1; it inserts metadata for the annotate_cv stage to render.

Q: How do I control how confident the classifier needs to be before it says it found something?
A: Use `threshold_high` between 0 and 1 to set the confidence threshold for detected objects.

Q: I've got object classification running but it's showing too many results. How do I limit that?
A: Set the `top_n_results` parameter to control how many results are shown.

Q: What size does the image need to be for the object classify stage to work?
A: The stage operates on a low resolution stream image of size 224×224.

Q: What command do I run to try out the object classification with rpicam-hello?
A: Run `rpicam-hello --post-process-file object_classify_tf.json --lores-width 224 --lores-height 224`.

Q: I don't want the model running on every single frame, that seems wasteful. Can I slow it down?
A: Yes, set the `refresh_rate` parameter to control frames elapsed between model runs.

# `pose_estimation_tf` stage

Q: How do I actually get the detected pose drawn onto my video, not just detected?
A: Use the separate `plot_pose_cv` stage to draw the detected pose onto the main image.

Q: What image size does the pose estimation stage need?
A: The pose estimation stage operates on a low resolution stream image of 257×257.

Q: Why does the example command use 258 instead of 257 for the pose estimation size?
A: YUV420 images must have even dimensions, so you round up to 258×258.

Q: How do I control how much of the pose gets drawn on screen?
A: Set `confidence_threshold` in the `plot_pose_cv` stage; it can even be less than zero.

# `object_detect_tf` stage

Q: What's the difference between object classify and object detect? Like why are there two stages?
A: Object detect uses an SSD model to detect and label objects with bounding boxes, not just classify.

Q: How do I make the bounding boxes thicker when detecting objects?
A: Set the `line_thickness` parameter in the `object_detect_draw_cv` stage configuration.

Q: Two detected objects are overlapping and showing as separate. How do I merge them?
A: Adjust the `overlap_threshold` parameter to control how much overlap triggers merging matches.

Q: What image size does the object detection stage work with?
A: The object detect stage operates on a low resolution stream image of size 300×300.

Q: How do I draw the detected objects on my actual camera image?
A: Use the separate `object_detect_draw_cv` stage to draw detected objects onto the main image.

# `segmentation_tf` stage

Q: Can I actually see the segmentation results visually or is it just hidden data?
A: Set `draw` to 1 to display the segmentation map in the bottom right corner of the image.

Q: What does the segmentation stage actually output? Like what data does it produce?
A: It adds a vector of 257×257 values to image metadata indicating categories each pixel belongs to.

Q: My image isn't square but I want to use segmentation. Will it crop my image weirdly?
A: The stage works when squashing a non-square image without cropping.

Q: What resolution should I set for the segmentation stage's low resolution stream?
A: Set at least 258×258 for both width and height due to YUV420 even dimension requirements.

# Whole Document

Q: Do all these TensorFlow stages need a labels file or just some of them?
A: Object classify, object detect, and segmentation stages all require a labels file.

Q: All these stages seem to need a low resolution stream. Why is that?
A: All TensorFlow Lite stages operate on low resolution stream images, not the full camera image.

Q: I want more debug info printed while these stages run. Is there a setting for that?
A: Yes, set `verbose` to 1 in any stage's configuration to output extra console information.

Q: Do all these AI stages use Google MobileNet models?
A: Yes, all four TensorFlow Lite post-processing stages use Google MobileNet v1 models.
