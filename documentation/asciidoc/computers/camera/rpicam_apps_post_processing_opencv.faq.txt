# `sobel_cv` stage

Q: What does the Sobel filter stage actually do to my image?
A: It applies a Sobel filter to emphasise edges in the image.

Q: I want to tweak the Sobel effect — is there anything I can adjust?
A: You can configure the kernel size using the `ksize` parameter.

Q: What's the default kernel size for the Sobel filter?
A: The default kernel size is 5.

# `face_detect_cv` stage

Q: Can I use this face detection thing when I'm taking a still photo?
A: No, the face detect stage ignores still image capture entirely.

Q: What resolution does the face detector run at?
A: It runs on a low resolution stream between 320×240 and 640×480 pixels.

Q: Does the face detector draw boxes on my image or just find the faces?
A: It optionally draws face locations on the image using the `draw_features` parameter.

Q: What method does the face detection stage use to actually find faces?
A: It uses the OpenCV Haar classifier to detect faces in images.

Q: I'm getting too many false positives with face detection. What setting should I look at?
A: Increase `min_neighbors`, which sets the minimum overlapping neighbours required for a face.

Q: Can I set a minimum and maximum size for the faces it detects?
A: Yes, you can configure both `min_size` and `max_size` parameters.

Q: How often does the face detector actually re-run between frames?
A: The `refresh_rate` parameter controls how many frames to wait before re-running.

Q: Where does the face detection results data get stored?
A: Face location metadata is returned under the key `face_detect.results`.

# `annotate_cv` stage

Q: I want to put a timestamp on my video. How do I do that?
A: Pass `%F %T %z` to get ISO date, 24h local time, and timezone offset.

Q: What does `%F` show when I use it in the annotation text?
A: It displays the ISO-8601 date, for example 2023-03-07.

Q: Can I change the text colour and background of the annotation?
A: Yes, you can configure `fg` foreground colour and `bg` background colour.

Q: Where does the annotate stage put the text on the image?
A: It writes text into the top corner of images.

Q: Can another post-processing stage control what text gets written onto my image?
A: Yes, other stages can write text by putting it in `annotate.text` metadata.

Q: I want bigger text in my annotation. What setting do I change?
A: Adjust the `scale` parameter, which is proportional to text size.

Q: What's the default transparency setting for the annotation background?
A: The default alpha value is 0.3 when overwriting background pixels.

# Whole Document
