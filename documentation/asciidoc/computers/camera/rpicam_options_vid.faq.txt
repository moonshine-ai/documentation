# `quality`

Q: I'm recording in MJPEG and not sure what quality setting to use. What's the default?
A: The default MJPEG quality level is 50, on a scale of one to 100.

Q: Does the quality flag do anything if I'm recording in H.264?
A: No, the quality option only applies to videos encoded in MJPEG format.

# `bitrate`

Q: I want to control how big my video file ends up. Is there a flag for that?
A: Yes, use the bitrate option to control H.264 encoder target bits per second.

Q: What's the shorthand for the bitrate option? I don't want to type the whole thing out.
A: The shorthand alias for bitrate is just `-b`.

# `intra`

Q: What does the intra option actually do? I don't really know what an iframe is.
A: It sets how often intra frames appear in the H.264 bitstream, in frames.

Q: What's the default iframe frequency if I don't set intra myself?
A: The default intra frame frequency is every 60 frames.

# `profile`

Q: What H.264 profiles can I choose from?
A: You can choose baseline, main, or high for the H.264 profile.

# `level`

Q: What values can I use for the H.264 level option?
A: You can set the H.264 level to 4, 4.1, or 4.2.

# `codec`

Q: What video encoders are available? I don't know which one to pick.
A: Available codecs are h264, mjpeg, yuv420, and libav; h264 is the default.

Q: Can I record uncompressed video on a Raspberry Pi?
A: Yes, use the yuv420 codec option to output uncompressed YUV420 frames.

# `save-pts`

Q: I want to put my video into an MKV file. How do I do that with rpicam-vid?
A: Save timestamps with save-pts, then use mkvmerge to create the MKV container.

Q: I've got a Pi 5 and save-pts isn't working. What should I use instead?
A: Pi 5 doesn't support save-pts; use libav to generate timestamps for container formats.

# `keypress`

Q: Can I pause and resume recording without stopping the whole program?
A: Yes, use the keypress option to toggle recording on and off with Enter.

Q: How do I actually stop and exit when I'm using keypress mode?
A: Type x and press Enter to exit when using the keypress option.

# `signal`

Q: Is there a way to control recording from another script or process?
A: Yes, use the signal option; send SIGUSR1 to toggle recording, SIGUSR2 to exit.

# `initial`

Q: I want the camera to start paused and only record when I tell it to. Can I do that?
A: Yes, set initial to pause so recording starts disabled until you toggle it.

# `split`

Q: I'm toggling recording on and off and I want each session saved as a separate file. How?
A: Use the split option to write each recording session into its own separate file.

Q: If I use split but don't give each file a unique name, what happens?
A: It overwrites the file each time unless you combine split with the output option.

# `segment`

Q: I want to automatically chop my video into smaller chunks. Is there a way to do that?
A: Yes, the segment option cuts video into multiple files of a given millisecond duration.

Q: Can I save each frame as its own file, kind of like burst mode?
A: Yes, pass a very small duration like 1 millisecond to segment to record each frame separately.

# `circular`

Q: What does the circular buffer option actually do? When does it save the video?
A: It records into a memory buffer and saves to disk only when the application quits.

Q: What's the default size of the circular buffer if I don't specify one?
A: The default circular buffer size is 4 megabytes.

# `inline`

Q: My video player can't seek into the middle of my stream. Is there something that helps with that?
A: Use inline to write a sequence header in every iframe, helping clients decode from any point.

# `listen`

Q: I want to stream video over the network. Is there an option that waits for someone to connect first?
A: Yes, the listen option waits for an incoming client connection before encoding starts.

# `frames`

Q: I only want to record exactly 500 frames and then stop. Is there a way to do that?
A: Yes, use the frames option and pass the exact number of frames you want recorded.

# `framerate`

Q: How do I lock my recording to a specific framerate?
A: Use the framerate option and pass the exact frames per second you want recorded.

# `low-latency`

Q: I'm streaming in real time on a Pi 5 and there's too much delay. Is there anything I can do?
A: Use the low-latency option on Pi 5 to reduce encoding latency for real-time streaming.

Q: Does low-latency mode affect video quality at all?
A: Yes, it slightly reduces coding efficiency; B frames and arithmetic coding are no longer used.

# `sync`

Q: I've got multiple cameras and I want them all capturing at exactly the same moment. Is that possible?
A: Yes, use sync mode set to either client or server for software camera synchronisation.

# Whole Document

Q: Do all these video options work with every format, or are some of them only for H.264?
A: Several options like bitrate, intra, profile, level, and inline only apply to H.264 format.

Q: How do I actually pass these options on the command line? Do I need dashes or anything?
A: Prefix each option name with two dashes, and separate any value with a single space.

Q: Some of these options have short versions. When should I use those instead?
A: Use shorthand aliases to save space and time, though they're less readable than full names.
