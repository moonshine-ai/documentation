# Configuration

Q: I've got a third-party camera and it's not working. Do I need to change any settings?
A: Check the manufacturer's instructions for any necessary configuration changes needed.

Q: I'm using an HQ camera. What do I put in config.txt to make it work?
A: Add `dtoverlay=imx477` to your `/boot/firmware/config.txt` file.

Q: I've got a V2 camera module. What's the overlay I need?
A: Use `dtoverlay=imx219` in your `/boot/firmware/config.txt` file.

Q: I added an overlay to config.txt but my camera still isn't being detected right. Did I miss a step?
A: You also need to set `camera_auto_detect=0` and then reboot with `sudo reboot`.

Q: Wait, if I turn off auto detection, won't it stop finding my camera altogether?
A: No, you manually specify your camera using the correct dtoverlay in config.txt instead.

Q: I've got a Raspberry Pi 5 with two camera connectors. How do I tell it which one to use?
A: Add `,cam0` to your dtoverlay entry to specify connector 0 instead of the default.

Q: My IMX290 camera needs a clock frequency. Where do I find the right one to use?
A: Check your module vendor's instructions for the correct clock frequency to use.

Q: I just want to make sure — do most cameras need me to mess with config.txt at all?
A: No, most use cases work automatically with no configuration changes needed.

# Tweak camera behaviour with tuning files

Q: What even is a tuning file? Do I need to worry about it?
A: It controls algorithms and hardware settings to produce the best image quality.

Q: I've got the NoIR version of the camera. Do I need a different tuning file?
A: Yes, NoIR sensors use different Auto White Balance settings and need a different tuning file.

Q: How do I use a different tuning file with my camera?
A: Use the `--tuning-file` option with `rpicam-hello` to specify a different file.

Q: I'm on a Pi 4, not a Pi 5. Are the tuning files in the same place?
A: No, use files in `/usr/share/libcamera/ipa/rpi/vc4/` instead on older models.

Q: Can I customize the tuning file or do I have to use the ones that come with it?
A: You can copy and alter existing tuning files to customize camera behaviour.

Q: I've got a Soho Enterprises SE327M12 camera. Is there a tuning file for that?
A: Yes, libcamera includes `se327m12.json` as the tuning file for that camera.

Q: Does libcamera only support official Raspberry Pi cameras for tuning files?
A: No, libcamera maintains tuning files for several cameras including third-party models.

# Whole Document

Q: I'm setting up a camera module and I don't know if I need to touch anything. When do I actually need to change config.txt?
A: Only non-standard drivers, overlays, or third-party cameras typically require configuration changes.

Q: My camera's a standard official one connected to a Pi 5. Will auto-detection find it okay?
A: Yes, auto-detection correctly identifies official cameras connected to single-board computers.
