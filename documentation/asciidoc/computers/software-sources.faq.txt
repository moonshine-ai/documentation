# Finding software sources in Raspberry Pi OS

Q: I want to look at the source code for packages in Raspberry Pi OS. How do I do that?
A: Edit apt sources files to add deb-src, then run apt source.

Q: I'm on a 64-bit Pi. Which file do I edit to enable source packages?
A: Edit `/etc/apt/sources.list.d/debian.sources` to add deb-src.

Q: What does the plus-rpt tag mean on some packages?
A: It marks downstream packages that Raspberry Pi has patched from upstream sources.

Q: After I edit those apt files, what do I do next?
A: Run sudo apt update to refresh the package lists.

Q: I want to actually build a package from source, like labwc. What's the process?
A: Install devscripts, run apt build-dep, then build with debuild.

Q: What's the devscripts package for? Do I actually need it?
A: It's a helper package needed as part of the standard Debian building process.

Q: I've got the source fetched and I'm in the folder. What command do I run to build it?
A: Run debuild with the flags -uc and -us to build the package.

# Our GitHub organizations

Q: Where can I find Raspberry Pi's open source code on GitHub?
A: Raspberry Pi uses three GitHub organizations: raspberrypi, raspberrypi-ui, and RPi-Distro.

Q: I'm looking for Raspberry Pi software on GitHub but I don't know which account to check. Are there multiple?
A: Yes, there are three organizations: raspberrypi, raspberrypi-ui, and RPi-Distro.

# List of categorized sources

Q: Where do I find the Linux kernel source for my Pi?
A: It's at github.com/raspberrypi/linux and supports Pi 1 through Pi 5.

Q: Does the same kernel repo work for all Pi models or do I need different ones?
A: One repo covers all versions from Raspberry Pi 1 through Raspberry Pi 5.

Q: I want to check what changed in a recent firmware update. Where do I look?
A: The firmware changelog is linked from the raspberrypi/firmware GitHub repository.

Q: What's in the rpi-eeprom repo exactly?
A: It has bootloader EEPROM scripts and binaries for Raspberry Pi 4 and 5.

Q: I want to control GPIO pins directly. Is there a supported library for that?
A: Yes, gpiolib in the raspberrypi/utils repo is the supported method for GPIO access.

Q: I'm writing Python code to control the camera. What library should I use?
A: Use picamera2, the official Python library for controlling Raspberry Pi cameras.

Q: What's the difference between picamera2 and rpicam-apps?
A: Picamera2 is a Python library; rpicam-apps is a C++ library and application suite.

Q: Where's the source for the taskbar at the top of the Wayland desktop?
A: It's in the raspberrypi-ui/wf-panel-pi repository on GitHub.

Q: I'm using the old X-based desktop, not Wayland. Where's the taskbar source for that?
A: The legacy X-based taskbar source is at raspberrypi-ui/lxpanel-pi on GitHub.

Q: What manages the desktop background on Raspberry Pi OS?
A: The file manager, pcmanfm, also handles displaying the desktop background.

Q: I want to find the source for the Raspberry Pi Configuration tool. Where is it?
A: It's at raspberrypi-ui/rc_gui, the Raspberry Pi configuration plugin for Control Centre.

Q: Where's the code for the SD Card Copier app?
A: It's in the raspberrypi-ui/piclone repository on GitHub.

Q: I want to check my SD card's health. Is there a diagnostics app and where's its source?
A: Yes, the Diagnostics app source is at raspberrypi-ui/agnostics on GitHub.

Q: Where can I find the Raspberry Pi Imager source code?
A: It's available at github.com/raspberrypi/rpi-imager on GitHub.

Q: I want to boot my Compute Module over USB. Is there a tool for that?
A: Yes, the usbboot tool lets you boot Raspberry Pi devices over USB for provisioning.

Q: Does the secure boot provisioning tool work on all Pi models?
A: It supports Raspberry Pi 5, Compute Module 4, and Compute Module 5 only.

Q: I found a bug in the current Raspberry Pi OS. Where do I report it?
A: Report it at the raspberrypi/trixie-feedback repository on GitHub.

Q: I want the VS Code extension for Pico development. Where do I get it?
A: It's on the Microsoft Visual Studio Code marketplace under raspberry-pi.raspberry-pi-pico.

Q: Where do I find example projects for the Raspberry Pi Pico?
A: Examples are available at github.com/raspberrypi/pico-examples on GitHub.

Q: What's picotool used for?
A: It's a tool for interacting with RP-series devices when they're in BOOTSEL mode.

# Whole Document

Q: Why doesn't Raspberry Pi just open source everything?
A: They open source as much as possible but some firmware remains closed source.

Q: What kind of software does Raspberry Pi actually focus on developing?
A: They focus on software optimizing user experience, like multimedia, camera, and AI acceleration.

Q: I'm trying to understand what rpt-tagged packages are. What does that mean?
A: Those are downstream packages that Raspberry Pi has patched from upstream software sources.
