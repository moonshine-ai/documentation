# Kernel headers

Q: I'm trying to build a kernel module and it says I'm missing kernel headers. How do I get those?
A: Install them with apt or clone the entire kernel from GitHub instead.

Q: Do I already have the kernel headers if I cloned the kernel from GitHub?
A: Yes, the headers are already included in the full kernel source tree.

Q: What's the command to install kernel headers on the 64-bit version of Raspberry Pi OS?
A: Run sudo apt install linux-headers-rpi-v8 on 64-bit Raspberry Pi OS.

Q: I've got the 32-bit version of Pi OS. What do I run to get the kernel headers?
A: Run sudo apt install linux-headers-rpi-{v6,v7,v7l} for 32-bit Raspberry Pi OS.

Q: I ran the install command and nothing seems to be happening. Is it frozen?
A: Installation takes several minutes and shows no progress indicator, so just wait.

Q: I updated my kernel and now my module won't compile. Could it be a headers mismatch?
A: Yes, you need headers matching your exact kernel version after any update.

Q: I want the absolute latest kernel headers. Should I use apt or something else?
A: Clone the kernel from GitHub directly for the most up-to-date header versions.

Q: Why does apt have older headers than what my kernel is actually running?
A: It can take several weeks for the apt package to reflect the latest kernel version.

Q: Do I need the full kernel source just to compile a module, or is there a smaller option?
A: You can install just the kernel headers with apt instead of the full source.
