# Prepare to configure

Q: What do I need to install before I can use menuconfig?
A: Install libncurses5-dev headers using sudo apt install libncurses5-dev.

Q: I'm trying to run menuconfig but it won't compile. What am I missing?
A: You're probably missing the ncurses development headers; install libncurses5-dev first.

Q: Do I need to download the kernel source before configuring anything?
A: Yes, download kernel sources and install the default build configuration first.

# `menuconfig`

Q: How do I actually open the kernel configuration menu?
A: Just run make menuconfig in your terminal to open the configuration utility.

Q: I'm cross-compiling a 64-bit kernel. What command do I use for menuconfig?
A: Run make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- menuconfig for 64-bit cross-compilation.

Q: What about cross-compiling a 32-bit kernel, is the command different?
A: Yes, run make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- menuconfig for 32-bit.

Q: How do I move around inside menuconfig? I don't see a mouse cursor or anything.
A: Use arrow keys to navigate, Enter to go into submenus, and Escape twice to go back.

Q: How do I turn an option on or off in menuconfig?
A: Press the space bar to toggle binary options on or off.

Q: I'm lost in a submenu. How do I get back out?
A: Press Escape twice to go up a level or exit the current menu.

Q: Is there a help button if I don't understand what an option does?
A: Yes, press the H key to get help on any option or menu.

Q: I want to enable a bunch of things right away. Is that okay?
A: No, start small; it's relatively easy to break your configuration on the first attempt.

# Save your changes

Q: How do I save my changes when I'm done in menuconfig?
A: Keep pressing Escape until prompted to save; it saves to the .config file by default.

Q: Can I back up my kernel config somehow so I don't lose it?
A: Yes, just copy the .config file to save and reload your configuration anytime.

Q: After I've saved my kernel config, what's the next step?
A: After customising and saving, you're ready to go ahead and build the kernel.

# Whole Document

Q: Why would I even want to mess with the kernel configuration? What's the point?
A: You can enable new hardware support or experimental network protocols through kernel configuration.

Q: Is there an easier way to configure the kernel than editing config files by hand?
A: Yes, menuconfig is the recommended interface; editing .config manually is harder.

Q: I've never touched kernel settings before. Is this something a beginner should do?
A: It's for advanced users; beginners should start small and get comfortable with the process.
