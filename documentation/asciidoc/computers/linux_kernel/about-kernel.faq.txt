# Introduction

Q: Where's the Raspberry Pi kernel code actually hosted?
A: The Raspberry Pi kernel is hosted on GitHub at raspberrypi/linux.

Q: Is the Raspberry Pi kernel always up to date with the main Linux kernel?
A: No, Raspberry Pi kernel updates lag behind the upstream Linux kernel.

Q: How does Raspberry Pi decide when to update their kernel version?
A: They integrate long-term Linux releases, tested via a next branch before merging.

Q: What's this "next" branch I keep seeing mentioned in the Raspberry Pi firmware repo?
A: It's created for each long-term Linux release, merged after extensive testing and discussion.

# Update

Q: Do I need to manually update my kernel or does it just happen automatically?
A: The normal Raspberry Pi OS update process automatically updates your kernel.

Q: I want to try the newest kernel even if it's not totally stable. How do I do that?
A: You can manually update using the rpi-update process to get the latest unstable kernel.

Q: My Pi's kernel seems old. Will just doing a normal system update fix that?
A: Yes, the usual Raspberry Pi OS update process updates your kernel automatically.

Q: What's the difference between the stable kernel and the test kernel on Raspberry Pi?
A: Stable updates automatically; the unstable test kernel requires a manual update process.

# Whole Document

Q: So Raspberry Pi makes their own version of Linux? How does that even work?
A: They take long-term Linux releases, test them in a next branch, then merge them.

Q: I just want to know if my kernel will stay updated without me doing anything.
A: Yes, the standard Raspberry Pi OS update process keeps your kernel at the latest stable release.
