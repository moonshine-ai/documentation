# Common display options

Q: My Pi 4 is connected to a 4K monitor but it's only running at 30Hz. How do I get 60Hz?
A: Set `hdmi_enable_4kp60=1` in your config.txt to allow 60Hz selection.

Q: I enabled 4K 60Hz on my Pi 4 — can I run that on both HDMI ports at the same time?
A: No, Pi 4 doesn't support 4Kp60 output on both micro HDMI ports simultaneously.

Q: I turned on that 4K 60Hz setting and my Pi seems to be running hotter. Is that normal?
A: Yes, enabling 4Kp60 increases both power consumption and temperature on supported models.

# Common hardware configuration options

Q: I plugged in a camera but the Pi doesn't seem to see it. Do I need to configure anything?
A: Camera auto-detect is on by default and loads overlays for recognised CSI cameras automatically.

Q: How do I turn off the automatic camera detection on my Pi?
A: Set `camera_auto_detect=0` or remove `camera_auto_detect=1` from config.txt.

Q: I connected a DSI display and nothing's showing up. Does the Pi detect those automatically?
A: Yes, display auto-detect is enabled by default and loads overlays for recognised DSI displays.

Q: What even is a dtoverlay? I keep seeing it in config.txt and I don't know what it does.
A: It tells the firmware to load a config file enabling kernel support for built-in or external hardware.

Q: I want to enable I2C on my Pi. Is there a setting in config.txt for that?
A: Yes, use `dtparam` to enable I2C and SPI interfaces via Device Tree configuration parameters.

Q: What's the line length limit when adding overlay parameters in config.txt?
A: Keep overlay parameter lines under 98 characters when appending them to dtoverlay settings.

Q: My Pi 4B feels a bit slow. I heard there's a setting to boost the clock speed?
A: On supported Pi 4B revisions, `arm_boost` raises turbo-mode clock from 1.5GHz to 1.8GHz.

Q: How do I turn off that arm boost setting if I don't want it?
A: Set `arm_boost=0` in config.txt to disable the boosted turbo-mode clock speed.

Q: What does power_force_3v3_pwm actually do and which Pi models support it?
A: It forces PWM on 3.3V GPIO or CSI output, supported on Pi 5, 500, 500+, and Compute Module 5.

# Whole Document

Q: Where do all these config settings like dtoverlay and camera_auto_detect actually live on my Pi?
A: They're all set in the `/boot/firmware/config.txt` file on your Raspberry Pi.

Q: Do I need to manually set up camera and display overlays or does Raspberry Pi OS handle that?
A: Raspberry Pi OS enables auto-detect for both cameras and displays by default in config.txt.
