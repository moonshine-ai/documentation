# What is `config.txt`?

Q: What's config dot txt and why does my Raspberry Pi need it?
A: It's the Raspberry Pi's configuration file, replacing a conventional PC's BIOS.

Q: Where's the config dot txt file actually stored on my Pi?
A: It's in the boot partition, located at slash boot slash firmware slash.

Q: I'm on an older version of Raspberry Pi OS. Is the config file in a different place?
A: Before Bookworm, the boot partition was stored at slash boot slash.

Q: Do I have to shut down to edit config dot txt, or can I do it while it's running?
A: You can edit it directly from your running Raspberry Pi OS installation.

Q: I changed something in config dot txt but nothing happened. Do I need to restart?
A: Yes, changes to config dot txt only take effect after a reboot.

Q: How do I check what a specific config setting is currently set to?
A: Use vcgencmd get_config followed by the setting name to display it.

Q: I want to see all my integer config options at once. How do I do that?
A: Run vcgencmd get_config int to list all non-zero integer config options.

Q: Can I check all my string config settings in one go?
A: Yes, run vcgencmd get_config str to list all non-null string config options.

# File format

Q: What format does config dot txt use? Is it like a normal text file?
A: It uses simple property equals value statements, one per line, integers or strings.

Q: How do I comment something out in config dot txt so it's ignored?
A: Start the line with a hash character to comment it out or disable it.

Q: Is there a limit to how long each line in config dot txt can be?
A: Yes, there's a ninety-eight character line length limit per entry.

Q: What happens if I write a really long line in config dot txt?
A: Raspberry Pi OS ignores any characters past the ninety-eight character limit.

# Advanced features

Q: Can I split my config dot txt into multiple files to keep things tidy?
A: Yes, use the include directive to insert another file's contents into config dot txt.

Q: I want to use include in config dot txt. Are there any settings it won't work for?
A: Bootloader-handled settings only work if specified directly in config dot txt itself.

Q: Does the bootloader support the include directive in config dot txt?
A: No, bootcode dot bin and EEPROM bootloaders do not support the include directive.

# Whole Document

Q: I edited my Pi's config file from another computer. Is that actually allowed?
A: Yes, you can remove the storage and edit the boot partition from a separate computer.

Q: Not all my config settings show up when I run vcgencmd. Is that normal?
A: Yes, not all config settings can be retrieved using vcgencmd.

Q: I heard some config dot txt options are outdated. Where do I find out about those?
A: Legacy options are listed separately and aren't included in the main article.
