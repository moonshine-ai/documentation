# `total_mem`

Q: How do I make my Pi 4 act like it's got less RAM than it actually has?
A: Set `total_mem` in config to your desired RAM amount in megabytes.

Q: I've got a 4 gig Pi but I want it to only use 1 gig. How do I do that?
A: Add `total_mem=1024` to your config file to limit it to one gigabyte.

Q: Is there a minimum amount of memory I can set with that total mem thing?
A: Yes, the minimum value you can set is 128 megabytes.

Q: What happens if I set total mem to something higher than what's actually in my Pi?
A: It gets clamped to the maximum total memory actually installed on the board.

Q: Can I limit how much RAM my Raspberry Pi uses?
A: Yes, use the `total_mem` parameter to specify RAM in megabytes.
