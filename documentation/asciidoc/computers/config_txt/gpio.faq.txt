# `gpio`

Q: How do I set a GPIO pin to a specific mode at boot without making a custom dt-blob.bin file?
A: Use the `gpio` directive in `config.txt` to set pins at boot.

Q: Can I set multiple GPIO pins at once, or do I have to do them one at a time?
A: You can set a single pin, a range, or a comma-separated list together.

Q: I want GPIO12 to be an output that starts high. How do I write that?
A: Use `gpio=12=op,dh` to set GPIO12 as a high output.

Q: What's the difference between `pu` and `pd` in the gpio directive?
A: `pu` means pull up and `pd` means pull down for a pin.

Q: If I have two gpio lines that both affect the same pin, which one wins?
A: Settings appearing later in the file override those appearing earlier.

Q: I set a GPIO pin in config.txt but it's not showing up in sysfs. Is that normal?
A: Yes, gpio directive changes don't export pins to the sysfs interface.

Q: Can I use different GPIO settings depending on which Pi model I'm running?
A: Yes, the gpio directive respects conditional filters like model or serial number.

Q: I powered on my Pi but the GPIO changes didn't seem to happen right away. What's going on?
A: There's a delay of a few seconds before gpio directive changes take effect at boot.

Q: Will the GPIO settings I put in config.txt get overridden by anything?
A: Yes, Device Tree pinctrl entries and utilities like pinctrl can override them.

Q: I'm booting my Pi over the network and the GPIO changes seem really slow to kick in. Is that expected?
A: Yes, network or USB boot causes a longer delay before gpio changes take effect.

Q: How do I set pins 18 and 20 to use a pull-up resistor?
A: Use `gpio=18,20=pu` in your config.txt file.

# `enable_jtag_gpio`

Q: How do I enable the JTAG interface on my Raspberry Pi?
A: Add `enable_jtag_gpio=1` to config.txt to enable the JTAG interface.

Q: Which GPIO pins get used when I enable JTAG on the Pi?
A: JTAG uses GPIO pins 22 through 27 in Alt4 mode.

Q: Does the JTAG GPIO thing work on all Pi models or just certain ones?
A: It works on all models of Raspberry Pi.

Q: Which pin is ARM_TDI when I've got JTAG enabled?
A: GPIO26 is the ARM_TDI pin when JTAG is enabled.

# Whole Document

Q: I want to configure GPIO at boot time without writing any extra code. Is that possible?
A: Yes, use the `gpio` directive in config.txt to configure pins at boot.

Q: Do GPIO changes in config.txt affect what the Linux kernel sees?
A: No, they have no direct effect on the kernel at all.

Q: Can I use alt modes like Alt2 or Alt4 through the gpio directive in config.txt?
A: Yes, use attributes like `a2` or `a4` to select alternate pin modes.
