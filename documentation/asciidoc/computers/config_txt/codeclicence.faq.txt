# Whole Document

Q: Do I need to buy a licence key for my Raspberry Pi 4 to play MPEG2 files?
A: No, Pi 4 has disabled hardware decoders, software decoding works fine instead.

Q: I've got a Pi 5 — do I need any special licence for H.265 video?
A: No, Pi 5 has H.265 hardware decoding enabled by default, no licence needed.

Q: What's the deal with codec licence keys? Do I actually need one?
A: Only Pi 3 and earlier need purchased licence keys for additional hardware codecs.

Q: I have three Raspberry Pis and I keep swapping the same SD card between them. Do I need to update the config each time for codec licences?
A: No, you can list up to eight licence keys in one config.txt file.

# `decode_MPG2`

Q: What do I put in my config file to enable MPEG-2 hardware decoding?
A: Add decode_MPG2 followed by your licence key, like decode_MPG2=0x12345678.

Q: I bought an MPEG-2 licence key. Where does it go exactly?
A: Put it in config.txt using decode_MPG2 equals your licence key number.

# `decode_WVC1`

Q: How do I turn on hardware VC-1 decoding on my older Pi?
A: Add decode_WVC1 with your licence key in config.txt, like decode_WVC1=0x12345678.

Q: I've got licences for both MPEG-2 and VC-1. Do I need separate lines for each in the config?
A: Yes, use decode_MPG2 for MPEG-2 and decode_WVC1 for VC-1 separately.

Q: I bought codec licences for like five different Pis. Do I really have to have a different SD card for each one?
A: No, list up to eight licence keys comma-separated in one config.txt line.
