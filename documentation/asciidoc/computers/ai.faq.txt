# Hardware prerequisites

Q: What Pi do I need to run AI models with a Hailo NPU?
A: You need a Raspberry Pi 5 with 64-bit Raspberry Pi OS Trixie installed.

Q: I've got an AI Kit sitting around — can I still use it or is it too old?
A: AI Kit still works but it's no longer in production; use AI HAT+ for new designs.

Q: Do I need a camera to use the AI hardware, or is that optional?
A: Camera is only needed if you want to run vision AI models specifically.

Q: I want to do object detection with my Pi 5. What hardware do I need besides the board itself?
A: You need a Hailo NPU accessory and a supported camera like Camera Module 3.

Q: Should I attach the camera before or after the AI HAT?
A: Attach your camera first before attaching the AI hardware to your Pi.

# Software prerequisites

Q: What's the order of things I need to set up before running AI models?
A: Enable PCIe Gen 3, update the OS, install dependencies, then verify the hardware.

Q: Do I need to do the PCIe Gen 3 thing with the AI HAT Plus or just the AI Kit?
A: Only the AI Kit needs PCIe Gen 3 manually enabled; AI HAT+ applies it automatically.

Q: My Pi defaults to PCIe Gen 2. How do I bump it up to Gen 3 for the AI Kit?
A: Use raspi-config or add `dtparam=pciex1_gen=3` to your config.txt file.

Q: How do I enable PCIe Gen 3 using raspi-config?
A: Go to Advanced Options, then PCIe Speed, select Yes, finish, and reboot.

Q: What's the difference between the packages I install for the AI Kit versus the AI HAT Plus 2?
A: AI Kit and AI HAT+ use `hailo-all`; AI HAT+ 2 uses `hailo-h10-all` instead.

Q: Can I have both hailo-all and hailo-h10-all installed at the same time?
A: No, those two packages can't co-exist on the same system.

Q: How do I install the dependencies for the AI HAT Plus?
A: Run `sudo apt install dkms` then `sudo apt install hailo-all` in the terminal.

Q: After I install the Hailo stuff, how do I actually check it's working?
A: Run `hailortcli fw-control identify` and look for device info in the output.

Q: I ran the verify command and it shows N/A for serial number. Is something wrong?
A: That's expected for AI HAT+ and AI HAT+ 2 and doesn't affect functionality.

Q: How do I check the kernel logs to see if the Hailo driver loaded okay?
A: Run `dmesg | grep -i hailo` to see Hailo-related kernel log entries.

# Run vision AI models on Raspberry Pi 5

Q: What do I need to install to get the camera working with AI demos?
A: Install `rpicam-apps` using `sudo apt update && sudo apt install rpicam-apps`.

Q: How do I quickly test that my camera is set up right before running AI stuff?
A: Run `rpicam-hello` — it shows a preview window for five seconds if working.

Q: What's the command to run object detection with YOLOv8 on the camera?
A: Run `rpicam-hello -t 0 --post-process-file /usr/share/rpi-camera-assets/hailo_yolov8_inference.json`.

Q: Is there a YOLO model that's specifically designed for detecting people and faces?
A: Yes, YOLOv5 is described as handling people and face detection specifically.

Q: What if I want a really fast lightweight object detection option?
A: YOLOX is described as lightweight and fast for object detection.

Q: How do I do pose estimation? Like drawing the skeleton lines on a person?
A: Run `rpicam-hello -t 0 --post-process-file /usr/share/rpi-camera-assets/hailo_yolov8_pose.json`.

Q: Can I save a video with AI processing instead of just previewing it?
A: Yes, you can use `rpicam-vid` instead of `rpicam-hello` with compatible options.

Q: I don't want the preview window to pop up, I just want text output. How do I do that?
A: Add the `-n` flag to turn off the viewfinder display.

Q: How do I do image segmentation where it draws a colored mask over objects?
A: Run `rpicam-hello -t 0 --post-process-file /usr/share/rpi-camera-assets/hailo_yolov5_segmentation.json --framerate 20`.

Q: I need to use a specific version of the Hailo toolchain. How do I lock the packages to a matching version?
A: Install the specific version then run `sudo apt-mark hold` on the relevant packages.

# Run LLMs on Raspberry Pi 5 (AI HAT+ 2 only)

Q: Can I run a large language model locally on my Pi 5?
A: Yes, but only with the AI HAT+ 2, which has the Hailo-10H NPU on board.

Q: What are the two ways I can interact with an LLM once it's set up?
A: You can use POST requests to the API or the browser-based Open WebUI chat interface.

Q: Why do I need Docker to use Open WebUI? Can't I just install it normally?
A: Open WebUI is incompatible with Python 3.13 used on Trixie, so Docker is required.

Q: How do I start the Hailo Ollama server?
A: Just run `hailo-ollama` in a Raspberry Pi Terminal window.

Q: How do I get a list of the LLMs I can download and run?
A: Run `curl --silent http://localhost:8000/hailo/v1/list` after starting the server.

Q: I want to download a specific model to try out. What's the command for that?
A: Send a POST to `http://localhost:8000/api/pull` with the model name in the JSON body.

Q: The Open WebUI container is taking forever to start. Is something wrong?
A: It can take up to a minute to initialise; run `docker logs open-webui -f` to monitor progress.

Q: Once Open WebUI is running, how do I actually open it in my browser?
A: Go to `http://127.0.0.1:8080` in a browser to access the chat interface.

Q: Do I need to set up Open WebUI or can I just use the terminal to talk to the LLM?
A: Open WebUI is optional; you can just use terminal-based POST requests instead.
