# GPIO and the 40-pin header

Q: Does every Raspberry Pi have those GPIO pins along the edge?
A: All current Raspberry Pi boards have a 40-pin GPIO header.

Q: My Pi Zero doesn't seem to have any pins soldered on. Is that normal?
A: Zero devices without the "H" suffix ship unpopulated, with no headers soldered.

Q: What can I actually do with the GPIO pins?
A: Pins work as general-purpose input, output, or up to six alternate functions.

Q: Wait, the pin numbers don't seem to go in order. Am I reading the diagram wrong?
A: No, the GPIO numbering scheme is genuinely not in numerical order.

# Outputs

Q: So when a GPIO pin is set to high, what voltage does it actually output?
A: A high output pin is set to 3.3V; low is 0V.

# Inputs

Q: How do I read whether a GPIO pin is on or off?
A: Input pins read as high at 3.3V or low at 0V.

Q: Do I need to add my own pull-up resistors, or does the Pi handle that?
A: You can configure pull-up or pull-down resistors in software for most pins.

Q: I heard GPIO2 and GPIO3 are different from the other pins. What's special about them?
A: GPIO2 and GPIO3 have fixed pull-up resistors that can't be changed.

# View a GPIO pinout for your Raspberry Pi

Q: I can never remember which pin is which. Is there a quick way to check on the Pi itself?
A: Run the `pinout` command in a terminal to see a GPIO reference.

Q: Where does that pinout command come from? Do I need to install something?
A: It's provided by the GPIO Zero Python library, installed by default in Raspberry Pi OS.

# Permissions

Q: I added a new user and now they can't use the GPIO pins. What's going on?
A: New users must be manually added to the `gpio` group using `sudo usermod`.

Q: What's the exact command to give a user access to GPIO?
A: Run `sudo usermod -a -G gpio <username>` replacing username with theirs.

Q: Does the default Pi user already have GPIO access or do I have to set that up?
A: The default user account is already a member of the `gpio` group.

# GPIO pads

Q: I keep seeing the word "pads" in datasheets. Is that the same as the GPIO pins?
A: Yes, "pads" is a semiconductor term meaning the chip's connections to the outside world.

Q: What settings can I actually control on the GPIO pads?
A: You can configure pull-up/pull-down, drive strength, and Schmitt-trigger input filtering.

# Power-on states

Q: When I restart my Pi, do the GPIO pins stay in whatever mode I set them to?
A: No, all GPIO pins revert to general-purpose inputs on power-on reset.

# Interrupts

Q: Can a GPIO pin trigger something automatically when its state changes?
A: Yes, GPIO input pins can be configured as interrupt sources for the Arm processor.

Q: What kinds of events can trigger a GPIO interrupt?
A: Interrupts can trigger on high/low levels, rising/falling edges, or asynchronous edges.

# Alternative functions

Q: Can I use GPIO pins for I2C or SPI, or are those totally separate?
A: GPIO pins support alternate functions including I2C, SPI, PWM, and serial communication.

Q: Which pins support hardware PWM? I don't want to mess with software PWM.
A: Hardware PWM is available on GPIO12, GPIO13, GPIO18, and GPIO19.

Q: I want to set up I2C. Which GPIO pins do I use for that?
A: I2C data is on GPIO2 and clock is on GPIO3.

Q: What GPIO pins are used for serial TX and RX?
A: Serial TX is on GPIO14 and RX is on GPIO15.

# Voltage specifications

Q: I've got a 5V sensor. Can I just plug it into a GPIO pin?
A: No, GPIO pins are 3.3V-tolerant; don't connect 5V components directly.

Q: What's the maximum current I can pull from a GPIO output pin?
A: At maximum drive strength the output current is 18mA low and 17mA high.

Q: Are the voltage specs the same for a Pi 4 as older Pi models?
A: No, BCM2711-based Pi 4 series devices have different voltage specifications than older models.

# Whole Document

Q: I want to connect an LED directly to a GPIO pin. Anything I should watch out for?
A: Always use a resistor with LEDs to limit the current through them.

Q: Can I plug a motor straight into the GPIO pins?
A: No, use an H-bridge circuit or motor controller board instead.

Q: I'm totally new to this. What's the easiest way to get started with GPIO on a Pi?
A: Start with the `pinout` command and GPIO Zero library, installed by default in Raspberry Pi OS.
