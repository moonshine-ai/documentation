# Boot Sequence

Q: My Pi 3 isn't booting from USB by default. Do I need to turn that on somehow?
A: Yes, USB boot on Pi 3 may need enabling; check the USB mass storage boot page.

Q: What's the very first thing the BCM2837 checks when it boots up?
A: It reads the OTP memory block to see which boot modes are enabled.

Q: What file is the boot ROM actually looking for on each boot source?
A: The boot ROM searches each boot source for a file called bootcode.bin.

Q: My Pi takes forever to start when there's no SD card in it. Is there a way to speed that up?
A: Insert a blank SD card or use GPIO bootmode OTP to enable only USB boot.

Q: Can I make the USB boot timeout longer if my hard drive takes a while to spin up?
A: Yes, set program_usb_boot_timeout=1 in config.txt to extend timeout to five seconds.

Q: Does MSD boot or network boot happen first if both are available?
A: MSD boot takes precedence over Ethernet boot.

Q: Does the boot ROM support GUID partitions or just the old-style ones?
A: The boot ROM supports GUID partitioning, tested with Mac, Windows, and Linux drives.

Q: Does the first partition on my USB drive have to be FAT for MSD boot to work?
A: No, MSD boot will keep searching for a FAT partition beyond the first one.

Q: How do I boot a Raspberry Pi Zero from a PC over USB?
A: Leave the OTGID pin floating and push bootcode.bin using the usbboot code from GitHub.

Q: I've heard about GPIO boot mode but I don't really know what it does. What's it for?
A: GPIO boot mode lets specific GPIO lines refine which OTP-enabled boot modes are attempted.

Q: What's the product ID the Pi uses when it boots in USB device mode?
A: Pi 3 uses VID 0x0a5c and PID 0x2764 when booting in USB device mode.

Q: Does NAND boot actually work on the Pi, or is it just there in theory?
A: NAND boot works but doesn't yet have full GPU support.

Q: I've got a standalone LAN9500 chip. Will it work for network booting on my Pi?
A: No, you'd need an I2C EEPROM to change its IDs to match the LAN951x.

Q: Does this boot sequence stuff apply to the Pi 4 as well?
A: No, Pi 4 and Pi 5 use a different EEPROM bootflow described separately.

Q: Can I boot from a secondary SD card using a different set of GPIO pins?
A: It's theoretically possible but not yet enabled on the Raspberry Pi.
