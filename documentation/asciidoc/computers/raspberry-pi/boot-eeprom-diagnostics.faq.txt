# Boot diagnostics

Q: My Pi won't boot and I'm seeing some weird screen with info on it. What is that?
A: It's the bootloader diagnostics screen showing boot troubleshooting information.

Q: How do I get the diagnostics screen to show up on purpose?
A: Power down, disconnect your boot media like an SD card, then power back up.

Q: I disconnected my SD card and got this diagnostics screen. How do I get back to normal booting?
A: Reconnect your boot media, then power cycle or press the power button.

Q: There's a QR code on my Pi's boot screen. What does it link to?
A: It links to the Raspberry Pi software downloads page.

Q: What does the "boot" line on the diagnostics screen actually tell me?
A: It shows current boot mode, boot order, retry count, and restart cycles.

Q: I want to check if my SD card is being detected. Is there somewhere on that diagnostics screen that shows that?
A: Yes, the SD line shows whether your SD card is detected or not detected.

Q: My Pi's doing network boot and I want to see the TFTP server address. Where do I find that?
A: The tftp line on the diagnostics screen shows the TFTP server IP address.

Q: I don't want this diagnostics screen showing up every time. How do I turn it off?
A: Use the DISABLE_HDMI option in your bootloader configuration settings.

Q: I'm doing network boot and I can't tell if my connection is up. Does the diagnostics screen show that?
A: Yes, the net line shows link status, client IP, subnet, and default gateway.

Q: Does this boot diagnostics thing work on all Raspberry Pi models?
A: No, it only works on Raspberry Pi 4 or later flagship models.

Q: What info does the "board" line show on the diagnostics screen?
A: It shows board revision, serial number, and the Ethernet MAC address.

Q: How do I know if my HDMI display is being detected properly during boot?
A: The display line shows hotplug detection and whether EDID was read successfully.

Q: When would this diagnostics screen pop up automatically without me doing anything?
A: It appears automatically when the bootloader can't boot from any media or network.
