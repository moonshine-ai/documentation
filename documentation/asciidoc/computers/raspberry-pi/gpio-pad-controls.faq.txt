# GPIO pads control

Q: What's the difference between GPIO drive strength and maximum current? Aren't they the same thing?
A: Drive strength is max current where pad still meets spec, not a limit.

Q: I've got a device connected to a GPIO pin and it's not working right. Could the drive strength be wrong?
A: Yes, you should set drive strength to match the connected device's requirements.

# Control drive strength

Q: How does changing the drive strength actually work inside the chip?
A: More parallel drivers are enabled as drive strength increases, raising output current.

Q: I've got a Raspberry Pi 5 and the drive strength values look off. Is there something different about newer ones?
A: On 4-series devices, current level is half the value shown in the diagram.

# Current value

Q: I set my GPIO drive strength to 16mA — does that mean it'll always output exactly 16mA?
A: No, it's the maximum current where output voltage still meets specification.

Q: What voltage does a GPIO pin try to reach when you set it high?
A: The pad tries to drive output to the rail voltage, which is 3point3 volts.

Q: What happens if I accidentally short a GPIO pin that's set high to ground?
A: The pad tries to deliver maximum current and will eventually fail over time.

Q: What are VOL and VOH and why do they matter?
A: They're guaranteed minimum high and maximum low output voltage levels for GPIO.

Q: I set drive strength to 2mA but I'm drawing 16mA from the pin. Will the voltage still be correct?
A: No, output voltage won't meet the high-level guarantee and may not register correctly.

Q: Can I change the 3.3V reference voltage on a regular Pi to affect those GPIO voltage levels?
A: Only Compute Module devices support changing VDD IO from the standard 3point3 volts.

Q: I've got like 17 GPIO pins all running at once. Could that cause problems with my SD card?
A: Yes, overloading GPIO can collapse the 3point3 volt supply and interfere with the SD card.

Q: What's the maximum current the 3.3V supply was designed to handle per GPIO pin?
A: The 3point3 volt supply was designed for a maximum of around 3mA per pin.

# Safe current

Q: How much current can I pull from a GPIO pin before I actually damage the Pi?
A: Sixteen milliamps is the safe value that won't damage the device.

Q: Wait, so even if I set drive strength low but somehow draw 16mA, it won't break anything?
A: Correct, drawing 16mA even at low drive strength settings won't damage the device.

# GPIO addresses

Q: What's the memory address I need for controlling GPIO pins 0 through 27?
A: The pad control address for GPIO 0 to 27 is 0x7e10002c.

Q: What's the password I have to include when writing to the GPIO pad registers?
A: You must write 0x5A in bits 31 to 24 as accidental write protection.

Q: What's the default setting for slew rate on GPIO pads, limited or not?
A: Default slew rate setting is zero, meaning slew rate is limited by default.

Q: Is input hysteresis turned on or off by default on GPIO pins?
A: Input hysteresis is enabled by default, with a reset value of one.

# Drive strength list

Q: What number do I set if I want 8mA drive strength on a GPIO pin?
A: Set drive strength to 3 for 8mA output.

Q: What's the highest drive strength value I can set and what current does that give?
A: The highest setting is 7, which gives 16mA drive strength.

Q: I want 12mA on my GPIO pin. What value do I write to the drive strength register?
A: Write the value 5 to the drive strength register for 12mA.

# Whole Document

Q: I'm worried about lots of GPIO pins switching at the same time. Is that a real problem?
A: Yes, simultaneous switching outputs have limitations depending on PCB quality and load type.

Q: So basically GPIO pins are voltage sources not current sources, right? What does that actually mean?
A: Yes, pads drive toward a voltage and deliver whatever current the load demands.

Q: Is there any risk to my Pi if I load up too many GPIO pins with high current draws?
A: Yes, total high current draw can collapse the 3point3 volt supply and cause instability.
