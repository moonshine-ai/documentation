# Frequency management and thermal control

Q: My Pi is getting really hot. What temperature does it start slowing down?
A: Throttling begins between 80°C and 85°C, with full throttle at 85°C.

Q: Can I set the max temperature higher than 85 degrees on my Pi?
A: No, you can set it lower than 85°C but not higher than that.

Q: Why does my Pi seem slower when it gets warm?
A: The Pi reduces CPU and GPU frequencies to lower heat and stay under 85°C.

# Use DVFS

Q: What even is DVFS? Do I need to worry about it?
A: DVFS lets Pi 4 run cooler by reducing voltage when full speed isn't needed.

Q: Which Pi models actually support this DVFS thing?
A: DVFS applies only to 4-series devices: Pi 4, Compute Module 4, and Pi 400.

Q: I've got a headless Pi 4 server. Is there a DVFS setting that saves power?
A: Use dvfs=1 for power savings on headless systems, but it risks PCIe instability.

Q: What's the default DVFS mode on Pi 4?
A: The default is dvfs=3, which scales voltage up on demand for overclocking.

Q: I set over_voltage in config.txt and now I'm wondering if DVFS still works.
A: Setting over_voltage disables dynamic voltage scaling, reverting the system to dvfs=2.

Q: How do I switch my Pi to use the powersave CPU governor?
A: Install cpufrequtils and run sudo cpufreq-set -g powersave in the terminal.

Q: Does DVFS apply to my Pi 5?
A: No, DVFS settings are removed on 5-series devices, which always use mode 3.

# Measure temperatures

Q: How do I actually check the temperature of my Pi right now?
A: Run vcgencmd measure_temp in the terminal for an accurate SoC temperature reading.

Q: I tried checking the temp through Linux and got a weird number. Is that normal?
A: Yes, Linux-based temperature readings can be inaccurate due to SoC architecture.

Q: What's the most accurate way to see my Pi's current temperature?
A: Use vcgencmd measure_temp, as it communicates directly with the GPU.

# Add heat sinks

Q: Do I actually need a heatsink or will my Pi just fry without one?
A: Heatsinks aren't necessary thanks to built-in throttling, but they reduce performance slowdowns.

Q: What's the best way to position my Pi to keep it cool?
A: Mount your Raspberry Pi vertically for best airflow and slightly improved heat dissipation.

# Fan cases

Q: Does the Pi control the fan speed automatically or do I have to manage it?
A: Raspberry Pi firmware automatically manages fan speeds for all official fans.

Q: I've got a Pi 5 and want to overclock it. Which fan should I get?
A: The Active Cooler is recommended for overclockers because it provides better cooling performance.

Q: Where does the fan plug into on a Pi 5?
A: It plugs into the four-pin JST-SH PWM connector between the GPIO header and USB 2 ports.

Q: At what temperature does the Pi 5 fan actually turn on?
A: The fan turns on at 30% speed when the Pi 5 reaches 50°C.

Q: My Pi 5 fan was running and then it slowed down. Is something wrong?
A: No, fan speed decreases when temperature drops 5°C below each speed threshold.

Q: Can I change when the Pi 5 fan kicks in? Like make it stay off longer?
A: Yes, use fan_tempN dtoverlay settings in config.txt to adjust temperature thresholds.

Q: What are the four pins on the Pi 5 fan connector?
A: The four pins are 5V, PWM, GND, and Tach, with red, blue, black, and yellow wires.

Q: How does the Pi 5 know if the fan is actually working?
A: At boot the fan spins and the tachometer input is checked to confirm it's spinning.

# Whole Document

Q: My Pi keeps throttling under heavy load. What are my options to fix that?
A: Add a heatsink, fan, or mount vertically; these reduce throttling and improve performance.

Q: I've got a Pi 3 B+. Is there anything special about how it handles heat?
A: It has better PCB heat dissipation and a soft limit at 60°C that reduces clock speed.

Q: What's the soft temperature limit on the Pi 3 B+ and can I change it?
A: Default soft limit is 60°C; change it using temp_soft_limit in config.txt.

Q: Does the Pi 4 have a soft temperature limit like the Pi 3 B+?
A: No, there is currently no soft temperature limit defined for the Pi 4.
