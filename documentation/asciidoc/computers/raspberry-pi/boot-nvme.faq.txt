# NVMe SSD boot

Q: Can I boot my Raspberry Pi 5 from an NVMe drive?
A: Yes, using an M.2 HAT+ or M.2 HAT+ Compact with additional configuration.

Q: What hardware do I need to connect an NVMe drive to my Pi 5?
A: You need an NVMe M.2 SSD and the M.2 HAT+ or M.2 HAT+ Compact adapter.

Q: I've got a Compute Module 4, what adapter do I need for NVMe?
A: Search for a PCI-E 3.0 x1 lane to M.2 NGFF M-Key SSD NVMe adapter card.

Q: How do I check if my NVMe drive is actually connected and recognized?
A: Boot from an SD card and run `ls -l /dev/nvme*` to check.

# Edit the bootloader boot priority

Q: How do I set my Pi to boot from NVMe instead of the SD card?
A: Run `sudo raspi-config`, go to Advanced Options, then Boot Order, and select NVMe.

Q: I've got a CM4 with eMMC, anything special I need to do to boot from NVMe?
A: Set NVMe first in boot order and add boot mode 6 to BOOT_ORDER in recovery/boot.conf.

Q: Does CM4 Lite automatically try to boot from NVMe?
A: Yes, CM4 Lite automatically boots from NVMe when the SD card slot is empty.

# NVMe `BOOT_ORDER`

Q: What boot mode number do I use for NVMe in the EEPROM config?
A: Use boot mode 6 for NVMe boot in the BOOT_ORDER setting.

# Example

Q: What does my Pi show in the terminal when it's booting from NVMe?
A: It shows "NVME (06)" in the boot mode output, then loads start4.elf and the kernel.

Q: Once it's booted, how does Linux name my NVMe drive?
A: The SSD appears as `/dev/nvme0` and the namespace as `/dev/nvme0n1`.

Q: My NVMe drive booted but I want to check how the partitions are set up. How do I do that?
A: Run `lsblk` to check partition assignments on the NVMe drive.

Q: What partitions should I expect to see on my NVMe drive after booting?
A: Expect two partitions: nvme0n1p1 as FAT for boot firmware and nvme0n1p2 as EXT4.

# Troubleshooting

Q: My Pi won't boot from the NVMe drive. Where do I report the problem?
A: File an issue on the rpi-eeprom GitHub repository and attach your console output.

Q: What should I include when I report an NVMe boot failure?
A: Attach a copy of the console and anything displayed on screen during boot.

# Whole Document

Q: Do I need to update my Pi's software before setting up NVMe boot?
A: Yes, run `sudo apt update && sudo apt full-upgrade` to ensure software is current.

Q: What PCIe slots can I use to connect an NVMe drive on a Raspberry Pi?
A: CM4 IO Board PCIe slot, CM5 IO Board M.2 slot, or Pi 5 with an M.2 HAT+.
