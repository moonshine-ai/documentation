# BCM2835

Q: What Raspberry Pi models actually use the BCM2835 chip?
A: Pi 1 Models A, A+, B, B+, Pi Zero, Zero W, and Compute Module 1.

Q: I've got a Raspberry Pi Zero — what processor is inside it?
A: The BCM2835 chip with a single-core ARM1176JZF-S processor inside.

Q: What kind of processor is in the original Raspberry Pi B+?
A: It uses a single-core ARM1176JZF-S processor on the BCM2835 chip.

Q: I'm reading the BCM2835 spec sheet and something seems wrong. Is that normal?
A: Yes, the peripheral specification document is known to contain errors.

Q: Is there somewhere I can check if the errors I'm seeing in the BCM2835 docs are already known about?
A: Yes, a list of known errata is available at elinux.org/BCM2835_datasheet_errata.

Q: Where do I find more info about the ARM1176JZF-S processor specifically?
A: ARM documentation for the ARM1176JZF-S is linked from the BCM2835 page.

Q: Does the Compute Module use the same chip as the regular Pi 1?
A: Yes, the Compute Module 1 uses the same BCM2835 chip as the Pi 1.

Q: Where can I find the GPU docs for the BCM2835?
A: GPU documentation and open-source driver docs are available via Broadcom's website.
