# BCM2836

Q: What Pi model used the BCM2836 chip?
A: BCM2836 was used in early models of the Raspberry Pi 2 Model B.

Q: What's the difference between the BCM2835 and BCM2836 chips?
A: BCM2836 replaces the ARM1176JZF-S with a quad-core Cortex-A7 cluster.

Q: I've got an older Pi 2 and I'm trying to find technical docs for it. Where do I look?
A: Check the BCM2836 ARM-local peripherals and Cortex-A7 MPcore Processor Reference Manual.

Q: Is the BCM2836 still being made or is it discontinued?
A: BCM2836 is discontinued; later Pi 2 Model B revisions use a different chip.

Q: My Pi 2 doesn't seem to match what I'm reading about BCM2836. What's going on?
A: Later Raspberry Pi 2 Model B revisions use a different SoC, not BCM2836.

Q: Is the BCM2836 basically the same as the BCM2835 under the hood?
A: Yes, the underlying architecture of BCM2836 is identical to BCM2835.

Q: Where can I find the reference manual for the processor inside the BCM2836?
A: The Cortex-A7 MPcore Processor Reference Manual is available at the ARM developer site.
