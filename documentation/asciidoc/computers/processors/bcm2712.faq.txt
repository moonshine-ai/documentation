# BCM2712

Q: What Raspberry Pi products use the BCM2712 chip?
A: BCM2712 is used in Raspberry Pi 5, 500, 500+, and Compute Module 5.

Q: How fast is the CPU in the Raspberry Pi 5?
A: The quad-core Arm Cortex-A76 runs at up to 2.4 GHz.

Q: How much faster is the Pi 5 compared to the Pi 4?
A: BCM2712 delivers a 2 to 3 times performance uplift over Raspberry Pi 4.

Q: Does the Pi 5 support playing 4K video?
A: Yes, it supports 4Kp60 HEVC hardware decode and dual 4Kp60 display output.

Q: What graphics API does the Pi 5 GPU support? Like does it do Vulkan?
A: VideoCore VII supports OpenGL ES 3.1 and Vulkan 1.3.

Q: I want to run two 4K monitors off my Pi 5. Is that actually possible?
A: Yes, BCM2712 includes an HDMI controller capable of driving dual 4Kp60 displays.

Q: What happens with H264 video if there's no hardware decoder for it?
A: H264 runs in software, using roughly 10 to 60 percent CPU depending on resolution.

Q: How much cache does the Pi 5 CPU have?
A: Each core has 512 kB L2 cache, plus a 2 MB shared L3 cache.

# Vulnerabilities and mitigations

Q: Does the Pi 5 have any security vulnerabilities I should worry about?
A: Known Cortex-A76 vulnerabilities exist but are all mitigated in Raspberry Pi OS.

Q: How do I check what security vulnerabilities my Raspberry Pi has?
A: Run lscpu piped through grep Vulnerability to list active mitigations.

Q: I'm using a third-party OS on my Pi 5. Should I be worried about security?
A: Third-party OSes may not include all latest kernel-level mitigations, so check carefully.

Q: Wait, how does Raspberry Pi fix CPU vulnerabilities if there's no microcode?
A: Arm processors used by Raspberry Pi don't use microcode, so all mitigations are kernel-level.

Q: The vulnerability list in the docs looks old. Is it still accurate?
A: The list was correct as of April 2025 but may have been superseded; run lscpu yourself.

Q: Where can I find more info about the CPU security issues from Arm directly?
A: Check developer.arm.com Arm Security Center using the Vendor ID from lscpu output.

# Whole Document

Q: What's the difference between the BCM2712 and the BCM2711?
A: BCM2712 succeeds BCM2711, sharing architectural features but with significant performance improvements.

Q: What's the memory bandwidth like on the Pi 5?
A: The 32-bit LPDDR4X interface provides up to 17 GB per second of memory bandwidth.

Q: Does the Pi 5 have PCIe support?
A: Yes, it has both times-one and times-four PCIe interfaces for high-bandwidth external peripherals.
