# BCM2837

Q: What Raspberry Pi models actually use the BCM2837 chip?
A: Early Pi 3 Model B, some Pi 2 Model B, and Compute Module 3.

Q: How fast are the CPU cores on the BCM2837?
A: The Arm cores run at 1.2 GHz on the BCM2837.

Q: I've heard the Pi 3 is faster than the Pi 2 — how much faster are we talking?
A: The BCM2837 makes it about 50% faster than the Raspberry Pi 2.

Q: What speed does the VideoCore IV run at on this chip?
A: The VideoCore IV runs at 400 MHz on the BCM2837.

Q: What's actually different between the BCM2836 and BCM2837? They sound almost the same.
A: The BCM2837 swaps the Armv7 cores for quad-core Arm Cortex A53 Armv8 cores.

Q: Is the BCM2837 still being made, or is it discontinued?
A: The BCM2837 is discontinued; affected devices are End-of-Life or use different SoCs.

Q: Where do I look if I want the peripherals documentation for the BCM2837?
A: Check the BCM2836 Arm-local peripherals document, as it also applies to BCM2837.

Q: What processor architecture does the BCM2837 use?
A: It uses a quad-core Arm Cortex A53, which is an Armv8 architecture.
