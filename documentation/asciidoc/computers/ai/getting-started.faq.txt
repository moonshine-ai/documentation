# Hardware prerequisites

Q: What Pi do I need to run AI models with a Hailo NPU?
A: You need a Raspberry Pi 5 with 64-bit Raspberry Pi OS Trixie installed.

Q: I've got an old AI Kit sitting around, can I still use it or is it discontinued?
A: AI Kit is no longer in production; use AI HAT+ or AI HAT+ 2 for new designs.

Q: Do I need a camera to use the AI accelerator, or is that optional?
A: A camera is only required if you want to run vision AI models specifically.

Q: Which camera should I get for running vision AI stuff on my Pi 5?
A: Raspberry Pi Camera Module 3 is recommended as a supported camera option.

Q: Should I plug the camera in before or after attaching the AI hardware?
A: Attach your camera before attaching your AI hardware, the docs recommend it.

Q: What's the difference between the AI HAT+ and the AI HAT+ 2?
A: AI HAT+ 2 additionally supports Generative AI models including Large Language Models.

# Software prerequisites

Q: What do I actually need to do software-wise before I can start running AI models?
A: Enable PCIe Gen 3, update your OS, install dependencies, then verify hardware detection.

Q: Do I need to enable PCIe Gen 3 if I've got the AI HAT+ 2?
A: No, PCIe Gen 3 is automatically applied for AI HAT+ and AI HAT+ 2.

Q: I just got my AI Kit set up, do I need to do anything special to get full speed out of it?
A: Enable PCIe Gen 3.0 for full speed; it's not enabled by default on the AI Kit.

Q: How do I enable PCIe Gen 3 without editing config files?
A: Run raspi-config, then choose Advanced Options, PCIe Speed, and select Yes.

Q: What line do I add to config.txt to enable PCIe Gen 3?
A: Add the line `dtparam=pciex1_gen=3` to your `/boot/firmware/config.txt` file.

Q: I installed the Hailo dependencies but I'm not sure which package to use for my AI Kit.
A: AI Kit and AI HAT+ use `hailo-all`; AI HAT+ 2 uses `hailo-h10-all` instead.

Q: Wait, can I have both hailo-all and hailo-h10-all installed at the same time?
A: No, those two packages can't co-exist on the same system.

Q: How do I check that my NPU is actually working after I've installed everything?
A: Run `hailortcli fw-control identify` and check for device information in the output.

Q: My AI HAT+ 2 shows N/A for serial number, is that broken?
A: That's expected for AI HAT+ and AI HAT+ 2; it doesn't affect functionality at all.

Q: How do I check the kernel logs to see if Hailo loaded properly?
A: Run `dmesg | grep -i hailo` to check the kernel logs for Hailo entries.

# Run vision AI models on Raspberry Pi 5

Q: What's the first thing I need to install to get camera AI demos working?
A: Install `rpicam-apps`, which includes the Hailo post-processing demo stages needed.

Q: How do I check my camera is working before trying AI demos?
A: Run `rpicam-hello`; it shows a preview window for five seconds if working correctly.

Q: I want to detect objects in real time with my camera, what command do I run?
A: Use `rpicam-hello -t 0 --post-process-file` with one of the YOLO inference JSON files.

Q: What's the difference between the YOLO models available for object detection?
A: Different models have speed and accuracy tradeoffs; YOLOX is described as lightweight and fast.

Q: Is there a demo that detects people specifically rather than general objects?
A: Yes, YOLOv5 is listed for people and face detection specifically.

Q: Can I do image segmentation with this, like mask out objects in the camera feed?
A: Yes, use the `hailo_yolov5_segmentation.json` post-processing file with rpicam-hello.

Q: Is there a pose detection demo I can try, like tracking where people's joints are?
A: Yes, run rpicam-hello with `hailo_yolov8_pose.json` for 17-point human pose estimation.

Q: I want to record video with AI processing, not just preview. Can I do that?
A: Yes, you can use `rpicam-vid` instead of `rpicam-hello` with some command line adjustments.

Q: I don't want the preview window showing, I just want text output from the AI. How?
A: Add the `-n` flag to turn off the viewfinder, and `-v 2` for text output only.

Q: How do I lock my AI Kit to a specific version of the Hailo software?
A: Install the specific package versions then run `sudo apt-mark hold` on those packages.

Q: I need to downgrade to Hailo version 4.17, what packages do I install?
A: Install `hailo-tappas-core=3.28.2 hailort=4.17.0 hailo-dkms=4.17.0-1` via apt.

# Run LLMs on Raspberry Pi 5 (AI HAT+ 2 only)

Q: Can I run a large language model locally on my Pi, like ChatGPT but offline?
A: Yes, but only with AI HAT+ 2 using the Hailo-10H NPU for local LLM inference.

Q: What are the two ways I can talk to a local LLM running on my Pi?
A: You can use POST requests to the API or a browser-based Web UI frontend.

Q: What's the hailo-ollama server actually doing when I run LLMs?
A: It loads LLMs, manages inference on the Hailo-10H NPU, and exposes a REST API.

Q: Do I need the web interface to run LLMs, or can I just use the terminal?
A: The web interface is optional; you can interact via terminal-based POST requests instead.

Q: Why does Open WebUI need Docker? Can't it just run normally?
A: Open WebUI is incompatible with Python 3.13 used on Raspberry Pi OS Trixie.

Q: How do I download a specific LLM model to run on my Pi?
A: Send a POST request to `http://localhost:8000/api/pull` with your chosen model name.

Q: How do I get a list of LLMs I can actually run on the AI HAT+ 2?
A: Run `curl --silent http://localhost:8000/hailo/v1/list` after starting hailo-ollama.

Q: How do I send a question to the LLM once it's running?
A: POST to `http://localhost:8000/api/chat` with your model name and message content.

Q: I installed Docker and Open WebUI, what address do I go to in my browser?
A: Open your browser and go to `http://127.0.0.1:8080` to access the chat interface.

Q: The Open WebUI container seems to be taking forever to start, is that normal?
A: Yes, it can take up to a minute to initialise; check logs with `docker logs open-webui -f`.

# Whole Document

Q: What even is an NPU, and why would I want one for my Pi?
A: An NPU is an AI accelerator that runs neural networks more efficiently than the CPU.

Q: So I've got a Pi 5, which AI add-on board should I get?
A: AI HAT+ or AI HAT+ 2 are recommended; AI Kit is no longer in production.

Q: What Pi OS version do I need for all this AI stuff to work?
A: You need 64-bit Raspberry Pi OS Trixie installed on your Raspberry Pi 5.

Q: Can the AI HAT+ 2 do everything the AI HAT+ can, plus more?
A: Yes, AI HAT+ 2 runs vision AI models and additionally supports GenAI including LLMs.

Q: I want to run both vision AI and LLMs on my AI HAT+ 2, do I need to follow different instructions?
A: Yes, follow both the vision AI instructions and the separate LLM instructions for that.
