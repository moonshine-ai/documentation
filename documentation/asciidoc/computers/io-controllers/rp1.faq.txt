# Whole Document

Q: What even is RP1? I keep seeing it mentioned but I don't really know what it does.
A: RP1 is an in-house chip managing USB, Ethernet, GPIO, and storage interfaces.

Q: Is RP1 something I can buy separately for my own projects?
A: No, RP1 isn't sold separately; it's built into Raspberry Pi 5 and Compute Module 5.

Q: Wait, does RP1 stand for the original Raspberry Pi Model B or something?
A: No, RP1 is not short for the first Raspberry Pi single-board computer.

Q: Why did Raspberry Pi build their own chip instead of just using the main processor for everything?
A: RP1 moves high-speed serial interfaces off the more expensive main processor node.

# RP1 overview

Q: How big is the RP1 chip physically?
A: RP1 measures approximately 12 by 12 millimetres in a BGA package.

Q: How does RP1 actually connect to the main processor on a Pi 5?
A: RP1 connects to the BCM2712 main CPU over a PCIe 2.0 x4 link.

Q: So the Pi 5 uses two chips to handle everything? How does that work?
A: The CPU handles core processing while RP1 manages peripherals, continuing a two-chip architecture.

# Peripheral interfaces

Q: Does RP1 give you more USB bandwidth than the Pi 4?
A: Yes, RP1 provides more than twice the usable USB bandwidth compared to Raspberry Pi 4.

Q: What USB ports does RP1 actually support?
A: RP1 has two host controllers, each with one USB 3.0 and one USB 2.0 port.

Q: Can RP1 handle camera and display connections at the same time?
A: Yes, RP1 has two 4-lane MIPI transceivers supporting both DSI displays and CSI-2 cameras.

Q: Does RP1 support GPIO and stuff like I2C and SPI?
A: Yes, RP1 includes GPIO, SPI, I2C, UART, PWM, and I2S as low-speed peripherals.

# Internal features

Q: Does RP1 have its own processors inside it or something?
A: Yes, RP1 integrates two Cortex M3 processors with tightly-coupled memories.

Q: What kind of memory does RP1 have built in?
A: RP1 includes 64 kilobytes of shared SRAM.

Q: Does RP1 have a temperature sensor or anything like that built in?
A: Yes, RP1 includes a 12-bit ADC with a built-in temperature sensor.

# Multimedia and audio components

Q: Can the Pi 5 output composite video through RP1?
A: Yes, but only one composite channel of the 3-channel video DAC is used on Pi 5.

Q: Does RP1 support microphone input or just audio output?
A: RP1 includes a PDM microphone clock generator and stereo bitstream input.

Q: I want to connect a display directly to GPIO pins. Does RP1 support that?
A: Yes, RP1 includes a DPI video frame generator for displays connected to GPIO pins.

Q: Can RP1 do audio without needing an extra chip or codec?
A: Yes, RP1 supports simple audio generation without external codecs using delta-sigma PWM audio out.

# RP1 naming

Q: Why is it called RP1? What does the name actually mean?
A: RP stands for Raspberry Pi, and the number refers to its first-generation I/O controller chip.
