# Set up your Raspberry Pi

Q: Do I need to unplug my Pi before connecting the SD card and other stuff?
A: Yes, unplug the power supply before connecting any peripherals or storage.

Q: I just inserted my SD card and plugged everything in. How do I know it's actually turning on?
A: The status LED lights up when your Raspberry Pi powers on successfully.

Q: How long should I wait before I see something on my screen after plugging in?
A: You should see the boot screen on your display within minutes of powering on.

# Configuration on first boot

Q: I set everything up in Imager already. Do I still have to go through a setup wizard?
A: No, if you customised the OS in Imager, your device is already ready to use.

Q: My Pi's been on for like five minutes and nothing's happening. What do I do?
A: Check the status LED; if it's flashing, look up the LED warning flash codes.

Q: It just won't boot at all. What can I try?
A: Try booting from an SD card, re-imaging it, or updating the bootloader first.

Q: I skipped all the customisation in Imager. Will it ask me to set things up later?
A: Yes, your Raspberry Pi runs a configuration wizard on the very first boot.

Q: Do I need a mouse to get through the setup wizard?
A: A monitor and keyboard are required for the wizard; a mouse is optional.

# Bluetooth

Q: I've got a Bluetooth keyboard. Will the Pi find it automatically during setup?
A: Yes, the Pi scans for pairable devices and connects to the first one it finds.

Q: I don't have built-in Bluetooth on my Pi. Can I still use a Bluetooth keyboard with a USB adapter?
A: Yes, it works with a USB Bluetooth adapter; just plug it in before booting.

# Locale

Q: Where do I set my language and time zone during setup?
A: The Locale page lets you configure country, language, time zone, and keyboard layout.

# User

Q: What's the default username when setting up a Raspberry Pi?
A: Older versions of Raspberry Pi OS set the default username to "pi."

Q: I'm using the username "pi" — is there a password I should avoid?
A: Yes, avoid the old default password "raspberry" to keep your Pi secure.

# Wi-Fi

Q: Can I connect to Wi-Fi during the first boot setup?
A: Yes, the Wi-Fi page lets you choose a network and enter a password if needed.

# Browser

Q: Can I pick which browser I want during setup, like Firefox or Chrome?
A: Yes, you can choose Firefox or Chromium as your default browser during setup.

Q: If I pick one browser, can I just get rid of the other one?
A: Yes, you can optionally uninstall whichever browser you don't set as default.

# Raspberry Pi Connect

Q: What's Raspberry Pi Connect and why would I want to turn it on?
A: It lets you access your Raspberry Pi remotely with no manual network configuration needed.

# Software updates

Q: Should I bother doing the software update during the wizard or can I skip it?
A: The wizard can update your OS and software to latest versions if you have internet.

Q: How long do updates take during first setup?
A: Updates may take several minutes; a Raspberry Pi 500's first update can take thirty minutes.

Q: What happens to the browser I said I wanted to uninstall — when does it actually get removed?
A: It gets removed during the software update step of the wizard.

# Finish

Q: Once the wizard's done, do I have to do anything or does it just restart itself?
A: Click Restart at the end of the wizard to reboot and apply your configuration.

# Whole Document

Q: I've never set up a Raspberry Pi before. What's the basic order of steps?
A: Install OS, connect storage and peripherals, power on, then complete the setup wizard.

Q: Do I need a display to set my Pi up from scratch?
A: A monitor is needed for the first-boot configuration wizard if you skipped Imager customisation.
