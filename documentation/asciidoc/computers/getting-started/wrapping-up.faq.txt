# Whole Document

Q: My Pi's all set up, what should I do next to get started?
A: Install recommended software, follow tutorials, and visit the Raspberry Pi forums.

Q: Where do I even find extra apps to install on my Raspberry Pi?
A: Click the raspberry icon, then go to Preferences and Recommended Software.

Q: I don't want to use the terminal to install stuff. Is there another way?
A: Yes, use the package manager GUI found under Preferences and Recommended Software.

# Recommended Software

Q: I want to write documents on my Pi. Is there anything like Microsoft Word I can use?
A: LibreOffice is available for writing and editing documents and spreadsheets.

Q: Wait, is the extra software free or do I have to pay for it?
A: You can install a wide variety of recommended software for free.

Q: I've got someone who needs a screen reader on the Pi. Is that a thing?
A: Yes, the Orca screen reader is available under Universal Access in recommended software.

Q: My vision isn't great. Are there any accessibility tools I can get for Raspberry Pi OS?
A: A screen magnifier and Orca screen reader are available under Universal Access.

# Tutorials

Q: I've never coded before. Is there somewhere I can learn using my Pi?
A: Raspberry Pi tutorials can teach you coding, external device control, and project building.

Q: I want to do cool projects with my Pi. Where do I go for ideas?
A: Visit raspberrypi.com/tutorials for projects involving coding and controlling external devices.

# Support

Q: I'm having trouble with my Pi and I don't know who to ask. Where should I go?
A: Visit the Raspberry Pi forums for support and to connect with other users.

Q: Is there like a community of other Pi users I can talk to if I get stuck?
A: Yes, the Raspberry Pi forums let you connect with other Raspberry Pi users.
