# Install Samba on your Raspberry Pi

Q: Does Raspberry Pi OS come with Samba already installed?
A: No, Samba is not included by default in Raspberry Pi OS.

Q: How do I install Samba on my Pi?
A: Run sudo apt update then sudo apt install samba samba-common-bin smbclient cifs-utils.

Q: What does installing Samba actually give me, like what can I do with it?
A: You can share folders between Windows, macOS, and Linux machines.

# Mount a folder shared from Windows

Q: I want to access a folder from my Windows PC on my Pi. Where do I even start?
A: First you need to enable sharing on your Windows device before mounting.

Q: I'm trying to mount a Windows share but I'm not sure what the command looks like. What do I type?
A: Use sudo mount.cifs followed by the hostname, share name, mount point, and username.

Q: What info do I actually need to mount a Windows folder on my Pi?
A: You need the Windows PC hostname or IP address, share name, and a Windows username.

Q: After I mount the Windows share, how do I check it worked?
A: Run ls windowshare/ to view the contents of the mounted Windows share.

Q: I'm getting a "host is down" error when trying to mount a Windows share. What's going on?
A: SMB protocol versions don't match; append a version like vers=1.0 to your mount command.

Q: My NAS is giving me a host is down error. What version should I try?
A: Older devices like some NAS may require version 1.0; try appending vers=1.0.

Q: What SMB version does my Raspberry Pi use by default?
A: Raspberry Pi OS uses SMB versions 2.1 and above by default, compatible with Windows 7.

Q: What SMB version do I need for a Windows 10 machine?
A: Windows 10 uses SMBv3.1.1, which corresponds to version 3.11.

Q: I've got a Windows 7 PC. What SMB version should I be using?
A: Windows 7 uses the SMBv2.1 protocol, corresponding to version 2.1.

# Sharing a Folder from your Raspberry Pi

Q: How do I share a folder from my Pi so Windows or Mac computers can see it?
A: Create a shared folder, set a Samba password, and add the folder config to smb.conf.

Q: I set up the shared folder but Windows still can't connect. What credentials do I use?
A: Enter your Raspberry Pi username and password to mount the shared folder.

Q: Where do I add the folder sharing settings in Samba?
A: Add the share configuration at the end of the file /etc/samba/smb.conf.

Q: Will people connecting to my shared Pi folder be able to write files, or just read them?
A: The configuration sets read only to no and writable to yes, allowing read and write.

Q: I've got a Windows workgroup set up. Do I need to configure that in Samba anywhere?
A: Yes, find the workgroup line in smb.conf and change it to match your Windows network.

Q: What's the smbpasswd command for and when do I need to run it?
A: It sets your Samba password for the user account that will be used to access the shared folder.

Q: What even is Samba? Do I need it to share files between my Pi and my Windows PC?
A: Samba is a free reimplementation of SMB protocol for sharing folders across different operating systems.

Q: Can I use my Pi to both access Windows shares and share its own folders?
A: Yes, installing Samba supports both running a Samba server and a Samba client.

Q: I just want to share files between my Pi and my Mac. Will Samba work for that?
A: Yes, Samba lets you share folders between Windows, macOS, and Linux machines.
