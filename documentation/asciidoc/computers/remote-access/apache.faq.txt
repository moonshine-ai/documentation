# Set up an Apache web server

Q: What even is Apache and why would I want it on my Pi?
A: Apache is a web server app that lets your Pi serve web pages.

Q: Does Apache only do basic HTML or can it do fancier stuff too?
A: Apache serves HTML over HTTP, and modules add support for PHP and more.

# Install Apache

Q: How do I actually get Apache installed on my Raspberry Pi?
A: Run sudo apt update, then sudo apt install apache2 -y in Terminal.

Q: Do I need to update my packages before installing Apache or can I just go straight to installing it?
A: Yes, run sudo apt update first before installing the apache2 package.

# Test the web server

Q: I just installed Apache. How do I know if it's actually working?
A: Browse to http://localhost/ on your Pi and look for the success message.

Q: I want to check my Pi's web server from my laptop. What address do I type in?
A: Use your Pi's IP address, like http://192.168.1.10, from another computer.

Q: How do I find my Pi's IP address to test the web server from another device?
A: Type hostname -I at the command line to find your Pi's IP address.

## Change the default web page

Q: Where's the default Apache web page actually stored on my Pi?
A: The default page is at /var/www/html/index.html on the filesystem.

Q: I want to edit that default web page but I can't save changes. What's going on?
A: The file is owned by root, so change ownership using sudo chown username: index.html.

Q: I changed the index.html file. How do I see if it worked?
A: Save the file, then refresh your browser to see the web page update.

# Install PHP for Apache

Q: I want my Pi's web server to run PHP. What do I need to install?
A: Install php and libapache2-mod-php using sudo apt install php libapache2-mod-php -y.

Q: After installing PHP, why do I have to delete the index.html file?
A: Not specified in this section.

Q: I've set up PHP on Apache. How do I do a quick test to make sure it's working?
A: Create index.php with <?php echo "hello world"; ?> and refresh your browser.

Q: Is there a way to check all my PHP settings through the browser on my Pi?
A: Yes, create a PHP file containing <?php phpinfo(); ?> and open it in your browser.

# Whole Document

Q: Can I host a website on my local network using just a Raspberry Pi?
A: Yes, put your HTML files in /var/www/html/ and serve them locally.

Q: I've never set up a web server before. Is this something a beginner can actually do on a Pi?
A: Yes, Apache installs with one command and works immediately with minimal configuration.
