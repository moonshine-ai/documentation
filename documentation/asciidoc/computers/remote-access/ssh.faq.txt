# Enable the SSH server

Q: SSH is turned off on my Pi by default, right? How do I turn it on?
A: Enable SSH via desktop Control Centre, raspi-config, Imager, or manually.

Q: I'm setting up a brand new Pi. Can I enable SSH before I even boot it for the first time?
A: Yes, enable SSH during Imager setup under the Customisation Remote Access tab.

Q: How do I turn on SSH using just the terminal, without touching any desktop settings?
A: Run sudo raspi-config, select Interfacing Options, then navigate to SSH and choose Yes.

Q: I don't want to use raspi-config. Is there a manual way to enable SSH without any menus?
A: Create an empty file named ssh in the boot partition, then reboot the machine.

Q: When I'm flashing a new image with Imager, where exactly do I find the SSH toggle?
A: It's under the Customisation Remote Access tab in Raspberry Pi Imager.

# Connect to an SSH server

Q: Okay I've enabled SSH, now how do I actually connect to my Pi from another computer?
A: Open a terminal and run ssh username at the Pi's IP address.

Q: I'm trying to SSH in and I keep getting connection timed out. What's going on?
A: You may have entered the wrong IP address for your Raspberry Pi.

Q: The first time I connected over SSH it showed some security warning. Is that normal?
A: Yes, just type yes to continue; you'll only see it on the first connection.

Q: Do I need to be on the same network as my Pi to use SSH?
A: Yes, SSH works between computers on the same network.

# Forward X11 over SSH

Q: Can I run graphical apps on my Pi from my laptop over SSH?
A: Yes, use ssh -Y to forward X11 and open graphical windows remotely.

Q: I'm on a Mac and want to use X11 forwarding over SSH. Do I need anything extra?
A: Yes, macOS requires a third-party X server to use X11 forwarding.

Q: What flag do I add to SSH to get graphical windows working?
A: Pass the -Y flag to forward an X session over SSH.

# Configure SSH without a password

Q: I'm sick of typing my password every time I SSH into my Pi. Can I skip that?
A: Yes, set up an SSH keypair so you can connect without a password each time.

# Preconfigure an OS image with Raspberry Pi Imager

Q: Can I set up SSH keys during the initial Imager setup so I don't have to do it later?
A: Yes, enable SSH and select public key authentication in Imager's Remote Access tab.

Q: If I already have an SSH key on my computer, will Imager pick it up automatically?
A: Yes, if id_rsa.pub exists in tilde/.ssh, Imager automatically prefills it for you.

# Check for existing SSH public keys

Q: How do I know if I've already got an SSH key on my computer before making a new one?
A: Run ls tilde/.ssh and look for files like id_ed25519.pub or id_rsa.pub.

# Generate new SSH keypair

Q: I don't have any SSH keys yet. How do I make a new pair?
A: Run ssh-keygen, press Enter for default location, and Enter again for no passphrase.

Q: Where does ssh-keygen save my keys by default?
A: The default save location is tilde/.ssh/id_rsa for the private key.

Q: Which file is my public key and which is my private key after running ssh-keygen?
A: id_rsa is your private key; id_rsa.pub is your public key to share.

Q: Is RSA the only option for generating SSH keys, or can I use something else?
A: You can also generate an Ed25519 key by passing -t ed25519 to ssh-keygen.

# Add the SSH key to your list of SSH identities

Q: After generating my SSH key, do I need to do anything before I can use it?
A: Start the SSH agent and add your key with ssh-add tilde/.ssh/id_rsa.

# Copy a public key to your Raspberry Pi

Q: How do I get my public key onto my Pi so I can log in without a password?
A: Run ssh-copy-id username at the Pi's IP address from your computer.

# Manually copy a public key to your Raspberry Pi

Q: My system doesn't have ssh-copy-id. How else can I get my public key onto my Pi?
A: Use scp to copy your public key to .ssh/authorized_keys on your Raspberry Pi.

Q: What permissions should I set on the .ssh folder and authorized_keys file on my Pi?
A: Set .ssh to 700 and authorized_keys to 644.

Q: I already have SSH keys set up on my Pi and want to add another one without wiping the old ones.
A: Append the new public key as a new line in the existing authorized_keys file.

# Whole Document

Q: What even is SSH? Why would I want to use it with my Pi?
A: SSH lets you access your Raspberry Pi's terminal remotely from another computer.

Q: I want to control my Pi from my laptop without plugging in a keyboard or monitor. What do I need?
A: Use SSH to access the Pi's terminal remotely over your network.

Q: Do I need a password to connect via SSH, or can I set it up to just log straight in?
A: You can use password authentication or set up SSH keys to skip the password.
