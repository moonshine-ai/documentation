# Whole Document

Q: What even is SCP and why would I use it on my Pi?
A: SCP sends files securely over SSH between your Pi and another computer.

Q: Do I need anything special set up before I can use SCP with my Pi?
A: You need to know your Raspberry Pi's IP address to use SCP.

Q: I've never used SCP before — does it work both ways, like can I send and receive files?
A: Yes, you can copy files both to and from your Raspberry Pi using SCP.

# Copy files to your Raspberry Pi

Q: How do I send a file from my laptop over to my Pi?
A: Run `scp myfile.txt username@pi_ip_address:` from your computer's terminal.

Q: I want to copy a file into a specific folder on my Pi, not just the home directory. How do I do that?
A: Append the directory path after the colon in your SCP command.

Q: Wait, will SCP automatically make the folder if it doesn't exist yet?
A: No, SCP won't create folders automatically — you must create them beforehand.

Q: What do I replace in the SCP command — like what are those placeholder things?
A: Replace username with your Pi login name and pi_ip_address with your Pi's IP.

# Copy files from your Raspberry Pi

Q: How do I grab a file off my Pi and pull it down to my computer?
A: Run `scp username@pi_ip_address:myfile.txt .` to copy it to your current directory.

Q: That dot at the end of the SCP command — what's that for?
A: The dot means copy the file into your current directory on your computer.

# Copy multiple files with one command

Q: Can I copy more than one file at a time or do I have to do them one by one?
A: You can list multiple filenames separated by spaces in a single SCP command.

Q: I want to copy all my text files over to the Pi at once. Is there a quick way to do that?
A: Use `scp *.txt username@pi_ip_address:` to copy all files ending in `.txt`.

Q: Can I use a wildcard to copy files that start with a certain letter?
A: Yes, for example `scp m* username@pi_ip_address:` copies all files starting with m.

Q: My filename has a space in it and SCP isn't working. What am I doing wrong?
A: Wrap the filename in quotes, like `scp "my file.txt" username@pi_ip_address:`.

# Copy a folder

Q: How do I copy a whole folder with everything inside it over to my Pi?
A: Use the `-r` flag, like `scp -r project/ username@pi_ip_address:`, for recursive copying.

Q: What's that `-r` flag do when I'm copying folders with SCP?
A: The `-r` flag means recursive, copying the folder and all of its contents.
