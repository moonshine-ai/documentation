# Remote access with Raspberry Pi Connect

Q: I want to control my Pi from another computer. What's the easiest way to do that remotely?
A: Use Raspberry Pi Connect to access your Pi from any browser.

Q: Do I need to mess with my router settings or firewall to access my Pi remotely?
A: No, Connect handles configuration automatically without firewall or IP changes.

Q: I don't know my Pi's IP address. Can I still access it remotely?
A: Yes, Connect works without needing your Pi's local or public IP address.

Q: Does Raspberry Pi Connect let me see the actual desktop, or just the terminal?
A: It supports screen sharing on Wayland models and terminal access on all models.

Q: I've got an older Pi model. Can I still use Raspberry Pi Connect for anything?
A: Remote shell terminal access works on all Raspberry Pi models with Connect.

Q: What's Raspberry Pi Connect actually do? Like, what's it for?
A: It lets you access your Raspberry Pi remotely from a browser on another device.

Q: My Pi uses Wayland. Does Connect give me full screen sharing or just command line?
A: Wayland models get full screen sharing, plus remote shell terminal access too.

Q: Where do I find out more about setting up Raspberry Pi Connect?
A: Check the Connect documentation for full details and setup instructions.
