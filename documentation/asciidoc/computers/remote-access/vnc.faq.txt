# Whole Document

Q: What even is VNC and why would I need it on my Raspberry Pi?
A: VNC lets you control your Raspberry Pi's desktop from another device remotely.

Q: So both my Pi and my laptop need to be on the same network for this to work?
A: Yes, both devices must be connected to the same network, like home Wi-Fi.

Q: I've never used VNC before. What two things do I need to get it working?
A: You need a VNC server on your Pi and a VNC client on another device.

# Screen share with VNC

Q: My keyboard and mouse are far away from my Pi. Can I just control it from my laptop instead?
A: Yes, VNC lets you send keyboard and mouse events to your Pi remotely.

Q: What VNC software does Raspberry Pi OS come with already?
A: Raspberry Pi OS includes wayvnc, which provides a built-in VNC server.

Q: I just want to see my Pi's desktop on my computer screen. Is that possible with VNC?
A: Yes, the VNC client displays your Pi's desktop in a window on your device.

# Enable the VNC server

Q: Do I have to use the terminal to turn on VNC or can I do it through the desktop?
A: You can enable VNC either graphically through the desktop or via the command line.

Q: I turned on VNC and now I want to tweak the settings. Where's the config file?
A: The WayVNC configuration is accessible at the path slash etc slash wayvnc slash.

# Enable VNC Server Graphically

Q: How do I turn on VNC without using the terminal?
A: Go to system tray, Preferences, Control Centre, Interfaces tab, and toggle VNC on.

Q: I found the Interfaces tab but I don't see how to save my changes. What do I do?
A: Click the OK button to save your VNC configuration changes.

# Enable the VNC server on the command line

Q: What command do I type to start setting up VNC from the terminal?
A: Run sudo raspi-config, then navigate to Interface Options and select VNC.

Q: I'm in raspi-config trying to enable VNC. How do I actually confirm I want it on?
A: Highlight yes under the VNC Server prompt and press Enter to confirm.

Q: How do I get out of raspi-config once I've turned VNC on?
A: Press Enter to return to the menu, then press Escape to exit raspi-config.

# Connect to a VNC server

Q: What do I actually need to know before I can connect to my Pi using VNC?
A: You need your Pi's hostname or IP address and a valid username and password.

Q: I don't know my Pi's IP address. How am I supposed to connect to it?
A: Check the instructions for finding your IP address linked in the documentation.

Q: What VNC client should I download to connect to my Pi?
A: Download TigerVNC from the Releases page of their GitHub repository.

Q: I'm on a Mac. What file do I download for TigerVNC?
A: macOS users should download the dmg file from TigerVNC's GitHub releases page.

Q: I'm on Linux and I've downloaded TigerVNC. How do I actually run it?
A: Install Java with sudo apt install default-jre, then run the jar file with Java.

Q: I connected with TigerVNC but I can't see the mouse cursor anywhere. What's wrong?
A: In TigerVNC Options under the Input tab, check "Show dot when no cursor."

Q: TigerVNC is giving me some warning about a certificate signed by an unknown authority. Should I be worried?
A: Click Yes to grant an exception for your Raspberry Pi and continue connecting.

Q: I connected and entered my username and password but now what happens?
A: If credentials are correct, TigerVNC opens a window showing your Pi's desktop.
