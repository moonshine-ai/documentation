# Synchronise folders between computers with `rsync`

Q: How do I copy files from my Raspberry Pi to my PC automatically?
A: Use rsync to synchronise folders between your Raspberry Pi and personal computer.

Q: I keep running the rsync command over and over — does it re-download everything each time?
A: No, rsync tracks already downloaded files and skips them each time.

Q: What info do I need before I can set up rsync between my Pi and my computer?
A: You need your Pi's IP address, username, and the folder names to sync.

Q: If I delete a file on my Pi after syncing, does it get removed on my PC too?
A: Yes, rsync updates your personal computer if you delete or modify synced files.

Q: I want photos taken on my Pi to automatically show up on my laptop. Can rsync do that?
A: Yes, rsync can transfer new pictures from your Raspberry Pi to your personal computer.

Q: What's the actual command I run to sync a folder from my Pi to my computer?
A: Run rsync with dash avz, dash e ssh, your username, IP address, and folder names.

Q: Do I need to create a folder on my PC first before running rsync?
A: Yes, first create the destination folder using mkdir before running the rsync command.

Q: Where do I run the rsync command — on the Pi or on my personal computer?
A: Run the rsync synchronisation steps on your personal computer, not your Raspberry Pi.
