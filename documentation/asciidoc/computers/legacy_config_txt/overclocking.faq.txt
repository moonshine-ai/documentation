# Whole Document

Q: What are these legacy overclocking options actually for?
A: They prevent overvoltaging and disable automatic GPU turbo mode.

Q: I'm trying to overclock my Pi but don't want to void my warranty. What should I know?
A: Setting `never_over_voltage` locks the device and prevents warranty bit being set.

# `never_over_voltage`

Q: What's OTP memory? Like why does it matter for overclocking?
A: OTP is one-time programmable memory; changes to it are permanent and irreversible.

Q: I accidentally want to make sure nobody can overvolt my Pi. Is there a setting for that?
A: Yes, `never_over_voltage` sets a permanent bit preventing any overvoltage on the device.

Q: What does the warranty bit thing mean? Can I lose my warranty from overclocking?
A: Overvoltaging can set a warranty bit; `never_over_voltage` prevents that from happening.

Q: So if I set `never_over_voltage`, is that reversible or is it permanent?
A: It's permanent — it writes to one-time programmable memory, which can't be undone.

# `disable_auto_turbo`

Q: My Pi 2 keeps boosting its speed on its own. How do I stop that from happening?
A: Set `disable_auto_turbo` to stop the GPU automatically moving into turbo mode.

Q: Does the Pi 3 automatically speed itself up under heavy load? Can I turn that off?
A: Yes, it can; set `disable_auto_turbo` to disable that automatic GPU turbo behaviour.

Q: What exactly triggers turbo mode on a Pi 2 or 3?
A: The documentation says turbo mode activates under particular loads, without more detail.
