# Raspberry Pi 4 HDMI Pipeline

Q: My monitor is 1366 by 768 and the Pi 4 won't output to it. What's going on?
A: Pi 4 can't output HDMI at 1366×768 at 60Hz resolution.

Q: I've got a monitor that supports 1360 by 768. Can I manually set that on my Pi 4?
A: Yes, add hdmi_group, hdmi_mode, and hdmi_cvt settings to config.txt.

Q: What do I put in config.txt to get 1360 by 768 at 60Hz on my Pi 4?
A: Set hdmi_group=2, hdmi_mode=87, and hdmi_cvt=1360 768 60.

Q: Why doesn't my Pi 4 just automatically pick the right resolution for my monitor?
A: Monitors don't typically advertise 1360×768 via EDID, so it can't auto-select.

Q: I'm setting custom HDMI timings manually. Is there anything I need to watch out for?
A: All horizontal timing parameters must be divisible by two when set manually.

Q: Does the same divisible-by-two rule apply to DPI timings too?
A: No, DPI timings aren't restricted that way as it runs one pixel per clock.

Q: I'm using the VC4 KMS graphics driver. Do these HDMI settings in config.txt apply to me?
A: No, these settings only apply to legacy FKMS and firmware-based graphics drivers.

Q: Wait, these settings don't work with the newer graphics driver?
A: Correct, with VC4 KMS, Linux manages the display pipeline, not these settings.
