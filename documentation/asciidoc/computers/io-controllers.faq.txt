# RP1 I/O Controller

Q: What exactly is RP1 and what does it do?
A: RP1 is an in-house chip managing USB, Ethernet, GPIO, and storage interfaces.

Q: Does RP1 work on its own, like can I buy it separately?
A: No, RP1 isn't sold separately; it's built into Raspberry Pi 5 and Compute Module 5.

Q: Wait, is RP1 the same as the original Raspberry Pi Model B?
A: No, RP1 is not short for the first Raspberry Pi single-board computer.

# RP1 Overview

Q: How does RP1 connect to the main processor?
A: RP1 connects to BCM2712 over a PCIe 2.0 x4 link on Raspberry Pi 5.

Q: How big is the RP1 chip physically?
A: RP1 measures approximately 12 by 12 millimetres in a BGA package.

Q: Why does Raspberry Pi even use a separate chip for I/O instead of just the main CPU?
A: It offloads I/O tasks, continuing Raspberry Pi's traditional two-chip architecture.

# Peripheral Interfaces

Q: What USB ports does RP1 actually give you?
A: Each USB host controller provides one USB 3.0 port and one USB 2.0 port.

Q: I've heard RP1 improves USB bandwidth compared to older Pis. Is that true?
A: Yes, RP1 provides more than twice the usable USB bandwidth compared to Raspberry Pi 4.

Q: Does RP1 support cameras and displays?
A: Yes, via two 4-lane MIPI transceivers supporting DSI and CSI-2 interfaces.

Q: What low-speed interfaces does RP1 support?
A: RP1 supports SPI, UART, I2C, PWM, GPIO, and I2S low-speed peripherals.

Q: Does RP1 have Ethernet built in?
A: Yes, RP1 includes a Gigabit Ethernet MAC.

# Internal Features

Q: What processors are inside RP1?
A: RP1 integrates two Cortex M3 processors with tightly-coupled memories.

Q: Does RP1 have any kind of analog input, like for reading sensor voltages?
A: Yes, RP1 includes a 12-bit ADC with a built-in temperature sensor.

Q: How much onboard memory does RP1 have?
A: RP1 has 64 kilobytes of shared SRAM.

# Multimedia and Audio Components

Q: Can RP1 do audio without needing extra hardware?
A: Yes, RP1 supports delta-sigma PWM audio out without external codecs.

Q: Does RP1 support composite video output?
A: Yes, it has a 3-channel video DAC, but only one composite channel is used on Raspberry Pi 5.

Q: I want to connect a microphone directly. Does RP1 support that?
A: RP1 includes a PDM microphone clock generator and stereo bitstream input.

Q: Can RP1 drive a display connected directly to GPIO pins?
A: Yes, RP1 includes a DPI video frame generator for GPIO-connected displays.

# RP1 Naming

Q: Why is it called RP1? Does that mean it's the first Raspberry Pi?
A: RP1 refers to Raspberry Pi's first embedded I/O controller chip, not the first Pi.

Q: How does Raspberry Pi name its silicon chips?
A: Names start with RP for Raspberry Pi, followed by a number indicating chip generation.
