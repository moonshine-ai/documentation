# Use GPIO from Python

Q: What's the easiest way to control GPIO pins with Python on a Raspberry Pi?
A: The GPIO Zero library makes it easy to control GPIO devices with Python.

Q: Where do I find the full docs for that GPIO Zero library?
A: Full GPIO Zero documentation is available at gpiozero.readthedocs.io.

# LED Control

Q: I've got an LED wired up and I just want to make it blink. How do I do that in Python?
A: Import LED from gpiozero, then call led.on() and led.off() in a loop with sleep.

Q: What pin do I connect my LED to for that example code to work?
A: The example connects the LED to GPIO17.

Q: What are all the things I can make an LED do with GPIO Zero?
A: LED methods include on(), off(), toggle(), and blink().

Q: Can I just run that LED code in Thonny or do I need to use the terminal?
A: Yes, you can run it in an IDE like Thonny and the LED will blink repeatedly.

# Read Button State

Q: I've got a button wired to my Pi and I want to know if it's being pressed. How do I check that in Python?
A: Use the Button class from gpiozero and check the is_pressed property in a loop.

Q: What GPIO pin does that button example use?
A: The button example connects the button to GPIO2.

Q: Is there a way to detect if someone's holding a button down, not just pressing it?
A: Yes, GPIO Zero's Button has an is_held property and a when_held callback for that.

Q: Can I run some code automatically whenever a button gets pressed or released?
A: Yes, use the when_pressed and when_released callbacks on the Button object.

Q: I want my code to just stop and wait until the button is pressed. Is there a way to do that?
A: Yes, call button.wait_for_press() and your code will pause until it's pressed.

# Control an LED with a Button

Q: How do I make an LED turn on when I press a button and off when I let go?
A: Check button.is_pressed in a loop and call led.on() or led.off() accordingly.

Q: Are there different ways to wire up button and LED control logic in GPIO Zero?
A: Yes, there are three approaches: a loop with is_pressed, wait_for_press, or when_pressed callbacks.

Q: What's the simplest cleanest way to link a button press to an LED without a big loop?
A: Assign led.on to button.when_pressed and led.off to button.when_released directly.

Q: In that button-LED example, what GPIO pins are being used for each component?
A: The LED is on GPIO17 and the button is on GPIO2 in those examples.
