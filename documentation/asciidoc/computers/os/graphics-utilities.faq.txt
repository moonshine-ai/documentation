# `kmsprint`

Q: How do I see what display modes my monitor supports on my Pi?
A: Run `kmsprint -m` to list all display modes for each monitor.

Q: I just want to check what monitors are connected to my Pi. What do I run?
A: Run `kmsprint` to see details of all connected monitors.

# `vclog`

Q: How do I see what my GPU's been logging? Like error messages and stuff?
A: Run `sudo vclog --msg` for message log or `--assert` for assertion log.

Q: Do I need root to check the VideoCore logs or can I just run it normally?
A: Yes, `vclog` needs to be run as root using `sudo`.

# `vcgencmd`

Q: I don't know what commands vcgencmd supports. How do I get a list?
A: Run `vcgencmd commands` to see all supported commands.

# `vcos`

Q: How do I check what version of firmware my Pi's GPU is running?
A: Use `vcgencmd vcos version` to display the firmware build date and version.

Q: I want to see if there are any errors in the VideoCore firmware. How do I check?
A: Run `vcgencmd vcos log status` to display VideoCore firmware error log status.

# `get_throttled`

Q: My Pi might be throttling itself. How do I actually check if that's happening?
A: Run `vcgencmd get_throttled` — it returns a bit pattern showing throttling status.

Q: I ran get_throttled and got back some weird number. What does it mean?
A: It's a bit pattern where set bits indicate issues like undervoltage or throttling.

Q: What's the difference between "currently throttled" and "throttling has occurred"?
A: Bit 2 means throttled right now; bit 18 means throttling happened at some point.

Q: How do I know if my Pi's been undervolted at some point, even if it's fine now?
A: Bit 16 with hex value 0x10000 in `get_throttled` means undervoltage has occurred.

# `measure_temp`

Q: How do I check what temperature my Pi's running at?
A: Run `vcgencmd measure_temp` to get the SoC temperature from its internal sensor.

Q: I've got a Pi 4 — can I check the temperature of the PMIC separately?
A: Yes, use `vcgencmd measure_temp pmic` on Raspberry Pi 4 for PMIC temperature.

# `measure_clock [clock]`

Q: How do I see what speed my Pi's CPU is actually running at right now?
A: Run `vcgencmd measure_clock arm` to get the current ARM core frequency.

Q: Can I check what frequency the HDMI is running at using vcgencmd?
A: Yes, run `vcgencmd measure_clock hdmi` to get the current HDMI clock frequency.

Q: Is there a way to check the speed of the SD card interface on my Pi?
A: Yes, use `vcgencmd measure_clock emmc` to check the SD card interface frequency.

# `measure_volts [block]`

Q: How do I check what voltage the GPU core is running at?
A: Run `vcgencmd measure_volts core` to display the current VC4 core voltage.

Q: Can I check my SDRAM voltage with vcgencmd or something?
A: Yes, use `measure_volts sdram_c`, `sdram_i`, or `sdram_p` for SDRAM voltages.

# `otp_dump`

Q: What's OTP memory and can I see what's stored in it on my Pi?
A: OTP is one-time programmable memory; use `vcgencmd otp_dump` to display its contents.

# `get_config [configuration item|int|str]`

Q: How do I check how much total RAM my Pi has using the command line?
A: Run `vcgencmd get_config total_mem` to return total memory in megabytes.

Q: I want to see all the integer config settings on my Pi. How do I list them?
A: Run `vcgencmd get_config int` to display all integer configuration items.

# `get_mem type`

Q: How do I see how much memory is available to the GPU versus the CPU?
A: Use `vcgencmd get_mem gpu` for GPU memory and `get_mem arm` for ARM memory.

Q: I've got a Pi with more than a gig of RAM but get_mem arm shows less. Is that a bug?
A: No, GPU firmware only sees the first 1 GB, so `arm` always returns 1 GB minus GPU memory.

# `codec_enabled [type]`

Q: How do I check if H264 decoding is enabled on my Pi?
A: Run `vcgencmd codec_enabled H264` to report whether H264 is enabled.

Q: Can I use codec_enabled to check H265 on my Pi 4?
A: No, the Pi 4's H.265 block isn't part of the VideoCore GPU so this command won't work.

# `mem_oom`

Q: My Pi keeps crashing and I think it's running out of GPU memory. How do I check?
A: Run `vcgencmd mem_oom` to display out-of-memory event statistics in VideoCore memory.

# `mem_reloc_stats`

Q: Is there a way to see stats on how VideoCore memory is being allocated?
A: Yes, run `vcgencmd mem_reloc_stats` to see relocatable memory allocator statistics.

# `read_ring_osc`

Q: What does read_ring_osc actually tell me?
A: It returns the ring oscillator's current speed, voltage, and temperature.

# Whole Document

Q: What utilities come pre-installed on Raspberry Pi OS for checking system info?
A: Raspberry Pi OS includes `kmsprint`, `vclog`, and `vcgencmd` as pre-installed utilities.

Q: I want to dig into the source code for vcgencmd. Where can I find it?
A: The `vcgencmd` source code is available on GitHub at the raspberrypi/utils repository.

Q: Can I use these command-line tools without a desktop, just from the terminal?
A: Yes, all these utilities are command-line tools usable directly from the terminal.
