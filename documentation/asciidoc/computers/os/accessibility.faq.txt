# Visual aids

Q: I have trouble seeing the screen. Are there any accessibility tools for Raspberry Pi OS?
A: Yes, Orca screen reader and a screen magnifier are available for visually impaired users.

Q: Where do I find the accessibility tools in Raspberry Pi OS?
A: You can find helpful visual aid tools in the Recommended Software menu.

Q: I've heard there's a screen reader for Raspberry Pi. How do I get it?
A: Install Orca from Recommended Software, or press Ctrl, Alt, and Space.

Q: What's Orca? Is it something I need for my Raspberry Pi?
A: Orca is a screen reader that helps visually impaired users navigate Raspberry Pi Desktop.

# Orca screen reader

Q: I just set up a fresh Raspberry Pi image and I'm not sure how to get the screen reader going. Is there a reminder or something?
A: After first boot, a spoken reminder plays after thirty seconds with Orca installation instructions.

Q: I can't use a mouse very well. Is there a keyboard shortcut to get the screen reader installed?
A: Yes, pressing Ctrl, Alt, and Space will automatically install Orca for you.

Q: Does Raspberry Pi OS have anything to make the screen easier to read if my eyesight isn't great?
A: Raspberry Pi OS offers both a screen reader and a screen magnifier for readability.

Q: I booted up my Pi for the first time and heard some voice thing. What was that?
A: That's an automatic spoken reminder with instructions on how to install Orca screen reader.
