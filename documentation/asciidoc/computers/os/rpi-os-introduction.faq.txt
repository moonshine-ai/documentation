# Introduction

Q: What's Raspberry Pi OS actually based on, like what's it built from?
A: Raspberry Pi OS is a free, Debian-based operating system optimised for Raspberry Pi.

Q: How often do they release new versions of Raspberry Pi OS?
A: New releases happen roughly every two years, following Debian's release cycle.

Q: What's the newest version of Raspberry Pi OS right now?
A: The latest version is based on Debian Trixie; the previous was Bookworm.

Q: I heard Raspberry Pi OS supports a ton of packages. How many are we talking?
A: Raspberry Pi OS supports over 35,000 Debian packages.

# Get Raspberry Pi OS

Q: Where do I even download Raspberry Pi OS from?
A: Get it through Raspberry Pi Imager or from raspberrypi.com/software/operating-systems.

Q: What's the difference between the regular desktop version and the full version?
A: The full version adds LibreOffice, KiCad, Scratch, and many other applications.

Q: I just want a basic setup without a desktop. Is there a version for that?
A: Raspberry Pi OS Lite has no graphical desktop, suited for headless servers.

Q: Does Raspberry Pi OS Lite come with a browser and VLC and stuff?
A: No, Lite doesn't include a desktop, browser, VLC, or those bundled applications.

Q: I've got a Pi Zero — which version of Raspberry Pi OS should I be using?
A: Raspberry Pi OS Lite is recommended for Pi 1, 2, and Zero computers.

Q: I'm on an older version and want to upgrade to the latest. Can I just do it in place?
A: No, start fresh with a new image instead of doing an in-place upgrade.

Q: Does Raspberry Pi OS come in both 32-bit and 64-bit?
A: Yes, both 64-bit and 32-bit versions are available in all three editions.

Q: The desktop version — does it actually come with a web browser already installed?
A: Yes, it includes both Chromium and Firefox web browsers out of the box.

# Whole Document

Q: What is Raspberry Pi OS and do I need to pay for it?
A: Raspberry Pi OS is free, Debian-based, and optimised for Raspberry Pi hardware.

Q: I want to do Python stuff on my Pi. Does the desktop version have anything for that?
A: Yes, the desktop edition includes the Thonny Python environment pre-installed.

Q: Which edition of Raspberry Pi OS shows up by default when I open the Imager?
A: Raspberry Pi OS with desktop is the default version shown in Raspberry Pi Imager.
